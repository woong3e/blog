JDBC는 Java 프로그램이 데이터베이스에 연결해 SQL을 실행하고 결과를 읽는 표준 API다. 드라이버는 이 API 호출을 특정 데이터베이스와 통신하는 동작으로 연결한다. Java 코드·SQL·접속 설정의 역할을 나누면 오류 위치를 찾기 쉽다.

## ☘️ 연결 설정과 자원의 소유자

DriverManager는 JDBC 주소와 계정 정보로 Connection을 얻는다. 주소에는 DB 종류·호스트·포트·데이터베이스 등이 들어간다. MySQL 드라이버 의존성이 있어야 해당 주소를 처리할 수 있다. 아래 예제는 접속값을 환경 변수에서 읽어 소스에 비밀번호를 넣지 않는다.

Connection은 실제 연결 자원이다. 연결을 만든 쪽이 언제 닫을지 책임을 가져야 한다. DAO마다 전달받은 연결을 닫으면 뒤의 다른 작업이 실패할 수 있으므로 아래 DAO는 문장과 결과만 닫고 main이 마지막에 연결을 닫는다.

## ☘️ SQL과 값을 분리하기

Statement에 사용자 입력을 문자열로 이어 붙이면 입력이 SQL 구조로 해석될 위험이 있다. PreparedStatement는 SQL의 값 자리를 물음표로 두고 setInt·setString 등으로 별도 전달한다. 인수 위치는 1부터 시작한다. 물음표는 값 자리이며 테이블명이나 임의 SQL 문법 전체를 대체하는 용도는 아니다.

executeQuery는 조회 결과인 ResultSet을, executeUpdate는 등록·수정·삭제된 행 수를 반환한다. ResultSet은 처음부터 첫 행을 가리키지 않는다. next로 다음 행에 이동하고 true일 때 열을 읽는다. 열의 이름과 Java 타입을 맞춰 Menu 객체로 옮긴다.

## ☘️ DTO와 DAO로 역할 나누기

Menu는 한 행의 번호·이름·가격을 담아 전달한다. 이런 자료 전달 객체를 DTO라고 한다. MenuDAO는 SQL과 결과 변환을 모아 데이터 접근을 담당한다. main은 등록·검색·수정·삭제의 순서를 조정하고 SQL의 세부 문자열을 반복하지 않는다.

try-with-resources는 작업 중 예외가 발생해도 자원을 닫는다. ResultSet과 PreparedStatement를 안쪽에서 닫고 Connection은 바깥에서 닫으면 사용 순서의 반대로 정리된다. 자원을 닫는 것과 트랜잭션의 변경을 확정·취소하는 것은 별도 책임이다.

아래 예제는 같은 연결에서만 존재하는 임시 테이블을 사용한다. 메뉴 두 개를 등록하고 이름으로 찾은 뒤 가격을 바꾸고 첫 행을 지운다. 마지막 조회에서 남은 행과 수정 가격을 확인할 수 있다. 실제 접속 실행에는 본인이 준비한 MySQL 계정과 연습용 데이터베이스가 필요하다.

## ☘️ 연결부터 SQL 실행·자원 해제까지의 전체 예제

원본의 JDBC 연결·PreparedStatement·DAO 분리 흐름을 임시 테이블 하나로 정리한 설명용 예제다. 실제 메뉴 테이블을 수정하지 않는다. 연결 설정은 코드에 비밀번호를 쓰지 않고 환경 변수로 받는다.

**src/main/java/Main.java**

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;
import java.util.Properties;

public class Main {
  public static void main(String[] args) throws Exception {
    String url = required("JDBC_URL"),
        user = required("JDBC_USER"),
        password = required("JDBC_PASSWORD");
    Properties settings = new Properties();
    settings.setProperty("user", user);
    settings.setProperty("password", password);
    Class.forName("com.mysql.cj.jdbc.Driver");
    try (Connection connection = DriverManager.getConnection(url, settings)) {
      try (Statement statement = connection.createStatement()) {
        statement.executeUpdate(
            "CREATE TEMPORARY TABLE til_menu (code INT PRIMARY KEY, name VARCHAR(50), price INT)");
      }
      MenuDAO dao = new MenuDAO();
      System.out.println("등록 행 수: " + dao.insert(connection, new Menu(1, "아메리카노", 3000)));
      System.out.println("등록 행 수: " + dao.insert(connection, new Menu(2, "카페라떼", 4000)));
      for (Menu menu : dao.findByPrefix(connection, "카페")) System.out.println(menu);
      try (PreparedStatement statement =
          connection.prepareStatement("UPDATE til_menu SET price = ? WHERE code = ?")) {
        statement.setInt(1, 4500);
        statement.setInt(2, 2);
        System.out.println("수정 행 수: " + statement.executeUpdate());
      }
      try (PreparedStatement statement =
          connection.prepareStatement("DELETE FROM til_menu WHERE code = ?")) {
        statement.setInt(1, 1);
        System.out.println("삭제 행 수: " + statement.executeUpdate());
      }
      for (Menu menu : dao.findByPrefix(connection, "")) System.out.println(menu);
    }
  }

  static String required(String name) {
    String value = System.getenv(name);
    if (value == null || value.isBlank()) throw new IllegalStateException(name + " 환경 변수를 지정하세요.");
    return value;
  }
}

class Menu {
  final int code, price;
  final String name;

  Menu(int code, String name, int price) {
    this.code = code;
    this.name = name;
    this.price = price;
  }

  public String toString() {
    return code + ": " + name + " / " + price;
  }
}

class MenuDAO {
  int insert(Connection connection, Menu menu) throws SQLException {
    try (PreparedStatement statement =
        connection.prepareStatement("INSERT INTO til_menu VALUES (?, ?, ?)")) {
      statement.setInt(1, menu.code);
      statement.setString(2, menu.name);
      statement.setInt(3, menu.price);
      return statement.executeUpdate();
    }
  }

  List<Menu> findByPrefix(Connection connection, String prefix) throws SQLException {
    List<Menu> menus = new ArrayList<>();
    try (PreparedStatement statement =
        connection.prepareStatement(
            "SELECT code, name, price FROM til_menu WHERE name LIKE CONCAT(?, '%') ORDER BY"
                + " code")) {
      statement.setString(1, prefix);
      try (ResultSet result = statement.executeQuery()) {
        while (result.next())
          menus.add(
              new Menu(result.getInt("code"), result.getString("name"), result.getInt("price")));
      }
    }
    return menus;
  }
}
```

Connection은 데이터베이스 연결을 나타낸다. DAO는 그 연결을 받아 SQL을 실행하고 Menu는 행의 값을 Java 객체로 담는다. PreparedStatement의 물음표에는 1부터 시작하는 순서로 값을 넣는다. executeUpdate는 변경된 행 수를 반환하고 executeQuery는 ResultSet을 반환한다. next를 호출해 현재 행을 이동한 뒤 각 열을 읽는다. try-with-resources는 ResultSet과 문장을 닫고 main이 자신이 만든 Connection을 마지막에 닫는다. 임시 테이블은 같은 연결 동안만 사용된다. 메뉴 두 개 등록 → 이름 검색 → 가격 변경 → 첫 행 삭제 → 남은 한 행 조회 순서다.

코드와 초기값을 분석한 예상 출력(DB 연결 실행은 미검증):

```text
등록 행 수: 1
등록 행 수: 1
2: 카페라떼 / 4000
수정 행 수: 1
삭제 행 수: 1
2: 카페라떼 / 4500
```

**실행 방법**

Gradle과 JDK 21, MySQL 서버가 필요하다. JDBC_URL에는 `jdbc:mysql://localhost:3306/연습용DB` 형태의 접속 주소, JDBC_USER와 JDBC_PASSWORD에는 본인이 준비한 계정 정보를 환경 변수로 지정한다. package가 없는 Main.java를 표시한 경로에 저장한 뒤 프로젝트 루트에서 `gradle run`을 실행한다. 환경 변수 값은 저장소에 커밋하지 않는다. 이 문서에서는 컴파일까지만 확인했고 DB 연결 실행은 확인하지 않았다.
