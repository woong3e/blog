CSS는 HTML 요소가 화면에 어떤 크기·색·위치로 나타날지 정한다. 규칙은 선택자로 대상을 고르고, 속성과 값으로 표현 방법을 지정한다. 화면이 예상과 다르면 적용 대상, 겹친 규칙의 우선순위, 요소가 차지하는 공간을 나누어 확인한다.

## ☘️ 선택자와 적용 순서

태그 선택자는 같은 태그 전체, 클래스 선택자는 같은 class를 가진 요소, id 선택자는 특정 id의 요소를 고른다. 띄어쓰기는 아래 단계의 자손, >는 바로 아래 자식 관계를 뜻한다. 쉼표로 나누면 여러 대상을 같은 규칙에 묶는다. 속성 선택자는 특정 속성의 존재나 값으로 대상을 고른다.

같은 속성이 겹치면 일반적으로 id·class·태그 등의 구체성을 비교하고, 같은 구체성에서는 뒤에 선언한 규칙이 적용된다. 인라인 스타일이나 !important도 영향을 주므로 단순히 마지막 줄이 항상 이긴다고 생각하면 안 된다. 글자색처럼 자식에게 상속되는 속성과 여백처럼 보통 상속되지 않는 속성도 구분한다.

hover는 포인터를 올린 상태, focus는 입력 등을 선택한 상태를 가리키는 가상 클래스다. ::before와 ::after는 요소의 앞뒤에 꾸밈 내용을 만들 때 쓰는 가상 요소다. 선택 상태와 추가 표현이라는 역할이 다르다.

## ☘️ 요소가 차지하는 공간

박스는 내용, padding, border, margin으로 구성된다. padding은 내용과 테두리 사이, margin은 요소 바깥 간격이다. 기본 content-box에서는 width에 padding과 border가 추가되지만 border-box에서는 지정 너비에 둘을 포함해 계산한다. 같은 width인데 실제 크기가 다르면 box-sizing을 확인한다.

block은 보통 새 줄에서 영역을 차지하고 inline은 글자 흐름 안에 놓인다. inline-block은 흐름에 놓이면서 크기를 지정할 수 있다. display:none은 배치 공간도 없애고 visibility:hidden은 공간을 남긴 채 보이지 않게 한다.

## ☘️ 배치 방식과 기준점

Flex는 주축을 따라 항목을 배치하고 justify-content로 주축, align-items로 반대 축 정렬을 정한다. flex-direction이 바뀌면 축 방향도 달라진다. Grid는 행과 열의 틀을 정하고 그 칸에 항목을 배치한다. 한 방향 나열과 행·열 구성을 나누어 선택한다.

relative는 원래 자리 기준으로 위치를 조정하고, absolute는 배치 흐름에서 빠져 기준이 되는 조상 안에 위치한다. 아래 예제에서는 relative 부모가 기준이다. fixed는 보통 화면 기준으로 고정되고 sticky는 스크롤 조건에 따라 붙는 동작을 한다. top 값만 바꾸기 전에 어떤 기준으로 위치를 계산하는지 확인해야 한다.

색·테두리·그림자·글꼴은 구조를 바꾸지 않고 표현을 조정한다. 반응형 화면은 뷰포트 크기에 따라 규칙을 바꾸는 media query로 대응할 수 있다. 아래 문서는 선택자·박스·배치를 함께 두어 한 규칙의 변화가 주변 요소에 어떤 영향을 주는지 살펴볼 수 있게 구성했다.

## ☘️ 선택자와 화면 배치를 한 문서에서 확인하기

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**css-demo.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>선택과 배치</title>
    <style>
      * {
        box-sizing: border-box;
      }
      body {
        font-family: sans-serif;
        margin: 20px;
      }
      h1,
      h2 {
        text-align: center;
      }
      #lecture-list li {
        color: navy;
      }
      .highlight-text {
        background: beige;
      }
      #blue-text {
        color: blue;
      }
      input[type='text'] {
        border: 2px solid orange;
      }
      input[type='radio']:checked + label {
        font-weight: bold;
      }
      input:focus {
        outline: 3px solid lightblue;
      }
      .box {
        width: 300px;
        max-width: 100%;
        padding: 20px;
        border: 2px dashed aqua;
        margin: 20px auto;
        border-radius: 15px;
        box-shadow: 0 4px 12px #ccc;
      }
      .flex {
        display: flex;
        justify-content: space-between;
        align-items: center;
        flex-wrap: wrap;
        gap: 10px;
      }
      .grid {
        display: grid;
        grid-template-columns: 1fr 1fr 1fr;
        gap: 10px;
      }
      .grid > div:first-child {
        grid-column: 1 / 3;
      }
      .grid > div {
        padding: 10px;
        background: lightgreen;
      }
      .position {
        position: relative;
        height: 100px;
        border: 1px solid;
      }
      .position > span {
        position: absolute;
        top: 30px;
        left: 20px;
      }
      .button {
        display: inline-block;
        padding: 15px;
        background: tomato;
        transition:
          transform 0.3s,
          background 0.3s;
      }
      .button:hover {
        transform: translateY(-10px);
        background: lightgreen;
        opacity: 0.7;
      }
      .button:active {
        transform: translateY(-2px);
      }
      .button::after {
        content: ' →';
      }
    </style>
  </head>
  <body>
    <h1>선택자와 상자</h1>
    <ul id="lecture-list">
      <li>태그 선택</li>
      <li class="highlight-text">클래스 선택</li>
      <li id="blue-text">ID 선택</li>
    </ul>
    <input type="text" aria-label="이름" />
    <input type="radio" id="html" name="subject" checked /><label for="html">HTML</label>
    <input type="radio" id="css" name="subject" /><label for="css">CSS</label>
    <div class="box">내용과 안쪽 여백, 테두리를 합친 너비가 300px입니다.</div>
    <h2>Flex</h2>
    <div class="flex"><span>메뉴 1</span><span>메뉴 2</span><span>메뉴 3</span></div>
    <h2>Grid</h2>
    <div class="grid">
      <div>두 열</div>
      <div>한 열</div>
      <div>다음 행</div>
    </div>
    <h2>Position</h2>
    <div class="position"><span>부모 기준 위치</span></div>
    <a class="button" href="#lecture-list">목록으로 이동</a>
  </body>
</html>
```

style의 선택자는 어떤 HTML 요소에 규칙을 적용할지 정한다. 같은 요소에 규칙이 겹치면 우선순위를 비교하고, 같은 우선순위일 때 뒤에 선언한 값이 적용된다. margin은 요소 밖의 간격, padding은 테두리 안의 여백이다. Flex 영역은 한 방향의 항목 정렬을, Grid 영역은 행과 열 배치를 보여 준다. relative 부모 안의 absolute 표시는 부모를 기준으로 위치를 잡는다. hover는 포인터를 올렸을 때, focus는 입력에 초점이 왔을 때, ::after는 추가 표시 내용을 만들 때 적용된다.
