## ☘️ 선택자와 결합자

![CSS 선택자 과제](/static/images/TIL/css_prac.png)

CSS 과제를 풀며 선택자의 적용 범위를 복습했다.

- `*`: 전체 / `p`: 태그 / `.card`: 클래스 / `#title`: ID
- `h1, h2`: 쉼표로 묶은 요소에 같은 스타일
- `.container p`: 안쪽의 모든 p(자손)
- `.container > p`: 바로 아래 p(자식)
- `h2 + p`: 바로 다음 형제 p 하나
- `h2 ~ p`: 뒤에 오는 형제 p들
- `[type="text"]`: 속성 조건에 맞는 요소

## ☘️ 상태와 장식

- 가상 클래스 `:`: `:hover`, `:focus`, `:first-child`, `:nth-child()`처럼 상태나 위치를 선택한다.
- 가상 요소 `::`: `::before`, `::after`로 요소 내용의 앞·뒤에 장식을 붙인다.

사용자에게 전달할 본문은 HTML에, 구조를 늘릴 필요 없는 시각적 장식은 가상 요소에 둔다. 선택자를 조합하면 필요한 범위에 스타일을 적용할 수 있다.
