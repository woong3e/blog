어려운건 없었지만 css를 오랜만에 다뤄봐서 나름 재밌었던 것 같다.

대충 아는 선택자만으로도 꾸밀수는 있지만 정확히 어떤 선택자들이 있는지 찾아보기로 했다.

선택자에는 전체 선택자 (\*), 태그 선택자 (tag), 클래스 선택자 (.), ID 선택자 (#), 자손 선택자 ( ), 자식 선택자 (>), 인접 형제 선택자 (+), 일반 형제 선택자 (~), 속성 선택자 ([]), 가상 클래스 (:), 가상 요소 (::)가 있다.

가상요소는 많이 봤지만 사용하지 않아서 잘 몰랐는데 찾아보며 이해했다.

최근에는 tailwindcss만 사용하다보니 css 쓰는 법을 잊은 줄 알았는데 그래도 생각나서 다행이었다. 당연한것같기도하고.

아무튼 그냥 선택자를 조합해가면서 사용하면 css를 쓰는데에는 무리가 없을 것 같다.

## 🍀 기본 선택자

1. 전체 선택자 (\*) : 모든 요소를 선택한다.
2. 태그 선택자 (tag) : 특정 html 태그를 선택한다.
3. 클래스 선택자 (.) : 가장 많이 사용하는 것 같다. 클래스를 선택해서 사용한다.
4. ID 선택자 (#) : id를 선택해서 사용한다.

## 🍀 그룹 선택자

1. (,) 여러 선택자에 동일한 스타일을 적용한다. (h1,h2,h3) ,로 묶는 방법으로 사용한다.

## 🍀 결합자

1. 자손 선택자 ( ) : .container p{} , 이 경우에 container 안의 모든 p 태그에 적용된다.
2. 자식 선택자 (>) : .container > p{} , 이 경우에는 container 바로 다음 자식의 p 태그만 적용한다.
3. 인접 형제 선택자 (+) : 바로 다음에 오는 형제 하나를 선택해서 하나만 적용한다.
4. 일반 형제 선택자 (~) : 얘는 인접 형제 선택자와는 다르게 모든 형제들에게 적용한다.

## 🍀 속성 선택자

1. 속성 선택자 ([]) : 특정 속성이 있는 경우 [] 안에 해당 속성을 입력하여 사용한다.

## 🍀 가상 클래스

1. 가상 클래스(:) : :hover, :focus, :first-child,nth-chlid() 등 요소의 특정 상태를 선택한다.

2. 가상 요소 (::) : 가상 요소를 잘 활용해본적이 없어서 좀 헷갈렸는데 'html 구조를 건드리지 않으면서 시각적인 부품을 끼워넣는 것' 이라고 이해했다.

   div로 넣어도 되지만 사용자에게 전달해야하는 내용은 아니고 장식요소이기 때문에 가상 요소를 사용한다. 라고 이해했다.

   ::before 는 해당 요소의 앞에, ::after 는 뒤에 보여진다.
