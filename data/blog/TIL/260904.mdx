## ☘️ CSS 적용과 선택자

HTML이 페이지의 내용과 구조를 나타낸다면 CSS는 글자, 색상, 크기와 배치처럼 화면에 보이는 모습을 정한다. CSS 규칙은 **어떤 요소를 고를지 정하는 선택자**와 그 요소에 적용할 **속성: 값**으로 구성한다.

수업에서는 태그의 `style` 속성에 직접 쓰는 인라인 방식, HTML의 `style` 태그에 쓰는 내부 스타일, 별도 CSS 파일을 `link`로 연결하는 외부 스타일을 살펴봤다. 외부 파일을 쓰면 여러 페이지에서 스타일을 공유하고 HTML과 디자인 코드를 나눌 수 있다.

**요소 선택하기**

- 태그 이름은 해당 종류의 요소를 선택한다. `h2`는 제목 요소를 고른다.
- `.highlight-text`는 해당 클래스가 있는 요소들을 선택한다. 클래스는 여러 요소에 붙일 수 있다.
- `#blue-text`는 해당 id를 가진 요소를 선택한다. id는 문서에서 유일하게 사용한다.
- `input[type="text"]`는 input 중 type 속성의 값이 text인 요소만 고른다.
- 쉼표는 여러 선택자를 묶어 같은 규칙을 적용할 때 쓴다. `*`는 전체 요소를 선택한다.

여러 규칙이 같은 속성에 서로 다른 값을 지정하면 CSS는 적용 조건을 비교해 하나를 정한다. 수업에서는 같은 조건에서 대체로 id 선택자가 클래스보다, 클래스 선택자가 태그 선택자보다 높은 우선순위를 갖는 것을 확인했다. 실제 우선순위에는 적용 출처, `!important`, 선택자 구성과 선언 순서도 영향을 준다.

**요소 사이의 관계**

선택자를 이어 쓰면 HTML 안에서 어느 위치에 있는 요소를 고를지 정할 수 있다. 공백은 안쪽에 있는 모든 자손을, `>`는 바로 아래 자식만 고른다. `+`는 바로 뒤의 형제, `~`는 뒤에 오는 조건에 맞는 형제들을 고른다. 형제는 같은 부모를 가진 요소다.

수업의 `#lecture-list li`는 해당 목록 안에 있는 모든 `li`를 선택한다. 과제의 `header > nav > li`는 header 바로 아래 nav와 그 바로 아래 li를 차례로 찾는다. 각 단계가 바로 연결되어야 하므로 사이에 다른 요소가 끼면 선택되지 않는다.

## ☘️ 상태에 따른 선택과 장식

가상 클래스는 요소의 상태나 위치에 따라 선택한다. `:hover`는 포인터가 올라간 상태, `:focus`는 입력 등으로 포커스를 받은 상태, `:checked`는 선택된 입력을 고른다. `:first-child`와 `:nth-child()`는 형제 사이의 위치를 기준으로 선택한다.

수업의 `input[type="radio"]:checked + label`은 체크된 라디오 입력 바로 뒤의 라벨을 고른다. 따라서 입력의 선택 상태에 맞춰 라벨 색이나 굵기를 바꿀 수 있다. 과제에서는 `header > nav > li:hover`로 포인터가 올라간 메뉴를 위로 움직였다.

가상 요소 `::before`, `::after`는 기존 요소의 내용 앞이나 뒤에 표시할 부분을 CSS에서 만들어 꾸밀 때 쓴다. 내용 자체가 사용자에게 필요한 정보라면 HTML에 두고, 시각적 장식은 가상 요소로 표현할 수 있다.

## ☘️ 글자와 상자 모델

브라우저는 요소가 차지하는 공간을 상자로 다룬다. 안쪽부터 내용, `padding`(내용과 테두리 사이의 여백), `border`(테두리), `margin`(테두리 바깥 여백) 순서다. 여백을 어디에 둘지에 따라 글자와 테두리 사이를 띄울지, 다른 요소와의 간격을 늘릴지가 달라진다.

기본 `box-sizing: content-box`에서는 지정한 너비가 내용 영역의 너비다. 여기에 padding과 border가 더해져 실제 상자가 더 넓어질 수 있다. 수업의 `box-sizing: border-box`는 지정한 너비 안에 내용, padding, border를 포함하므로 크기를 맞추기 쉽다. margin은 이 지정 너비에 포함되지 않는다.

`font-family`는 글꼴, `font-weight`는 굵기, `text-align`은 글자 정렬이다. `border-radius`로 모서리를 둥글게 하고 `box-shadow`로 그림자를 추가했다. `width: 90%`와 `max-width: 300px`을 함께 쓰면 부모 너비에 따라 줄어들되 최대 너비를 넘지 않는다. 좌우 margin을 `auto`로 두어 상자를 가운데 정렬했다.

## ☘️ 배치와 반응

**Flex와 Grid**

`display: flex`를 부모에 지정하면 자식들이 한 방향의 축을 기준으로 배치된다. `justify-content`는 주축 방향의 정렬, `align-items`는 교차축 방향의 정렬을 정한다. 수업에서는 `space-between`으로 항목 사이에 공간을 배분하고 `center`로 교차축 가운데에 맞췄다. `flex-wrap: wrap`은 공간이 부족할 때 항목을 다음 줄로 넘긴다.

`display: grid`는 행과 열을 기준으로 배치한다. 수업의 `grid-template-columns: 1fr 1fr 1fr`은 남은 공간을 같은 비율의 세 열로 나눈다. `gap`은 칸 사이의 간격이다. 첫 항목의 `grid-column: 1/3`은 첫 번째 세로선부터 세 번째 세로선 직전까지, 즉 두 열을 차지하게 한다.

**위치와 상호작용**

`position: relative`를 지정한 요소는 위치가 지정된 자손의 기준점이 될 수 있다. 수업에서는 부모를 relative로 두고 자식에 `position: absolute`, `top`, `left`를 지정해 부모 기준으로 위치시켰다. absolute 요소는 일반적인 문서 흐름에서 빠져 다른 요소와 겹칠 수 있으므로 배치에 주의한다.

수업의 버튼은 `:hover`에서 배경색, 위치, 그림자, 투명도를 바꾸고 `:active`에서 클릭 중 위치를 바꾼다. `transform: translateY(...)`는 요소를 세로 방향으로 이동시키며, `transition`은 속성 변화가 지정한 시간 동안 부드럽게 진행되도록 한다. 메뉴 과제에도 hover 이동과 전환 효과를 적용했다.
