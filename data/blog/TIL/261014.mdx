### Object와 객체의 동등성

API는 프로그램에서 사용할 수 있도록 제공되는 클래스와 메서드 등의 사용 규칙이다. 자바의 모든 클래스는 직접 또는 간접적으로 최상위 클래스인 `Object`를 상속하므로, Object의 메서드를 사용하거나 목적에 맞게 재정의할 수 있다.

수업의 Book은 책 번호, 제목, 저자, 가격을 필드로 가진다. 객체를 문자열에 연결하면 `toString()`이 호출된다. 기본 출력은 클래스명과 해시값을 조합한 형태이므로, 필드값이 보이도록 재정의하면 객체 상태를 확인하기 쉽다.

```java
Book book1 = new Book(1, "홍길동전", "허균", 30_000);
System.out.println("book1 = " + book1);
// book1 = Book{number=1, title='홍길동전', author='허균', price=30000}
```

#### 동일성과 동등성

```java
Book book2 = new Book(2, "목민심서", "정약용", 30_000);
Book book3 = new Book(2, "목민심서", "정약용", 30_000);

System.out.println(book2 == book3);      // false
System.out.println(book2.equals(book3)); // true
```

| 비교 방식                  | 확인하는 내용          | 수업 예제의 결과          |
| -------------------------- | ---------------------- | ------------------------- |
| 참조형의 `==`              | 같은 객체를 가리키는가 | 별도로 생성했으므로 false |
| Object의 기본 `equals()`   | 같은 객체를 가리키는가 | 재정의하지 않았다면 false |
| Book이 재정의한 `equals()` | 책의 필드값이 같은가   | 네 필드가 같으므로 true   |

수업의 Book은 다음처럼 비교 기준을 정의했다.

```java
@Override
public boolean equals(Object o) {
    if (o == null || getClass() != o.getClass()) return false;
    Book book = (Book) o;
    return number == book.number
        && price == book.price
        && Objects.equals(title, book.title)
        && Objects.equals(author, book.author);
}

@Override
public int hashCode() {
    return Objects.hash(number, title, author, price);
}
```

null과 다른 클래스의 객체를 먼저 제외하고, 기본형 필드는 `==`, 문자열 필드는 `Objects.equals()`로 비교한다. `Objects.equals()`는 null도 처리한다.

`hashCode()`는 해시 기반 컬렉션에서 객체를 찾는 데 사용되는 값이다. **equals가 true인 두 객체는 같은 해시값을 반환해야 하므로**, 수업에서는 같은 필드를 기준으로 두 메서드를 함께 재정의했다. 해시값이 같다는 사실만으로 동등한 객체라고 판단할 수는 없다.

### String의 비교와 문자열 처리

String은 **불변 객체**다. 문자열을 가공하는 메서드는 원본의 내용을 바꾸는 대신 결과 문자열을 반환하므로, 필요한 결과를 변수에 받아 사용한다.

#### 생성 방식과 내용 비교

```java
String str1 = "java";
String str2 = "java";
String str3 = new String("java");
String str4 = new String("java");

System.out.println(str1 == str2);      // true
System.out.println(str3 == str4);      // false
System.out.println(str3.equals(str4)); // true

str2 += " mysql";
System.out.println(str1); // java
System.out.println(str2); // java mysql
```

같은 리터럴은 문자열 풀의 객체를 재사용하지만, `new String(...)`은 새로운 객체를 생성한다. String은 내용을 비교하도록 `equals()`를 재정의했으므로 **문자열의 내용 비교에는 equals를 사용한다.**

`str2 += " mysql"`은 원래 객체를 수정하는 것이 아니다. 연결 결과를 str2에 다시 대입하므로 str1은 여전히 `"java"`를 가리킨다.

```java
String input = null;
System.out.println("java".equals(input)); // false
// input.equals("java"); // NullPointerException
```

입력이 null일 수 있을 때는 null이 아닌 문자열 쪽에서 `equals()`를 호출할 수 있다.

#### 상품 정보 가공

```java
String rawData = "    [PROD-001] Apple iPhone 16 Pro | a17 bionic | 2500000    ";
String trimmedData = rawData.trim();
String upperData = trimmedData.toUpperCase();

int opening = upperData.indexOf('[');
int codeEnd = upperData.indexOf(']');
String productCode = upperData.substring(opening + 1, codeEnd);
System.out.println(productCode); // PROD-001

String replacedName = upperData.replace("IPHONE 16 PRO", "GALAXY S26");
```

| 메서드                            | 역할과 확인할 점                        |
| --------------------------------- | --------------------------------------- |
| `trim()`                          | 앞뒤 공백 제거                          |
| `toUpperCase()` / `toLowerCase()` | 대문자 / 소문자 변환                    |
| `indexOf(...)`                    | 처음 발견한 위치 반환. 없으면 -1        |
| `substring(start, end)`           | start부터 end 직전까지 추출             |
| `replace(...)`                    | 지정한 문자나 문자열을 치환한 결과 반환 |
| `split(...)`                      | 구분자를 기준으로 문자열 배열 반환      |
| `isEmpty()`                       | 문자열 길이가 0인지 확인                |

코드에서는 여는 괄호 다음 위치부터 닫는 괄호 직전까지 잘라 상품 코드를 얻는다. 이 예시는 입력에 괄호가 있는 상황을 전제로 한다.

#### 분리와 이스케이프

`"100/홍길동/서울//교육부".split("/")`의 결과에는 연속된 구분자 사이에 빈 문자열이 들어간다. 수업에서는 각 요소의 `isEmpty()`를 검사해 `"정보 없음"`을 출력했다.

`split()`의 구분자는 정규식으로 해석된다. 점 자체를 구분자로 쓰려면 다음처럼 작성한다.

```java
String fileName = "report.final.pdf";
String[] parts = fileName.split("\\.");
// report, final, pdf
```

자바 문자열의 `\\`는 역슬래시 한 개를 나타내므로, 정규식에는 `\.`이 전달되어 실제 점을 찾는다. 수업에서 함께 확인한 이스케이프 문자는 `\n`(줄바꿈), `\t`(탭), `\"`(쌍따옴표), `\\`(역슬래시)다.

### StringBuilder로 문자열 조립

String의 내용을 반복해서 연결하면 연결 결과를 새 문자열로 만드는 작업이 반복된다. StringBuilder는 내부 내용을 변경할 수 있는 **가변 객체**이므로 반복적인 조립에 적합하다.

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);
}
String result = sb.toString();
System.out.println(result.length()); // 38890
```

수업에서는 같은 반복을 `str += i`와 `sb.append(i)`로 수행하고, `System.nanoTime()`의 시작·종료 차이로 걸린 시간을 비교했다. 두 결과의 길이는 같지만 조립 방식이 다르다. 실행 시간은 환경에 따라 달라지므로 특정 수치를 고정된 성능 차이로 외우지 않는다.

| String                              | StringBuilder                               |
| ----------------------------------- | ------------------------------------------- |
| 불변 객체                           | 가변 객체                                   |
| 연결 결과를 문자열 변수에 다시 대입 | `append()` 등으로 내부 내용을 변경          |
| 문자열 자체를 표현                  | 반복 조립 후 `toString()`으로 문자열을 얻음 |

```java
StringBuilder sb2 = new StringBuilder("javamysql");
System.out.println(sb2.delete(4, 9));  // java
System.out.println(sb2.insert(0, "my")); // myjava
System.out.println(sb2.reverse());    // avajym

StringBuilder query = new StringBuilder();
query.append("SELECT ").append("* ").append("FROM product ")
     .append("WHERE price > ").append(10_000);
String sql = query.toString();
// SELECT * FROM product WHERE price > 10000
```

`delete(start, end)`는 end 직전까지 삭제하고, `insert()`는 지정 위치에 삽입하며, `reverse()`는 순서를 뒤집는다. 위 세 호출은 같은 sb2의 내용을 차례로 바꾼다. `append()`가 자기 자신을 반환하므로 메서드를 연속해서 호출하는 체이닝도 가능하다.

### Wrapper와 자료형 변환

Wrapper는 기본 자료형의 값을 객체 형태로 다룰 수 있게 하는 클래스다. 대표적으로 int에는 Integer, double에는 Double을 사용한다. 문자열과 숫자 사이의 변환에도 관련 메서드를 활용한다.

```java
String heightStr = "175.5";
String weightStr = "69.3";
System.out.println(heightStr + weightStr); // 175.569.3

double height = Double.parseDouble(heightStr);
double weight = Double.parseDouble(weightStr);
double bmi = weight / ((height / 100) * (height / 100));
String bmiStr = String.valueOf(bmi);
```

문자열끼리 `+`를 하면 이어 붙이므로 계산 전에 숫자로 파싱해야 한다. `Double.parseDouble()`은 double을 반환하는 static 메서드이고, 반대로 숫자를 문자열로 만들 때는 `String.valueOf()`를 사용할 수 있다.

```java
Integer age = 20;     // 자동 박싱
int unboxedAge = age; // 자동 언박싱

Integer nullableAge = null;
// int dangerAge = nullableAge; // NullPointerException

Integer num1 = 128;
Integer num2 = 128;
System.out.println(num1.equals(num2)); // true
```

| 구분   | 변환 방향                   |
| ------ | --------------------------- |
| 파싱   | 문자열 → 원하는 숫자 자료형 |
| 박싱   | 기본형 값 → Wrapper 객체    |
| 언박싱 | Wrapper 객체 → 기본형 값    |

**Wrapper 참조 변수에는 null을 저장할 수 있다.** 강의 주석의 “Wrapper 객체는 null을 가질 수 없다”는 설명은 바로잡아 이해해야 한다. null을 기본형으로 언박싱할 때 문제가 발생하며, 기본형 변수 자체에는 null을 저장할 수 없다.

Wrapper끼리 값을 비교할 때도 `equals()`를 사용한다. `==`는 참조를 비교하므로 객체 재사용 여부에 영향을 받는다. 단, equals를 호출하는 변수 자체가 null이면 예외가 발생하므로 null 가능성을 먼저 확인해야 한다.

### 날짜와 시간 API

| 클래스        | 표현하는 정보 | 수업 예시           |
| ------------- | ------------- | ------------------- |
| LocalDate     | 날짜          | 2026-10-14          |
| LocalTime     | 시간          | 13:48:56            |
| LocalDateTime | 날짜와 시간   | 2026-10-14T13:48:56 |

이 클래스들은 시간대 정보를 포함하지 않는다. 수업에서는 국가별 시간대가 필요하면 ZonedDateTime과 ZoneId를 사용한다고 소개했다.

```java
LocalDate departureDate = LocalDate.of(2026, 10, 14);
LocalTime departureTime = LocalTime.of(13, 48, 56);
LocalDateTime trainDeparture = LocalDateTime.of(departureDate, departureTime);
LocalDateTime now = LocalDateTime.now();

LocalDateTime arrivalDeadline = trainDeparture.minusMinutes(20);
System.out.println(arrivalDeadline); // 2026-10-14T13:28:56
System.out.println(trainDeparture);  // 2026-10-14T13:48:56
```

java.time의 위 객체들은 불변이다. `minusMinutes()`는 원본을 변경하지 않고 계산 결과를 새 객체로 반환하므로, 반환값을 받아 사용한다. `plus...()` 계열도 같은 방식이다.

`getYear()`, `getMonth()`, `getMonthValue()`, `getDayOfWeek()`로 필요한 부분을 얻는다. 예제의 월은 `getMonth()`로 OCTOBER, `getMonthValue()`로 10을 얻는다.

날짜·시간의 앞뒤 관계는 `isBefore()`, `isAfter()`, 같은지는 `isEqual()`로 비교한다. `trainDeparture.isEqual(now)`는 날짜만 같은지 묻는 것이 아니다. now에는 현재의 시·분·초와 나노초까지 들어가므로, 미리 정한 출발 시각과 같은 날짜라는 이유만으로 true가 되지 않는다.

#### 출력과 파싱

```java
DateTimeFormatter formatter =
    DateTimeFormatter.ofPattern("yyyy년 MM월 dd일 HH시 mm분 출발");
String ticket = trainDeparture.format(formatter);
// 2026년 10월 14일 13시 48분 출발

DateTimeFormatter parser = DateTimeFormatter.ofPattern("yyyyMMdd");
LocalDate parsedDate = LocalDate.parse("20261225", parser);
System.out.println(parsedDate); // 2026-12-25
```

`format()`은 날짜·시간을 문자열로, `parse()`는 문자열을 날짜·시간으로 바꾼다. 데이터에 맞는 클래스를 선택하므로 날짜만 있는 문자열은 LocalDate로 파싱했다.

강의의 출력 패턴은 `hh`를 사용했다. `hh`는 12시간제이므로 13시는 01시로 표시된다. 위 예시는 출발 시각을 24시간제로 표시하도록 `HH`로 정리했다. 월은 대문자 `MM`, 분은 소문자 `mm`라는 차이도 구분한다.

### 제네릭과 타입 안전성

제네릭은 클래스나 메서드에서 사용할 타입을 매개변수로 두고, 사용하는 곳에서 구체적인 타입을 지정하는 문법이다. 타입마다 비슷한 클래스를 만들지 않으면서 저장하고 꺼낼 값의 타입을 컴파일 시 확인할 수 있다.

#### Object로 저장하는 경우

수업의 NormalBox는 content 필드를 Object로 선언했다.

```java
NormalBox normalBox = new NormalBox();
normalBox.setContent("안녕하세요");
String content = (String) normalBox.getContent();

normalBox.setContent(123); // 저장 자체는 가능
// String wrong = (String) normalBox.getContent();
// 실행하면 ClassCastException
```

여러 타입을 저장할 수 있지만, 꺼낼 때 Object를 원하는 타입으로 다운캐스팅해야 한다. 숫자를 저장한 뒤 String으로 변환하려는 잘못은 실행 시점에 드러난다.

#### 타입 매개변수 사용

```java
public class GenericBox<T> {
    private T content;

    public T getContent() {
        return this.content;
    }

    public void setContent(T content) {
        this.content = content;
    }
}
```

T는 아직 정해지지 않은 타입을 나타내는 이름이다. 반드시 T로 써야 하는 것은 아니며, 수업에서는 관례적으로 Type의 T, Element의 E, Key의 K, Value의 V를 사용한다고 정리했다.

```java
GenericBox<String> stringBox = new GenericBox<>();
stringBox.setContent("하이");
String strContent = stringBox.getContent(); // 명시적 다운캐스팅 불필요
// stringBox.setContent(123); // 컴파일 오류

GenericBox<Integer> integerBox = new GenericBox<>();
integerBox.setContent(123); // 자동 박싱
int intContent = integerBox.getContent(); // 자동 언박싱
```

`GenericBox<String>`은 저장할 값과 반환할 값의 타입을 String으로 지정한다. 따라서 잘못된 타입을 저장하는 코드를 컴파일 시점에 막고, 값을 꺼낼 때 직접 형변환할 필요가 없다. 생성자 쪽 `<>`는 문맥에서 타입을 추론하게 한다.

타입 인자로는 참조형을 사용하므로 `GenericBox<int>`가 아니라 `GenericBox<Integer>`로 선언한다. 앞서 학습한 Wrapper와 박싱·언박싱이 여기서 연결된다.

### extends로 제네릭 타입 제한

제네릭에 어떤 참조형이든 허용하는 대신, 특정 클래스와 그 자식만 받도록 제한할 수 있다. 수업의 상속·구현 관계는 다음과 같다.

```text
Animal (인터페이스)
├─ Mammal (implements Animal)
│  └─ Rabbit
│     └─ Bunny
│        └─ DrunkenBunny
└─ Reptile (implements Animal)
   └─ Snake
```

토끼 농장은 Rabbit 계열만 다루므로 타입 매개변수에 상한을 둔다.

```java
public class RabbitFarm<T extends Rabbit> {
    private T animal;

    public RabbitFarm(T animal) {
        this.animal = animal;
    }

    public T getAnimal() {
        return animal;
    }

    public void setAnimal(T animal) {
        this.animal = animal;
    }
}
```

위 코드는 수업 클래스에서 사용하지 않는 기본 생성자를 생략한 것이다. `T extends Rabbit`은 **Rabbit 또는 Rabbit의 하위 타입만 T로 지정할 수 있다**는 의미다.

```java
RabbitFarm<Rabbit> farm1 = new RabbitFarm<>(new Rabbit());
RabbitFarm<Bunny> farm2 = new RabbitFarm<>(new Bunny());
RabbitFarm<DrunkenBunny> farm3 = new RabbitFarm<>(new DrunkenBunny());

Rabbit rabbit = farm1.getAnimal();
Bunny bunny = farm2.getAnimal();
DrunkenBunny drunkenBunny = farm3.getAnimal();

rabbit.cry();       // Rabbit가 운다.
bunny.cry();        // Bunny가 운다.
drunkenBunny.cry(); // DrunkenBunny가 운다.

// RabbitFarm<Snake> farm4 = new RabbitFarm<>(); // 타입 제한 위반
```

Snake도 Animal 계열이지만 Rabbit의 하위 타입은 아니므로 사용할 수 없다. 반대로 Bunny와 DrunkenBunny는 Rabbit을 상속하므로 허용된다.

타입 인자를 Bunny로 지정한 farm2의 `getAnimal()`은 Bunny 타입으로 사용할 수 있고, 실제 Bunny 객체가 재정의한 `cry()`를 실행한다. **제네릭의 타입 지정으로 저장·반환 타입을 확인하고, 오버라이딩으로 실제 객체의 동작을 실행한다.**
