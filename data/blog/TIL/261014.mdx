Java의 기본 API는 객체 비교, 문자열 가공, 숫자 변환, 날짜 계산 같은 반복 작업을 제공한다. 메서드 이름만 기억하기보다 원본을 바꾸는지와 반환값이 무엇인지 확인해야 결과를 올바르게 사용할 수 있다.

## ☘️ 같은 객체와 같은 값의 구분

참조의 ==는 같은 객체를 가리키는지 비교한다. equals는 클래스가 정한 값의 동등성을 비교할 수 있다. 책 번호와 제목이 같으면 같은 책으로 취급하려면 그 기준으로 equals를 구현한다. hashCode도 같은 기준에 맞춰야 해시 기반 컬렉션이 일관되게 동작한다.

toString은 객체를 읽기 쉬운 문자열로 표현하는 방법이다. 출력 형태를 바꾸는 것과 equals의 비교 기준을 바꾸는 것은 별개다. 아래 Book은 서로 다른 객체의 참조 비교와 값 비교를 함께 보여 준다.

## ☘️ 문자열 읽기와 조립

String은 내용을 바꾸는 메서드를 호출한 것처럼 보여도 대개 새 문자열을 반환한다. substring은 위치 범위의 일부, split은 구분자로 나눈 배열, replace는 교체한 문자열을 만든다. 시작 위치는 포함하고 끝 위치는 제외하는 범위를 사용하는 메서드가 있으므로 경계를 확인한다.

trim은 양끝의 공백을 다듬고 대소문자 변환은 새 결과를 만든다. 반환값을 받지 않으면 기존 변수는 그대로다. StringBuilder는 내부 내용을 바꾸며 append·insert·delete·reverse로 조립한 뒤 toString으로 문자열을 얻는다. 여러 번 이어 붙이는 작업과 이미 완성된 문자열을 다루는 작업을 구분한다.

Wrapper는 기본형 값을 객체로 다룰 수 있게 한다. parseInt 같은 메서드는 문자열을 숫자로 해석하며 형식이 맞지 않으면 예외가 발생한다. 문자열 연결과 숫자 계산을 하기 전에 필요한 타입으로 변환한다.

## ☘️ 날짜와 제네릭

LocalDate는 날짜, LocalTime은 시간, LocalDateTime은 날짜와 시간을 표현한다. plus·minus 계열은 계산한 새 값을 반환한다. DateTimeFormatter는 표시 형식을 정한다. 날짜 계산과 문자열 표시를 나누면 시간 값을 단순 문자열로 잘못 계산하는 일을 줄일 수 있다.

제네릭의 타입 매개변수 T는 사용할 때 구체 타입으로 정하는 자리다. `GenericBox<String>`이면 저장과 조회 타입이 String으로 연결된다. Object에 아무 값이나 넣고 매번 형변환하는 방식보다 타입 오류를 컴파일 단계에서 찾기 쉽다. extends 제한은 받을 수 있는 타입의 범위를 정하며, 제한된 공통 기능만 안전하게 사용할 수 있다.

## ☘️ 문자열·동등성·날짜·제네릭의 실행

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.LocalTime;
import java.time.format.DateTimeFormatter;
import java.util.Objects;

public class Main {
  public static void main(String[] args) {
    Book first = new Book(1, "홍길동전"), second = new Book(1, "홍길동전");
    System.out.println((first == second) + " / " + first.equals(second));
    System.out.println(first);
    String raw = "    [PROD-001] Apple iPhone 16 Pro | a17 bionic | 2500000    ";
    String text = raw.trim().toUpperCase();
    System.out.println(text.substring(text.indexOf('[') + 1, text.indexOf(']')));
    System.out.println(text.replace("IPHONE 16 PRO", "GALAXY S26"));
    String original = "java", changed = original;
    changed += " mysql";
    System.out.println(original + " / " + changed);
    for (String part : "100/사용자/서울//교육부".split("/"))
      System.out.print((part.isEmpty() ? "정보 없음" : part) + "|");
    System.out.println();
    System.out.println("report.final.pdf".split("\\.").length);
    StringBuilder builder = new StringBuilder("javamysql");
    builder.delete(4, 9).insert(0, "my");
    System.out.println(builder.reverse().toString());
    double height = Double.parseDouble("175.5"), weight = Double.parseDouble("69.3");
    System.out.println(Math.round(weight / ((height / 100) * (height / 100))));
    Integer boxed = 20;
    int unboxed = boxed;
    System.out.println(String.valueOf(unboxed));
    LocalDateTime departure =
        LocalDateTime.of(LocalDate.of(2026, 10, 14), LocalTime.of(13, 48, 56));
    DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm");
    System.out.println(departure.format(formatter));
    System.out.println(departure.minusMinutes(20).format(formatter));
    System.out.println(LocalDate.parse("20261225", DateTimeFormatter.ofPattern("yyyyMMdd")));
    GenericBox<String> box = new GenericBox<>();
    box.setContent("하이");
    System.out.println(box.getContent());
    RabbitFarm<Bunny> farm = new RabbitFarm<>(new Bunny());
    farm.getAnimal().cry();
  }
}

class Book {
  private final int number;
  private final String title;

  Book(int number, String title) {
    this.number = number;
    this.title = title;
  }

  @Override
  public String toString() {
    return number + ": " + title;
  }

  @Override
  public boolean equals(Object other) {
    if (!(other instanceof Book book)) return false;
    return number == book.number && Objects.equals(title, book.title);
  }

  @Override
  public int hashCode() {
    return Objects.hash(number, title);
  }
}

class GenericBox<T> {
  private T content;

  void setContent(T value) {
    content = value;
  }

  T getContent() {
    return content;
  }
}

class Rabbit {
  void cry() {
    System.out.println("Rabbit");
  }
}

class Bunny extends Rabbit {
  @Override
  void cry() {
    System.out.println("Bunny");
  }
}

class RabbitFarm<T extends Rabbit> {
  private final T animal;

  RabbitFarm(T animal) {
    this.animal = animal;
  }

  T getAnimal() {
    return animal;
  }
}
```

equals는 두 객체를 같은 값으로 볼 기준을 정하고 hashCode는 그 기준과 일치해야 한다. 같은 책으로 판단되는 객체의 해시 값도 같도록 두 메서드를 함께 구현했다. String의 변환 메서드는 새 문자열을 반환하므로 반환값을 받지 않으면 원래 변수는 그대로다. StringBuilder는 내부 내용을 바꾸며 여러 번 연결한 뒤 toString으로 문자열을 얻는다. Wrapper의 parse 메서드는 문자열을 기본형 값으로 읽으며 잘못된 형식은 예외가 될 수 있다. 날짜는 현재 시각 대신 고정값을 사용한다. `GenericBox<T>`는 저장할 타입을 선언 시 정해 꺼낼 때 불필요한 형 변환을 줄인다.
