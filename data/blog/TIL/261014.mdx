## ☘️ 객체와 문자열

API는 제공된 클래스·메서드를 사용하는 규칙이다. 모든 Java 클래스는 직접·간접으로 Object를 상속한다.

- toString: 기본 클래스명·해시 표현 대신 필드 상태를 보이도록 재정의. 객체를 문자열에 연결할 때도 호출
- 참조형 ==: 같은 객체인지 / Object 기본 equals도 동일성 비교
- Book의 재정의 equals: 번호·제목·저자·가격이 같으면 true. null·다른 클래스 제외 후 기본형은 ==, 문자열은 Objects.equals로 null까지 처리
- equals가 true인 객체는 같은 hashCode 필요. 두 메서드를 같은 필드 기준으로 재정의. 해시값 같음만으로 동등하지는 않음

**String은 불변**이다. 같은 리터럴은 풀에서 재사용하지만 new String은 새 객체다. 내용 비교는 equals, null 가능 입력은 `"JAVA".equals(input)`처럼 호출한다. str2 += " mysql"은 새 결과를 재대입하므로 함께 가리키던 str1은 유지된다.

- trim: 앞뒤 공백 / toUpperCase·toLowerCase: 대소문자
- indexOf: 처음 위치, 없으면 -1 / substring(start,end): end 직전까지
- replace: 치환 결과 / split: 구분자로 문자열 배열 / isEmpty: 길이 0
- 상품 코드: 여는 괄호 indexOf+1부터 닫는 괄호 직전 substring. 괄호가 있다는 전제
- `"100/홍길동/서울//교육부".split("/")`: 연속 구분자 사이 빈 문자열은 isEmpty로 검사해 정보 없음 표시
- split 구분자는 정규식. 점 자체는 `split("\\.")`로 분리. Java의 `\`가 정규식의 역슬래시 하나가 됨
- 이스케이프: `\n` 줄바꿈, `\t` 탭, `\"` 따옴표, `\` 역슬래시

**StringBuilder는 가변**이라 반복 조립에 적합하다. append는 자신을 반환해 체이닝 가능, toString으로 최종 문자열을 얻는다. delete(start,end)는 end 직전 삭제, insert는 삽입, reverse는 역순이다. 같은 객체 내용이 바뀐다.

실습은 str += i와 append를 nanoTime 차이로 비교했다. 길이가 같아도 조립 방식은 다르며 실행 시간은 환경에 따라 달라 고정 수치로 외우지 않는다.

## ☘️ Wrapper와 시간

- Wrapper: int→Integer, double→Double처럼 기본형을 객체로 다룸
- 파싱: 문자열→숫자. Integer.parseInt·Double.parseDouble은 static이며 기본형 반환
- 문자열끼리 +는 연결이므로 계산 전 파싱. 숫자→문자열은 String.valueOf
- 박싱: 기본형→Wrapper / 언박싱: Wrapper→기본형. 자동 변환도 가능
- Wrapper 참조는 null 가능. **null 언박싱에서 예외**, 기본형은 null 저장 불가. 강의의 반대 주석은 오류
- Wrapper 값은 equals로 비교하되 호출 변수 null 확인. ==는 참조라 객체 재사용 영향을 받음

**java.time**: LocalDate는 날짜, LocalTime은 시간, LocalDateTime은 둘 다. 시간대는 없으며 필요한 경우 ZonedDateTime·ZoneId 사용을 소개했다.

- 불변이라 plus/minus 계산 결과를 받아야 함. minusMinutes 호출만으로 원본 변경 안 됨
- getYear, getMonth(OCTOBER), getMonthValue(10), getDayOfWeek로 일부 추출
- isBefore·isAfter·isEqual로 앞뒤·동일 시각 비교. 같은 날짜여도 현재 시각의 초·나노초까지 다르면 동일하지 않음
- format: 날짜·시간→문자열 / parse: 문자열→해당 날짜·시간 타입
- DateTimeFormatter 패턴: **HH 24시간 / hh 12시간 / MM 월 / mm 분**. 수업의 hh는 13시를 01시로 보여 HH로 정리

```java
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm");
String text = departure.format(formatter);
LocalDate date = LocalDate.parse("2026-10-14");
```

## ☘️ 타입 안전성과 제한

NormalBox의 Object는 어떤 값도 저장하지만 꺼낼 때 캐스트해야 하며, 숫자를 String으로 잘못 변환하면 **실행 때** 실패한다.

```java
class GenericBox<T> {
    private T content;
    public void setContent(T content) { this.content = content; }
    public T getContent() { return content; }
}
GenericBox<String> box = new GenericBox<>();
box.setContent("문자열");
String text = box.getContent(); // 캐스트 불필요
```

제네릭은 타입을 매개변수화해 재사용하며 잘못된 저장을 **컴파일 때** 막는다. T(Type)·E(Element)·K(Key)·V(Value)는 관례 이름이다. 생성자의 &lt;&gt;는 타입 추론, 타입 인자는 참조형이므로 int 대신 Integer를 쓴다.

`RabbitFarm<T extends Rabbit>`은 Rabbit·그 하위 타입만 받는다. Bunny·DrunkenBunny는 가능, 같은 Animal 계열이어도 Rabbit 하위가 아닌 Snake는 불가다. 수업에서는 Mammal이 Animal 인터페이스를 구현하고 Rabbit이 Mammal을 상속한다.

Bunny로 지정하면 getAnimal 결과도 Bunny로 다루며 실제 Bunny의 cry가 실행된다. **제네릭은 저장·반환 타입, 오버라이딩은 실제 동작**을 정한다.
