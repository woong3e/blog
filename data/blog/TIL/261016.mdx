예외 처리는 실패했을 때 어떤 안내를 하고 어디까지 이어갈지 정하는 과정이다. 파일 입출력에서는 실패 처리와 함께 열어 둔 자원을 닫는 일도 필요하다. 문자 인코딩과 스트림의 종류를 맞춰야 저장한 내용을 다시 읽을 수 있다.

## ☘️ 예외 발생과 처리 후 흐름

throw는 예외를 실제로 발생시키고 throws는 메서드가 그 예외를 호출자에게 전달할 수 있음을 선언한다. try에서 예외가 나면 나머지 문장을 건너뛰고 해당 타입을 처리하는 catch로 이동한다. 더 구체적인 예외를 앞에서 잡아야 뒤의 처리 순서가 의미를 가진다.

finally는 정상·실패와 관계없이 마무리할 작업에 사용한다. 예외를 잡아 처리하면 이후 코드로 이어갈 수 있지만 다시 던지면 호출자에게 전달된다. 사용자 정의 예외는 실패의 의미를 이름과 메시지로 표현하는 방법이다.

## ☘️ 파일과 스트림의 역할

파일 경로를 나타내는 객체를 만든다고 실제 파일 내용이 생기지는 않는다. 디렉터리 생성·파일 쓰기·읽기는 각각 수행해야 한다. InputStream과 OutputStream은 바이트, Reader와 Writer는 문자를 다룬다. 텍스트를 바이트로 저장하고 다시 읽을 때 인코딩이 같아야 한글이 깨지지 않는다.

버퍼는 작은 단위로 반복하는 입출력을 모아 처리한다. BufferedReader의 readLine은 줄 끝 표시를 제외한 한 줄을 반환하며 더 읽을 내용이 없으면 null이다. 반복 종료 조건을 빈 문자열과 혼동하지 않는다.

try-with-resources는 AutoCloseable 자원을 작업 후 닫는다. 중간에 예외가 나도 닫는 흐름이 적용된다. 아래 예제는 독립된 임시 폴더에서 UTF-8 파일을 쓰고 읽은 뒤 자신이 만든 파일을 정리한다.

## ☘️ 설정 파일과 enum

Properties는 문자열 키와 값으로 설정을 저장하고 읽는다. 코드의 동작과 환경별 값을 분리할 때 사용할 수 있다. 파일을 읽는 시점에 키가 없는 경우의 기본값도 고려한다.

enum은 허용할 값의 집합을 타입으로 표현한다. 아무 문자열이나 받는 대신 정해진 상수만 사용하게 한다. 각 상수는 필드와 생성자를 가진 객체가 될 수 있고 name은 상수 이름, 별도 필드는 표시 이름처럼 다른 의미를 담는다. 아래 출력에서 상수가 준비되는 시점과 특정 값을 사용하는 시점을 나누어 확인한다.

## ☘️ 예외 처리·파일 자원·enum 초기화

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.io.Reader;
import java.io.Writer;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.Properties;

public class Main {
  public static void main(String[] args) throws Exception {
    try {
      checkEnoughMoney(30000, 5000);
    } catch (PriceNegativeException e) {
      System.out.println("가격 오류: " + e.getMessage());
    } catch (MoneyNegativeException e) {
      System.out.println("보유금 오류: " + e.getMessage());
    } catch (NotEnoughMoneyException e) {
      System.out.println("잔액 부족: " + e.getMessage());
    } finally {
      System.out.println("구매 검사 종료");
    }
    Path directory = Files.createTempDirectory("til-io-");
    Path textFile = directory.resolve("message.txt");
    try (BufferedWriter writer =
        new BufferedWriter(
            new OutputStreamWriter(Files.newOutputStream(textFile), StandardCharsets.UTF_8))) {
      writer.write("하이");
      writer.newLine();
      writer.write("반가워");
    }
    try (BufferedReader reader =
        new BufferedReader(
            new InputStreamReader(Files.newInputStream(textFile), StandardCharsets.UTF_8))) {
      String line;
      while ((line = reader.readLine()) != null) System.out.println(line);
    }
    Properties settings = new Properties();
    settings.setProperty("app.name", "fullstack-course");
    settings.setProperty("app.language", "ko");
    Path settingsFile = directory.resolve("application.properties");
    try (Writer writer = Files.newBufferedWriter(settingsFile, StandardCharsets.UTF_8)) {
      settings.store(writer, "settings");
    }
    Properties loaded = new Properties();
    try (Reader reader = Files.newBufferedReader(settingsFile, StandardCharsets.UTF_8)) {
      loaded.load(reader);
    }
    System.out.println(loaded.getProperty("app.name"));
    for (Subjects subject : Subjects.values())
      System.out.print((subject.ordinal() + 1) + "." + subject.name() + " ");
    System.out.println();
    UserRole admin = UserRole.ADMIN;
    UserRole guest = UserRole.GUEST;
    System.out.println(admin.getDescription() + " / " + guest.name());
    Files.delete(textFile);
    Files.delete(settingsFile);
    Files.delete(directory);
  }

  static void checkEnoughMoney(int price, int money)
      throws PriceNegativeException, MoneyNegativeException, NotEnoughMoneyException {
    if (price < 0) throw new PriceNegativeException("가격 음수");
    if (money < 0) throw new MoneyNegativeException("보유금 음수");
    if (money < price) throw new NotEnoughMoneyException("돈이 부족합니다.");
    System.out.println("구매 가능");
  }
}

class PriceNegativeException extends Exception {
  PriceNegativeException(String message) {
    super(message);
  }
}

class MoneyNegativeException extends Exception {
  MoneyNegativeException(String message) {
    super(message);
  }
}

class NotEnoughMoneyException extends Exception {
  NotEnoughMoneyException(String message) {
    super(message);
  }
}

enum Subjects {
  JAVA,
  MYSQL,
  JDBC,
  HTML,
  CSS
}

enum UserRole {
  GUEST("게스트"),
  CONSUMER("구매자"),
  PRODUCER("판매자"),
  ADMIN("관리자");
  private final String description;

  UserRole(String description) {
    this.description = description;
    System.out.println("생성: " + description);
  }

  String getDescription() {
    return description;
  }
}
```

try에서 예외가 나면 맞는 catch로 이동하고 finally는 정상 여부와 관계없이 실행된다. try-with-resources는 작업이 끝날 때 스트림을 닫는다. 문자를 파일에 쓸 때와 읽을 때 모두 UTF-8을 지정해 인코딩을 맞춘다. 버퍼는 작은 단위의 잦은 입출력을 완화하고 Properties는 이름과 값 형태의 설정을 저장한다. 예제는 새 임시 폴더 안에만 파일을 만들고 사용한 파일을 정리한다. enum 상수는 미리 정해진 객체들이며 초기화 시점의 출력과 이후 값을 사용하는 출력을 나누어 읽는다.

**실행 방법**

JDK 21 환경에서 파일명을 `Main.java`로 저장한다. 같은 폴더에서 `javac -encoding UTF-8 Main.java`로 컴파일한 뒤 `java -Dfile.encoding=UTF-8 Main`을 실행한다. 글마다 Main 클래스가 있으므로 예제는 서로 다른 폴더에 저장한다.
