Java 프로그램은 값을 정해진 자료형으로 보관하고 메서드를 호출하며 실행된다. 자료형은 저장 공간뿐 아니라 가능한 값의 범위와 연산 결과에도 영향을 준다. 코드를 읽을 때 최종 대입 변수의 타입보다 계산이 일어나는 순간의 타입을 먼저 확인한다.

## ☘️ 변수와 자료형

변수 선언은 자료형과 이름을 정하는 과정이고 초기화는 처음 값을 넣는 과정이다. 기본형에는 정수 byte·short·int·long, 실수 float·double, 문자 char, 논리 boolean이 있다. String은 여러 문자를 다루는 클래스이며 char와 다르다. 작은따옴표는 문자 하나, 큰따옴표는 문자열에 사용한다.

final은 한 번 정한 값을 다시 대입하지 못하게 한다. 상수로 사용할 값은 의미를 드러내는 이름을 붙이면 숫자만 반복하는 것보다 조건의 목적을 이해하기 쉽다. 변수 이름은 대소문자를 구분하며 같은 범위에 중복 선언할 수 없다.

## ☘️ 범위와 형변환이 계산에 미치는 영향

byte는 -128부터 127까지 표현한다. 이 범위를 넘는 연산은 원하는 큰 숫자를 보관하지 못하고 반대쪽 값으로 돌아갈 수 있다. 이런 범위 초과를 오버플로라고 한다. 큰 곱셈의 결과를 long 변수에 넣더라도 두 피연산자가 int이면 곱셈 자체가 먼저 int로 계산될 수 있다. 아래 코드는 곱하기 전에 하나를 long으로 바꾼다.

명시적 형변환은 괄호에 목표 타입을 적는다. 실수를 정수로 바꾸면 소수 부분이 버려지며 반올림하지 않는다. char끼리 더하면 글자 연결이 아니라 문자 코드의 정수 합이 된다. 반면 +의 피연산자에 String이 들어오면 문자열 연결이 된다. 연산이 왼쪽에서 진행되는 순서도 결과에 영향을 준다.

정수끼리 나누면 정수 몫을 얻는다. &&와 ||는 조건을 판단하는 데 필요하지 않은 오른쪽 식을 실행하지 않는다. 오른쪽에 증감이 있으면 변수의 최종값까지 달라지므로 단축 평가를 함께 추적한다. 문자열 내용 비교는 ==로 참조를 비교하는 대신 equals를 사용한다.

## ☘️ 메서드에 값을 전달하고 돌아오기

메서드는 처리할 작업을 이름으로 묶는다. 매개변수는 호출자가 넘긴 인수를 받고 return은 결과를 호출 위치에 돌려준다. void는 반환값이 없다는 뜻이다. 출력하는 것과 반환하는 것은 다르며 반환값은 다음 계산에 사용할 수 있다.

인스턴스 메서드는 객체를 만든 뒤 호출한다. static 메서드는 클래스에 속해 클래스 이름으로 호출할 수 있다. 아래 Calculator는 같은 비교 작업을 두 방식으로 보여 준다. A가 B를, B가 C를 호출하면 C가 끝난 뒤 B의 남은 문장, A의 남은 문장을 실행한다. 호출한 위치로 돌아온다는 점이 실행 순서의 핵심이다.

## ☘️ 자료형·연산·메서드 호출을 한 번에 추적하기

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
public class Main {
  static final int MAX_AGE = 20;

  public static void main(String[] args) {
    byte maximum = 127;
    maximum++;
    byte minimum = -128;
    minimum--;
    System.out.println(maximum + " / " + minimum);
    int firstNum = 1_000_000, secondNum = 700_000;
    System.out.println((long) firstNum * secondNum);
    System.out.println((int) 4.9);
    System.out.println('a' + 'b');
    System.out.println(9 + 9 + "9");
    System.out.println(10 / 3);
    int number = 10;
    boolean result = false && ++number > 0;
    System.out.println(result + " / " + number);
    System.out.println(MAX_AGE >= 20 ? "성인" : "미성년자");
    System.out.println("JAVA".equals(new String("JAVA")));
    Calculator calculator = new Calculator();
    System.out.println(calculator.minNumberOf(10, 20));
    System.out.println(Calculator.maxNumberOf(10, 20));
    System.out.println(createString("예제 사용자", MAX_AGE));
    methodA();
  }

  static String createString(String name, int age) {
    return name + ": " + age;
  }

  static void methodA() {
    System.out.println("A 시작");
    methodB();
    System.out.println("A 종료");
  }

  static void methodB() {
    System.out.println("B 시작");
    methodC();
    System.out.println("B 종료");
  }

  static void methodC() {
    System.out.println("C 실행");
  }
}

class Calculator {
  int minNumberOf(int first, int second) {
    return first < second ? first : second;
  }

  static int maxNumberOf(int first, int second) {
    return first > second ? first : second;
  }
}
```

byte는 127 다음이 -128, -128 이전이 127로 돌아간다. 곱셈 전에 첫 피연산자를 long으로 바꿔야 중간 결과도 long 범위에서 계산한다. 실수 4.9를 int로 바꾸면 소수 부분이 버려지고, 문자끼리 더하면 문자 코드의 정수 합이 된다. false && 오른쪽 식은 실행하지 않으므로 number는 10이다. minNumberOf는 객체를 통해, maxNumberOf는 클래스 이름으로 호출한다. A가 B를, B가 C를 호출한 뒤에는 C에서 B, A 순서로 돌아와 남은 문장을 실행한다.
