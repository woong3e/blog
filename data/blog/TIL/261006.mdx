# 🍀 Java 기초: 값과 변수부터 메서드와 패키지까지

오늘은 Java 프로그램에서 값을 표현하고 다루는 방법부터 연산자, 메서드, 패키지까지 기초 문법을 학습했다. 각 개념이 따로 보이지만, 값을 변수에 담고 자료형에 맞게 연산한 뒤 메서드로 동작을 나누어 사용하는 흐름으로 연결된다.

## 🍀 리터럴과 자료형

**리터럴(literal)**은 코드에 직접 적는 값이다. Java에서는 정수 `123`, 실수 `1.23`, 문자 `'a'`, 문자열 `"abc"`, 논리값 `true`와 `false`처럼 값의 종류를 구분한다.

문자 하나는 작은따옴표로 감싸고, 문자열은 큰따옴표로 감싼다. 문자 리터럴에는 문자 하나만 들어갈 수 있으므로 `'abc'`나 `''`는 올바른 문자 리터럴이 아니다.

```java
char letter = 'a';
String word = "abc";
boolean isReady = true;
```

기본 숫자 자료형은 크기와 표현 범위에 따라 정수형 `byte`, `short`, `int`, `long`, 실수형 `float`, `double`로 나뉜다. 문자형은 `char`, 논리형은 `boolean`을 사용한다. 문자열을 저장하는 `String`은 기본 자료형이 아니라 Java가 제공하는 클래스형 자료형이다.

문자도 내부적으로 정수 값으로 표현되므로 문자끼리 더하면 문자의 코드 값이 계산된다. 문자열에 `+`를 사용하면 이어 붙이며, 문자열과 숫자를 더해도 숫자가 문자열로 변환되어 결합된다. 연산 순서도 결과에 영향을 준다.

```java
System.out.println('a' + 'b'); // 문자 코드 값의 합
System.out.println("a" + "pple"); // apple
System.out.println("hello" + 123); // hello123
System.out.println(9 + 9 + "9"); // 189
```

정수끼리 나누면 소수 부분은 버려진다. 정수와 실수를 함께 연산하면 정수가 실수로 변환되어 실수 결과를 얻는다.

## 🍀 변수와 이름 짓기

변수는 값을 저장하는 메모리 공간이다. 변수를 사용하기 전에 자료형과 이름을 선언하고, 필요하면 선언과 동시에 초기화한다.

```java
int point = 100;
long population = 8_000_000_000L;
double rate = 1.25;
```

같은 범위 안에서 변수 이름은 중복될 수 없고, 예약어를 이름으로 쓸 수 없다. 이름은 숫자로 시작할 수 없으며 대소문자를 구분한다. 특수문자는 `_`와 `$`를 사용할 수 있지만, 일반적인 변수 이름에는 소문자로 시작하는 카멜 케이스를 사용한다. 이름만 보고 의미를 알 수 있도록 `age`, `maxAge`, `isAlive`처럼 목적을 드러내는 편이 좋다. boolean 변수는 `isReady`처럼 긍정형 질문 형태로 지으면 읽기 쉽다.

## 🍀 상수

상수는 한 번 정한 뒤 다시 값을 대입할 수 없는 값이다. 선언 앞에 `final`을 붙이고, 선언 시 초기화하거나 선언 후 한 번 초기화한다.

```java
final int AGE = 20;
```

상수 이름은 관례상 영문 대문자를 사용하고 여러 단어는 밑줄로 연결한다. 예를 들어 `MAX_AGE`처럼 작성한다. 상수는 프로그램에서 변하지 않아야 하는 기준값을 명확하게 나타낼 때 유용하다.

## 🍀 오버플로와 언더플로

정수 자료형이 저장할 수 있는 범위를 벗어난 값이 되면 오버플로 또는 언더플로가 발생한다. `byte`의 범위는 `-128`부터 `127`까지이므로 `127`에서 1을 더하면 순환해 `-128`이 되고, `-128`에서 1을 빼면 `127`이 된다.

```java
byte value = 127;
value++;
System.out.println(value); // -128
```

대입할 변수의 타입만 큰 타입으로 바꿔서는 이미 작은 타입으로 계산되어 넘친 결과를 복구할 수 없다. 곱셈 등의 계산 전에 피연산자 중 하나를 큰 타입으로 변환해야 연산 자체가 그 타입으로 수행된다.

```java
int first = 1_000_000;
int second = 700_000;
long result = (long) first * second;
```

## 🍀 형변환

서로 다른 숫자 자료형을 함께 사용하면 Java는 보통 표현 범위가 넓은 자료형에 맞춰 자동으로 변환한다. 작은 정수형에서 큰 정수형으로, 정수에서 실수로 변환되는 경우가 이에 해당한다.

표현 범위가 큰 타입에서 작은 타입으로 바꾸거나 실수를 정수로 바꾸려면 캐스트 연산자로 **강제 형변환**을 해야 한다.

```java
long source = 8L;
int number = (int) source;

float decimal = 4.9f;
long whole = (long) decimal; // 소수 부분은 버려짐
```

강제 형변환은 값의 범위를 넘기거나 소수 부분을 잃을 수 있으므로 변환 전후의 자료형 범위와 데이터 손실을 확인해야 한다.

## 🍀 연산자

### 산술·대입·증감 연산

산술 연산자는 `+`, `-`, `*`, `/`, `%`다. `%`는 나머지를 구하고, 정수 나눗셈은 소수 부분을 버린다. `+=`, `-=`, `*=`, `/=`, `%=`는 계산 결과를 기존 변수에 다시 대입하는 복합 대입 연산자다.

`++`와 `--`는 값을 1씩 증가·감소시킨다. 변수 앞에 쓰는 전위형은 먼저 값을 바꾸고, 뒤에 쓰는 후위형은 현재 표현식에서 기존 값을 사용한 뒤 바꾼다. 다른 연산과 섞이면 이 차이가 계산 결과에 반영된다.

### 비교 연산과 문자열 비교

`==`, `!=`, `>`, `<`, `>=`, `<=`는 비교 결과로 boolean 값을 만든다. 기본 자료형은 값 자체를 비교한다. 문자열에서 `==`는 같은 객체인지 비교하므로 문자열 내용이 같은지를 확인할 때는 `equals()`를 사용한다.

```java
String first = "JAVA";
String second = new String("JAVA");
System.out.println(first.equals(second)); // true
```

### 논리 연산과 단축 평가

논리 연산자인 `&&`와 `||`는 boolean 값에 사용한다. `&&`는 양쪽이 모두 참일 때 참이고, `||`는 둘 중 하나라도 참이면 참이다. `!`는 논리값을 반대로 바꾼다. Java에서는 숫자나 문자열을 JavaScript처럼 참·거짓으로 자동 판단하지 않는다.

`&&`에서 왼쪽이 거짓이면 오른쪽을 평가할 필요가 없고, `||`에서 왼쪽이 참이면 오른쪽을 평가할 필요가 없다. 이를 **단축 평가**라고 한다. 오른쪽에 증감이나 메서드 호출처럼 상태를 바꾸는 표현식이 있으면 실행 여부를 살펴야 한다.

### 삼항 연산자

삼항 연산자는 조건에 따라 둘 중 하나의 값을 선택한다.

```java
String message = (score >= 60) ? "합격" : "불합격";
```

형식은 `(조건식) ? 참일 때 값 : 거짓일 때 값`이다. 짧은 조건별 값 선택에 사용할 수 있다.

## 🍀 메서드와 호출 흐름

메서드는 특정 작업을 수행하는 명령문 묶음이다. 인스턴스 메서드는 클래스의 객체를 만든 뒤 `객체명.메서드명()`으로 호출한다. 메서드가 다른 메서드를 부르면 호출된 작업이 끝난 뒤 원래 호출 위치로 돌아오므로, 실행 순서를 출력문으로 확인할 수 있다.

메서드를 호출할 때 전달하는 값은 **인자(argument)**이고, 메서드 선언에서 값을 받도록 만든 변수는 **매개변수(parameter)**다. 전달하는 인자의 개수와 순서, 타입은 매개변수 선언과 맞아야 한다.

반환 타입이 `void`이면 호출한 곳에 돌려주는 값이 없다. `String`, `int`처럼 반환 타입을 지정했다면 해당 타입에 맞는 값을 `return`해야 한다. 반환값은 변수에 담거나 다른 메서드의 인자로 곧바로 사용할 수 있다.

```java
public String createMessage() {
    return "Hello";
}

String message = createMessage();
```

## 🍀 인스턴스 메서드와 static 메서드

인스턴스 메서드는 객체마다 사용할 동작으로, 객체를 생성한 뒤 호출한다. `static` 메서드는 특정 객체가 아니라 클래스에 속하므로 객체를 만들지 않고 `클래스명.메서드명()`으로 호출한다. 같은 클래스 안의 static 메서드는 클래스명을 생략할 수 있다.

```java
Calculator calculator = new Calculator();
int min = calculator.minNumberOf(10, 20);
int max = Calculator.maxNumberOf(10, 20);
```

실습에서는 `Calculator`의 최소값 메서드를 인스턴스 메서드로, 최대값 메서드를 static 메서드로 작성했다. static 메서드도 객체 참조로 호출할 수는 있지만, 클래스 이름으로 호출하는 편이 클래스에 속한 기능임을 잘 드러낸다.

## 🍀 패키지와 import

패키지는 관련 클래스를 묶고 클래스 이름이 겹치는 일을 줄인다. 다른 패키지의 클래스를 사용할 때는 패키지를 포함한 전체 이름을 쓰거나 파일 상단에 `import`를 선언할 수 있다.

```java
import com.woong3e.section01.method.Calculator;
```

import한 뒤에는 `Calculator`처럼 짧은 이름으로 클래스를 사용할 수 있다. 다른 패키지의 static 메서드는 보통 `Calculator.maxNumberOf(...)`처럼 클래스 이름을 붙여 호출하면 출처가 분명하다. static 멤버를 직접 import하면 짧게 쓸 수 있지만, 메서드가 어디에서 왔는지 덜 드러날 수 있다.

## 🍀 오늘의 정리

- 리터럴은 코드에 직접 쓴 값이며, 값의 종류에 맞는 자료형으로 다룬다.
- 변수는 값을 저장하고, `final` 상수는 초기화 뒤 다시 대입할 수 없다.
- 자료형 범위를 넘으면 오버플로가 생기며, 큰 타입으로 계산하려면 계산 전에 피연산자를 변환한다.
- 자동 형변환은 표현 범위가 넓은 타입으로 이루어지고, 반대 방향은 캐스트가 필요하며 데이터 손실을 살펴야 한다.
- 연산자는 계산, 비교, 논리 판단, 조건별 값 선택을 표현한다. 문자열 내용 비교에는 `equals()`를 사용한다.
- 인스턴스 메서드는 객체로, static 메서드는 클래스 이름으로 호출한다. 패키지와 import로 클래스를 구조화하고 다른 패키지에서 가져올 수 있다.
