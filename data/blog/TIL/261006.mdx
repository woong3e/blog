## ☘️ 값과 자료형

- 리터럴: 코드에 직접 쓴 값. 정수 123, 실수 1.23, 문자 'a', 문자열 "abc", 논리값 true·false
- `char`는 작은따옴표의 한 문자. `'abc'`, `''`는 불가. String은 큰따옴표이며 기본형이 아닌 클래스
- 기본형: 정수 byte·short·int·long / 실수 float·double / 문자 char / 논리 boolean
- 변수: 타입·이름 선언 후 초기화. `long population = 8_000_000_000L;`
- 이름: 같은 범위 중복·예약어·숫자 시작 불가, 대소문자 구분. `_`, `$` 사용 가능. 카멜 케이스, boolean은 isReady 같은 긍정형 권장
- `final int MAX_AGE = 20;`: 한 번 초기화한 뒤 재대입 불가. 선언 후 한 번 초기화도 가능. 상수명은 대문자·밑줄

**오버플로·형변환**

byte는 -128~127이라 127에서 증가하면 -128, -128에서 감소하면 127로 순환한다. 결과를 long에 담아도 int 계산 중 넘친 값은 복구되지 않는다.

```java
int first = 1_000_000, second = 700_000;
long result = (long) first * second; // 연산 전에 변환
long source = 8L;
int number = (int) source;
long whole = (long) 4.9f; // 4, 소수 부분 손실
```

넓은 범위로의 변환은 보통 자동, 좁은 타입·실수→정수는 캐스트가 필요하다. 범위 초과와 소수 손실을 확인한다.

## ☘️ 연산과 조건

- 산술 `+ - * / %`, 복합 대입 `+= -= *= /= %=`
- 정수끼리 나누면 소수 버림. 실수와 계산하면 실수 결과
- char끼리 더하면 코드값 계산, String과 +는 연결. `'a' + 'b'`는 195, `"a" + "pple"`은 apple, `9 + 9 + "9"`는 189
- `++`, `--`: 전위는 변경 후 사용, 후위는 기존 값 사용 후 변경
- 비교 `== != > < >= <=`는 boolean 반환. 문자열 내용은 equals, 참조형 ==는 객체 동일성
- `&&`, `||`, `!`는 boolean에 사용. JS처럼 숫자·문자열을 자동 참·거짓으로 취급하지 않음
- 단축 평가: && 왼쪽 false, || 왼쪽 true면 오른쪽 미실행. 오른쪽 증감·메서드의 실행 여부 주의
- 삼항: `score >= 60 ? "합격" : "불합격"`

## ☘️ 호출과 코드 구조

인자는 호출 때 전달하는 값, 매개변수는 선언에서 받는 변수다. 개수·순서·타입을 맞춘다. 다른 메서드 호출이 끝나면 호출한 위치로 돌아온다.

- void: 반환값 없음 / int·String 등: 해당 타입의 값을 return
- 반환값은 변수에 담거나 다른 메서드 인자로 바로 사용 가능
- 인스턴스 메서드: `new Calculator()` 후 `calculator.minNumberOf(10, 20)`
- static 메서드: 객체 없이 `Calculator.maxNumberOf(10, 20)`. 같은 클래스 안에서는 클래스명 생략 가능
- static을 객체 참조로 호출할 수도 있지만 클래스 이름이 소속을 명확히 보여줌

패키지는 관련 클래스를 묶고 이름 충돌을 줄인다. 다른 패키지의 클래스는 전체 이름을 쓰거나 import 후 짧은 이름으로 사용한다. static import로 멤버를 직접 가져올 수도 있지만 출처가 덜 드러난다.

```java
import com.woong3e.section01.method.Calculator;
```
