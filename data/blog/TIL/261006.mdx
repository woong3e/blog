## ☘️ Java의 값과 변수

Java에서는 변수를 선언할 때 저장할 값의 자료형을 함께 정한다. 자료형에 따라 담을 수 있는 값과 범위, 허용되는 연산이 달라진다. **리터럴**은 코드에 직접 적은 값이다. 수업의 123은 정수, 1.23은 실수, 작은따옴표의 'a'는 문자, 큰따옴표의 "abc"는 문자열, true·false는 논리값이다.

char는 한 문자를 저장한다. 빈 작은따옴표나 여러 글자를 넣을 수 없다. String은 여러 글자와 빈 문자열을 표현할 수 있으며 기본형이 아니라 자바가 제공하는 클래스다. 기본형은 정수 byte·short·int·long, 실수 float·double, 문자 char, 논리 boolean으로 나뉜다.

변수는 자료형과 이름을 선언하고 처음 사용할 값을 넣어 초기화한다. 같은 범위에 같은 이름을 중복 선언하거나 예약어를 이름으로 쓰거나 숫자로 시작하면 컴파일 오류다. 대소문자는 구분하며 `_`와 `$`를 이름에 사용할 수 있다. 의미가 드러나는 이름과 maxAge 같은 카멜 표기법을 사용한다. boolean은 isAlive처럼 긍정 의미로 이름을 짓는다.

`final`은 한 번 초기화한 뒤 다른 값을 다시 대입하지 못하게 한다. 선언과 초기화를 나누어도 되지만 초기화는 한 번이다. 수업에서는 AGE와 MAX_AGE처럼 상수에 대문자와 밑줄을 사용하는 이름 규칙도 확인했다.

## ☘️ 숫자의 범위와 형변환

자료형은 저장 범위가 정해져 있다. byte는 -128~127이므로 127에서 증가하면 -128, -128에서 감소하면 127이 된다. 정수 계산이 범위를 넘으면 수학적으로 기대한 큰 값이 그대로 보관되는 것이 아니다.

수업의 1000000과 700000을 int끼리 곱하면 int 범위를 넘는다. 결과를 받을 변수만 long으로 바꿔도 곱셈 자체는 int로 먼저 계산되므로 이미 넘친 결과가 전달된다.

```java
long result = (long) firstNum * secondNum;
```

연산 전에 한쪽을 long으로 바꾸면 곱셈을 long으로 진행한다. `(자료형)`은 명시적으로 타입을 바꾸는 **캐스트**다. 넓은 표현 범위의 타입으로는 보통 자동 변환되지만, long을 int로 줄이거나 실수를 정수로 바꿀 때는 캐스트가 필요하다. 범위를 벗어난 값이나 소수 부분이 손실될 수 있으므로 변환 위치를 확인한다. 수업의 4.0f를 long으로 바꾸면 4가 되며 소수가 있는 값 역시 정수 변환에서 버려진다.

## ☘️ 연산 결과를 읽는 방법

산술 연산은 `+ - * / %`이고 `%`는 나머지다. 정수끼리 나누면 소수 부분을 버리므로 123/456은 0이다. 정수와 실수를 함께 계산하면 실수 계산이 된다. char끼리 더하면 글자 연결이 아니라 문자 코드값 계산이므로 'a'+'b'는 195다.

String이 포함된 `+`는 문자열 연결이다. 왼쪽부터 계산하므로 `9 + 9 + "9"`는 숫자 합 18 뒤에 글자 9가 붙어 "189"가 된다. 원하는 숫자 계산을 먼저 해야 한다면 괄호와 계산 순서를 확인한다.

`+=` 같은 복합 대입은 계산 결과를 다시 같은 변수에 저장한다. 전위 증감은 값을 바꾼 뒤 사용하고 후위 증감은 기존 값을 사용한 뒤 바꾼다. 수업의 `++firstNum * 3`은 10을 먼저 11로 바꿔 33을 만든다.

비교 연산의 결과는 boolean이다. 숫자는 `==`, `!=`, `>`, `<`, `>=`, `<=`로 비교한다. 객체의 `==`는 같은 객체인지 비교하므로 문자열 내용은 equals를 사용한다. Java에는 JavaScript의 `===`가 없고 숫자와 문자열을 느슨하게 자동 변환해 비교하지도 않는다.

`&&`와 `||`는 boolean끼리 사용한다. 각각 모두 참, 적어도 하나 참을 뜻하며 `!`는 참·거짓을 뒤집는다. `&&` 왼쪽이 false이거나 `||` 왼쪽이 true이면 오른쪽을 생략하는 단축 평가가 있다. 오른쪽에 증감이나 함수 호출이 있다면 실행되지 않을 수 있다. `조건 ? 값1 : 값2`는 조건에 맞는 값 하나를 고르는 삼항 연산이다.

## ☘️ 메서드 호출과 코드의 소속

메서드는 특정 작업을 이름으로 묶은 코드다. main에서 methodA를 부르고 A가 B를, B가 C를 부르면 C가 끝난 뒤 B, A, main 순서로 돌아온다. 호출은 다른 메서드로 이동한 뒤 끝나면 호출한 위치 다음에서 이어진다.

호출할 때 넘기는 값이 인자이고 선언에서 그 값을 받는 변수가 매개변수다. 개수·순서·타입을 맞춰야 한다. void는 돌려줄 값이 없다는 뜻이고, String·int처럼 반환 타입을 지정하면 그 타입의 결과를 return해야 한다. 반환값은 변수에 담거나 다음 계산·다른 호출에 바로 사용할 수 있다. 출력하는 것과 값을 반환하는 것은 별개다.

인스턴스 메서드는 객체를 만든 뒤 그 객체를 통해 호출한다. 수업의 Calculator.minNumberOf는 new Calculator로 만든 cal을 통해 호출한다. static 메서드는 특정 객체가 아니라 클래스에 속하므로 Calculator.maxNumberOf로 호출한다. 같은 클래스 안에서는 클래스명을 생략할 수 있다. 객체 참조로 static을 호출하는 문법도 가능하지만 소속을 클래스명으로 드러내는 편이 명확하다.

패키지는 관련 클래스를 묶고 같은 이름의 충돌을 줄이는 단위다. 다른 패키지의 클래스는 전체 이름을 쓰거나 import로 가져와 짧은 이름을 사용한다. static import는 정적 멤버 이름을 직접 사용할 수 있게 하지만 어디에 속한 기능인지 덜 드러날 수 있다.
