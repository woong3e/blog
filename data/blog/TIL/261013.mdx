상속은 기존 클래스의 상태와 동작을 바탕으로 더 구체적인 클래스를 만드는 방법이다. 다형성은 같은 부모 타입으로 요청해도 실제 객체에 따라 다른 동작이 실행되는 성질이다. 공통 기능과 바뀌는 기능을 나누어 읽으면 상속 구조를 이해하기 쉽다.

## ☘️ 부모 초기화와 메서드 재정의

extends로 부모를 지정하면 자식은 접근 가능한 부모 멤버를 사용한다. 객체 생성 시 부모 생성자가 먼저 실행되고 자식 초기화가 이어진다. super는 부모 생성자나 부모 구현에 접근할 때 사용한다. 부모의 private 필드를 자식이 직접 사용할 수 있는 것은 아니다.

오버라이딩은 물려받은 메서드를 같은 호출 규칙으로 다시 구현하는 것이다. @Override를 붙이면 실제 재정의가 맞는지 컴파일러가 확인한다. 이름만 같은 별도 메서드를 추가하는 오버로딩과 구분한다. 접근 범위를 더 좁히는 등 재정의 규칙을 어기면 컴파일되지 않는다.

## ☘️ 참조 타입과 실제 객체

부모 타입 변수는 자식 객체를 가리킬 수 있다. 호출할 수 있는 멤버의 범위는 참조 타입에 영향을 받지만 재정의된 메서드의 실행은 실제 객체를 따른다. Animal로 Rabbit과 Tiger를 다루면 같은 먹기 요청이 서로 다른 구현으로 이어진다.

부모 참조에서 자식 전용 기능을 사용하려고 형변환할 때 실제 객체가 해당 타입인지 확인해야 한다. 잘못된 다운캐스팅은 실행 중 오류가 된다. instanceof는 타입 확인에 사용할 수 있다. 가능한 공통 동작은 부모 타입으로 요청하면 불필요한 형변환을 줄일 수 있다.

## ☘️ 추상 클래스와 인터페이스

추상 클래스는 직접 객체로 만들 수 없으며 자식이 구현할 추상 메서드와 공통 구현을 함께 둘 수 있다. Player의 공통 구조를 두고 Warrior와 Wizard가 자신의 공격을 구현하는 형태다.

인터페이스는 사용할 수 있는 기능의 약속을 표현한다. IConnectable을 구현한 Keyboard와 Mouse는 구체 종류가 달라도 연결·해제 요청을 받을 수 있다. 사용하는 코드가 구체 클래스 대신 인터페이스에 의존하면 구현 교체의 영향을 줄일 수 있다. 상속은 단순 코드 복사 수단보다 실제 포함 관계와 역할이 맞는지 먼저 판단한다.

## ☘️ 상속·다형성·인터페이스를 호출로 확인하기

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
public class Main {
  public static void main(String[] args) {
    FireCar fireCar = new FireCar();
    fireCar.run();
    fireCar.soundHorn();
    fireCar.sprayWater();
    System.out.println(new Computer("c-123", "컴퓨터", 2_000_000, "i5").getInformation());
    VendingMachine machine = new CoffeeVendingMachine();
    System.out.println(machine.vend());
    machine.powerOn();
    Animal[] animals = {new Rabbit(), new Tiger()};
    ZooKeeper keeper = new ZooKeeper();
    for (Animal animal : animals) {
      animal.cry();
      keeper.feed(animal);
      if (animal instanceof Rabbit rabbit) rabbit.jump();
    }
    Player[] players = {new Warrior(), new Wizard()};
    for (Player player : players) {
      player.attack();
      player.levelUp();
    }
    IConnectable[] devices = {new Keyboard(), new Mouse()};
    for (IConnectable device : devices) {
      device.connect();
      device.disconnect();
    }
  }
}

class Car {
  private boolean running;

  void run() {
    running = true;
  }

  protected boolean isRunning() {
    return running;
  }

  void soundHorn() {
    System.out.println("경적");
  }
}

class FireCar extends Car {
  FireCar() {
    super();
  }

  @Override
  void soundHorn() {
    System.out.println(isRunning() ? "소방차 경적" : "정지");
  }

  void sprayWater() {
    System.out.println("물 뿌리기");
  }
}

class Product {
  private final String code, name;
  private final int price;

  Product(String code, String name, int price) {
    this.code = code;
    this.name = name;
    this.price = price;
  }

  String getInformation() {
    return code + " " + name + " " + price;
  }
}

class Computer extends Product {
  private final String cpu;

  Computer(String code, String name, int price, String cpu) {
    super(code, name, price);
    this.cpu = cpu;
  }

  @Override
  String getInformation() {
    return super.getInformation() + " " + cpu;
  }
}

class VendingMachine {
  String vend() {
    return "밀크 커피";
  }

  final void powerOn() {
    System.out.println("전원 켜기");
  }
}

class CoffeeVendingMachine extends VendingMachine {
  @Override
  String vend() {
    return "아이스 아메리카노";
  }
}

class Animal {
  void cry() {
    System.out.println("동물 울음");
  }

  void eat() {
    System.out.println("동물이 먹는다");
  }
}

class Rabbit extends Animal {
  @Override
  void cry() {
    System.out.println("토끼 울음");
  }

  @Override
  void eat() {
    System.out.println("토끼가 먹는다");
  }

  void jump() {
    System.out.println("토끼가 뛴다");
  }
}

class Tiger extends Animal {
  @Override
  void cry() {
    System.out.println("호랑이 울음");
  }

  @Override
  void eat() {
    System.out.println("호랑이가 먹는다");
  }
}

class ZooKeeper {
  void feed(Animal animal) {
    animal.eat();
  }
}

abstract class Player {
  abstract void attack();

  void levelUp() {
    System.out.println("레벨업");
  }
}

class Warrior extends Player {
  @Override
  void attack() {
    System.out.println("검 공격");
  }
}

class Wizard extends Player {
  @Override
  void attack() {
    System.out.println("마법 공격");
  }
}

interface IConnectable {
  void connect();

  void disconnect();
}

class Keyboard implements IConnectable {
  public void connect() {
    System.out.println("키보드 연결");
  }

  public void disconnect() {
    System.out.println("키보드 해제");
  }
}

class Mouse implements IConnectable {
  public void connect() {
    System.out.println("마우스 연결");
  }

  public void disconnect() {
    System.out.println("마우스 해제");
  }
}
```

FireCar는 부모의 기능을 물려받고 필요한 메서드를 재정의한다. 부모 생성자는 자식 초기화 전에 실행되며 super는 부모 쪽 생성자나 메서드에 접근한다. Animal 변수로 Rabbit이나 Tiger를 가리켜도 재정의한 메서드는 실제 객체의 구현을 실행한다. 다만 참조 타입에 없는 자식 전용 메서드는 바로 호출할 수 없다. 추상 클래스는 공통 상태와 아직 구현하지 않은 동작을 함께 표현하고, 인터페이스는 구현 클래스가 제공해야 할 기능의 약속을 표현한다. Keyboard와 Mouse는 IConnectable이라는 같은 타입으로 연결 동작을 요청할 수 있다.

**실행 방법**

JDK 21 환경에서 파일명을 `Main.java`로 저장한다. 같은 폴더에서 `javac -encoding UTF-8 Main.java`로 컴파일한 뒤 `java -Dfile.encoding=UTF-8 Main`을 실행한다. 글마다 Main 클래스가 있으므로 예제는 서로 다른 폴더에 저장한다.
