state는 컴포넌트가 렌더링 사이에 기억하는 값이다. 입력값이나 클릭 횟수처럼 사용자 동작에 따라 화면이 달라질 때 사용한다. 일반 지역 변수를 바꾸는 것과 state 갱신 함수를 호출하는 것은 화면 갱신 관점에서 다르다.

## ☘️ 상태 갱신은 다음 렌더링의 입력

useState는 현재 값과 갱신 함수를 반환한다. 컴포넌트가 실행될 때 현재 상태를 읽고 JSX를 계산한다. 갱신 함수를 호출하면 React가 다음 렌더링을 준비하지만 현재 함수 안에서 이미 읽은 변수 값이 즉시 새 값으로 바뀌는 것은 아니다.

같은 이벤트 안에서 현재 count에 1을 더한 값을 여러 번 전달하면 모두 같은 이전 값을 기준으로 계산할 수 있다. 이전 결과를 이어 받아 여러 번 증가시키려면 함수형 갱신을 사용한다. React는 전달한 갱신 함수들을 순서대로 적용한다. 상태를 읽는 시점과 다음 값을 계산하는 시점을 구분해야 한다.

여러 상태는 각각 별도로 관리할 수 있다. 화면에 표시할 횟수·메시지·수량은 역할이 다르므로 어떤 이벤트가 어떤 상태를 바꾸는지 나누어 읽는다. 화면에 표시할 값이 기존 상태에서 계산 가능하다면 불필요하게 복사해 상태로 저장하지 않아도 된다.

## ☘️ 입력과 상태를 같은 값으로 유지하기

제어 입력은 input의 value를 state에 연결하고 onChange에서 최신 입력을 state에 저장한다. 사용자가 입력하면 이벤트 발생 → 새 값 저장 요청 → 다시 렌더링 → value 반영 순서로 이어진다. 입력값을 읽기만 하고 상태를 갱신하지 않으면 화면에서 수정할 수 없는 입력이 될 수 있다.

숫자 input도 value로 읽으면 문자열이다. 계산에 쓸 때 Number 등으로 변환하고 허용 범위를 확인한다. checkbox는 value 대신 checked로 현재 선택을 제어한다. 여러 입력의 이벤트를 재사용할 때는 name으로 어떤 필드인지 구분할 수 있다.

## ☘️ 객체 상태를 새 객체로 바꾸기

객체의 필드만 직접 수정하면 React에 새 상태를 전달한 것이 아니다. 이전 객체를 펼치고 바뀐 필드를 덮어 새 객체를 만든다. 동적으로 선택한 키는 대괄호 표기법으로 지정한다. 이전 상태가 필요한 갱신이라면 함수형 갱신 안에서 복사한다.

아래 가입 폼은 여러 필드를 하나의 객체에 보관한다. 한 필드를 수정할 때 나머지 필드를 보존하지 않으면 이전 입력이 사라지므로 Spread가 필요하다. 프로필 미리보기는 현재 입력 상태를 바로 표시해 상태와 화면의 연결을 확인한다.

## ☘️ 상태 변경과 입력값 연결

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**index.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>React 동작 확인</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  </head>
  <body>
    <div id="root"></div>
    <script type="text/babel">
      const { useState } = React
      function Counter() {
        const [count, setCount] = useState(0)
        const [quantity, setQuantity] = useState(0)
        const [message, setMessage] = useState('초기 메시지')
        return (
          <section>
            <h2>{message}</h2>
            <button onClick={() => setMessage('안녕하세요')}>입장</button>
            <p>현재 숫자: {count}</p>
            <button
              onClick={() => {
                setCount(count + 1)
                setCount(count + 1)
              }}
            >
              같은 값으로 두 번
            </button>
            <button
              onClick={() => {
                setCount((prev) => prev + 1)
                setCount((prev) => prev + 1)
              }}
            >
              이전 결과로 두 번
            </button>
            <p>수량: {quantity}</p>
            <button onClick={() => setQuantity((prev) => prev + 1)}>수량 증가</button>
            <button onClick={() => quantity > 0 && setQuantity((prev) => prev - 1)}>
              수량 감소
            </button>
            <button onClick={() => setQuantity(0)}>수량 초기화</button>
          </section>
        )
      }
      function ProfilePreview() {
        const [name, setName] = useState(''),
          [introduction, setIntroduction] = useState('')
        return (
          <section>
            <input aria-label="이름" value={name} onChange={(e) => setName(e.target.value)} />
            <textarea
              aria-label="소개"
              value={introduction}
              onChange={(e) => setIntroduction(e.target.value)}
            />
            <p>
              {name || '이름 없음'} / {introduction || '소개를 입력하세요'}
            </p>
          </section>
        )
      }
      function SignupForm() {
        const [form, setForm] = useState({ username: '', email: '' })
        const handleChange = (e) => {
          const { name, value } = e.target
          setForm((prev) => ({ ...prev, [name]: value }))
        }
        return (
          <form
            onSubmit={(e) => {
              e.preventDefault()
              alert(`${form.username}: ${form.email}`)
              setForm({ username: '', email: '' })
            }}
          >
            <input
              aria-label="아이디"
              name="username"
              value={form.username}
              onChange={handleChange}
            />
            <input aria-label="이메일" name="email" value={form.email} onChange={handleChange} />
            <button>가입 정보 확인</button>
          </form>
        )
      }
      function App() {
        return (
          <>
            <Counter />
            <ProfilePreview />
            <SignupForm />
          </>
        )
      }
      ReactDOM.createRoot(document.getElementById('root')).render(<App />)
    </script>
  </body>
</html>
```

useState는 현재 값과 갱신 함수를 함께 돌려준다. 갱신 함수를 부르면 React가 다음 렌더링을 준비하고 그때 새 값으로 화면을 계산한다. 같은 렌더링 안의 count는 즉시 바뀌지 않으므로 이전 값에서 연속 계산할 때는 함수형 갱신을 사용한다. 입력은 value를 상태에 연결하고 onChange에서 새 값을 저장한다. 객체 상태는 이전 객체를 펼친 뒤 바뀐 키만 덮어 새 객체로 전달한다. 프로필 미리보기와 가입 폼은 별도 상태이므로 각 입력이 어느 컴포넌트의 상태를 바꾸는지 구분해서 읽는다.

**실행 방법**

아래 전체 코드를 index.html로 저장하고 브라우저에서 연다. React 18·React DOM 18·Babel을 CDN에서 가져오므로 인터넷 연결이 필요하다. Babel은 브라우저에서 JSX를 변환하는 실습용 구성이다. 파일을 여러 조각으로 나누어 붙일 필요가 없다.
