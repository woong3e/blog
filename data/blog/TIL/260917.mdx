## ☘️ 상태와 업데이트

props는 부모에게 받은 값, state는 컴포넌트가 관리하는 값이다. `const [message, setMessage] = useState('초기 메시지')`는 현재 값과 setter를 반환한다.

입장·퇴장 예제는 메시지·색상 state를 함께 변경했다. setter로 다음 렌더링을 요청하면 DOM을 직접 수정할 필요가 없다.

```jsx
setCount(count + 1)
setCount(count + 1) // 같은 스냅샷을 읽어 합계 +1
// 별도 비교 예시
setCount((prev) => prev + 1)
setCount((prev) => prev + 1) // 앞선 결과를 이어 받아 +2
```

핸들러의 count는 현재 렌더링의 스냅샷이다. setter 호출 직후 그 변수가 바뀌지는 않으며, 함수형 업데이트는 큐에서 순서대로 적용된다.

## ☘️ 이벤트와 제어 입력

- `onClick={handleEnter}`: 실행할 함수 전달
- `onClick={handleEnter()}`: 렌더링 중 호출. 인수를 넘길 때는 `() => handleEnter(value)`로 감쌈
- `value` + `onChange`: state가 입력값을 결정하는 제어 입력

```jsx
const [name, setName] = useState('')
<input value={name} onChange={event => setName(event.target.value)} />
<p>{name !== '' ? name : '이름 없음'}</p>
```

프로필 실습은 이름·소개를 각각 관리했다. **입력 → event.target.value → state 변경 → 렌더링 → 미리 보기**이며, 빈 소개에는 안내 문구를 표시했다.

## ☘️ 객체 상태와 실습

```jsx
const [form, setForm] = useState({ username: '', email: '' })
const handleChange = ({ target: { name, value } }) => {
  setForm({ ...form, [name]: value })
}
;<input name="email" value={form.email} onChange={handleChange} />
```

input의 name과 객체 키를 맞추고 `[name]`으로 변경 대상을 선택한다. 기존 필드를 펼친 뒤 변경값만 덮어쓰므로 다른 입력도 유지된다. 직접 수정 대신 새 객체를 전달한다.

- 회원가입: 아이디·이메일 확인 후 `setForm({ username: '', email: '' })`로 입력칸까지 초기화
- 수량: 초기 0, 증가 +1, 감소는 `quantity > 0`일 때만 -1, 초기화는 0
- 이전 상태를 이어 계산할 때 함수형 setter 사용
