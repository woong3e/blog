오늘은 `useState`로 컴포넌트의 상태를 관리하고, 버튼 클릭과 입력 이벤트를 연결했다. 입장·퇴장 메시지와 카운터 예제를 살펴본 뒤 수량 조절기, 프로필 미리 보기, 회원가입 폼을 직접 구현했다.

## useState와 이전 상태를 기준으로 한 업데이트

`props`는 부모에게서 전달받는 값이고, `state`는 컴포넌트가 직접 관리하는 값이다. `useState`는 현재 상태와 상태 변경 함수를 배열로 반환하므로 구조 분해 할당으로 꺼낸다.

```jsx
const [message, setMessage] = useState('초기 상태 메시지입니다.')
const [textColor, setTextColor] = useState('black')

const handleEnter = () => {
  setMessage('안녕하세요 환영합니다.')
  setTextColor('tomato')
}

return (
  <>
    <p style={{ color: textColor }}>{message}</p>
    <button onClick={handleEnter}>입장</button>
  </>
)
```

상태 변경 함수에 다음 값을 전달하면 React가 그 값을 사용해 컴포넌트를 다시 렌더링한다. 메시지와 글자색을 state로 연결해 두었기 때문에 DOM을 직접 찾아서 수정할 필요가 없다.

**같은 이벤트에서 두 번 더할 때**

카운터 실습에서 가장 기억할 부분은 상태가 현재 렌더링의 스냅샷이라는 점이었다.

```jsx
// 두 호출 모두 현재 렌더링의 같은 count를 읽으므로 결과는 +1이다.
setCount(count + 1)
setCount(count + 1)

// 앞선 업데이트 결과를 다음 업데이트가 받아 결과는 +2가 된다.
setCount((prev) => prev + 1)
setCount((prev) => prev + 1)
```

setter를 호출했다고 이벤트 핸들러 안의 `count`가 즉시 바뀌는 것은 아니다. 이전 상태를 기준으로 연속 계산해야 한다면 함수형 업데이트를 사용한다. React는 큐에 들어간 업데이트 함수를 차례로 적용한다.

## 입력값과 이벤트 연결하기

**이벤트 핸들러는 함수로 전달한다**

`onClick={handleEnter}`는 클릭했을 때 실행할 함수를 전달한다. `onClick={handleEnter()}`처럼 호출 결과를 전달하면 렌더링 중 함수가 실행된다. 값이나 추가 동작을 함께 전달해야 할 때는 화살표 함수로 감싼다.

**value와 onChange로 제어 입력 만들기**

프로필 미리 보기 실습에서는 이름과 소개를 각각 state로 관리했다. 입력값을 `value`에 연결하고 `onChange`에서 새 값을 state에 저장했다.

```jsx
const [name, setName] = useState('')
const [introduction, setIntroduction] = useState('')

return (
  <>
    <input value={name} onChange={(event) => setName(event.target.value)} />
    <input value={introduction} onChange={(event) => setIntroduction(event.target.value)} />
    <p>{name !== '' ? name : '이름 없음'}</p>
    <p>{introduction !== '' ? introduction : '소개를 입력해 주세요.'}</p>
  </>
)
```

`event.target`은 이벤트가 발생한 입력 요소이고, `event.target.value`는 그 요소의 입력값이다. `입력 → state 변경 → 렌더링 → 미리 보기 갱신` 흐름으로 입력칸과 화면이 같은 데이터를 사용한다.

**여러 입력을 객체 하나로 관리하기**

회원가입 폼에서는 `username`, `email`을 한 객체에 넣었다. 각 input의 `name`을 state 객체의 프로퍼티 이름과 같게 지정하면 하나의 핸들러를 공유할 수 있다.

```jsx
const [form, setForm] = useState({ username: '', email: '' })

const handleChange = (event) => {
  const { name, value } = event.target
  setForm({ ...form, [name]: value })
}

return (
  <>
    <input name="username" value={form.username} onChange={handleChange} />
    <input name="email" value={form.email} onChange={handleChange} />
  </>
)
```

`[name]`은 변수에 들어 있는 문자열을 프로퍼티 이름으로 사용하는 계산된 프로퍼티 문법이다. `...form`으로 기존 필드를 복사한 뒤 변경된 필드만 덮어써서 다른 입력값을 유지한다. 객체 state를 직접 수정하지 않고 새 객체를 setter에 전달하는 것이 핵심이다.

## 실습에서 기억할 점

수량 조절기는 초기값을 `0`으로 두고 증가, 감소, 초기화 이벤트를 만들었다. 감소 시에는 수량이 양수인지 먼저 확인해 음수가 되지 않게 했다.

```jsx
const [quantity, setQuantity] = useState(0)

const handleIncrease = () => setQuantity(quantity + 1)
const handleDecrease = () => {
  if (quantity > 0) setQuantity(quantity - 1)
}
const handleReset = () => setQuantity(0)
```

회원가입 실습에서는 입력한 아이디와 이메일을 확인한 뒤 `setForm({ username: '', email: '' })`으로 초기화했다. 입력칸의 `value`가 state를 따르기 때문에 state를 비우면 입력칸도 함께 비워진다.

- 화면에 표시할 값은 state로 관리하고 이벤트에서 setter를 호출한다.
- 현재 렌더링의 state와 다음 렌더링에 반영될 state를 구분한다.
- 이전 상태를 이어서 계산할 때는 함수형 업데이트를 사용한다.
- 제어 입력은 `value`와 `onChange`를 함께 연결한다.
- 객체 state는 기존 값을 복사하고 변경할 필드만 덮어쓴다.
