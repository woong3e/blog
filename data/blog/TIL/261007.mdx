## ☘️ API와 입력

API는 미리 제공된 기능을 쓰는 인터페이스다. Math는 java.lang의 static 메서드라 import·객체 없이 abs·min·max를 호출한다.

- Math.random(): 0.0 이상 1.0 미만. `(int) (Math.random() * 10) + 1`은 1~10. 곱하기 전 캐스트하면 항상 0
- `new Random().nextInt(10)`: 0~9. java.util.Random import 필요
- `new Scanner(System.in)`: 키보드 입력. next는 공백 기준 한 토큰, nextLine은 현재 줄의 나머지를 읽고 개행 소비
- nextInt·nextDouble은 정수·실수 토큰. nextInt 뒤 개행이 남아 바로 nextLine하면 빈 문자열일 수 있음

```java
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
sc.nextLine(); // 남은 줄 소비
String name = sc.nextLine();
sc.close();
```

별도 방식으로 `Integer.parseInt(sc.nextLine())`도 가능하다. 문자는 `sc.nextLine().charAt(0)`으로 읽되 빈 문자열에 접근하면 안 된다. 이 호출들은 Scanner를 닫기 전에 사용한다.

## ☘️ 제어문

- if / if-else / else if: 먼저 참인 분기만 실행. 점수처럼 겹치는 범위는 순서 주의. 중첩 if로 안쪽 조건 검사 가능
- 전통 switch의 case에는 break가 없으면 다음 분기로 이어짐. 일치하지 않으면 default
- switch 표현식은 값 생성. 화살표 식은 그 결과, 블록은 yield로 결과 지정. return은 메서드 자체 종료

```java
int result = switch (operator) {
    case '+' -> first + second;
    case '-' -> first - second;
    default -> { System.out.println("잘못된 연산자"); yield 0; }
};
```

- for: 초기식 → 조건 → 본문 → 증감. 횟수·인덱스 순회
- while: 조건 먼저. 종료 조건 중심 / do-while: 본문 먼저라 최소 1회
- 누적 합계 변수는 반복문 밖에 초기화. 중첩 반복은 바깥 한 회마다 안쪽 전체 실행
- break: 가장 가까운 반복·switch 종료 / continue: 이번 회차 생략(for는 증감, while은 조건으로) / return: 메서드 종료
- 1~100에서 4·5의 공배수만 남기면 20·40·60·80·100. 나머지는 continue
- 중첩 안쪽 break만으로 바깥은 끝나지 않음. `break woong3e;` 같은 라벨 또는 boolean 종료 신호 사용

## ☘️ 배열과 복사

`int[] arr;`는 참조 변수 선언, `arr = new int[5];`는 배열 생성이다. 같은 타입을 고정 길이로 저장하며 인덱스는 0~length-1, 범위 밖은 ArrayIndexOutOfBoundsException이다.

- 기본값: 정수 0, 실수 0.0, boolean false, char `\u0000`, 참조형 null
- `int[] scores = {80, 90, 75, 90, 100};` → 합계 435, 평균 `sum / (double) scores.length`는 87.0
- `Arrays.toString(scores)`: 내용 출력
- 2차원은 배열 안의 배열. scores.length는 행 수, scores[i].length는 해당 행 길이
- 학생별 총점은 바깥 반복 안에서 sum 초기화, 안쪽에서 과목 합산. 입력받은 학생·과목 수로 배열 생성 가능
- `new int[3][]`의 행은 null. 각 행에 new int[3]·[4]·[2]를 할당한 뒤 접근. 원본의 iarr/iarr3 혼동 수정
- 가변 배열은 현재 행 길이로 순회. 읽기만 할 땐 `for (int[] row : scores)` 안에 `for (int score : row)`

```java
int[] origin = {1, 2, 3, 4, 5};
int[] shared = origin;
shared[4] = 80; // origin도 80, origin == shared는 true
int[] copy = Arrays.copyOf(origin, origin.length);
copy[0] = 99; // origin[0]은 1
```

수업의 참조 대입은 같은 배열을 공유한다. 1차원 int 배열을 독립 복사하는 방법은 **새 배열+for**, **Arrays.copyOf(원본, 길이)**, **미리 만든 대상에 System.arraycopy(원본, 시작, 대상, 시작, 길이)**, **clone()**이다. 객체·다차원 배열의 내부 참조까지 독립 복사되는 것으로 일반화하지 않는다.
