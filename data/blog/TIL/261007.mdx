## ☘️ 제공된 API와 키보드 입력

API는 미리 준비된 기능을 정해진 방식으로 사용하는 통로다. Java는 자주 필요한 작업을 클래스와 메서드로 제공한다. 수업의 Math는 절대값 abs, 최대·최소 max·min, 난수 random을 사용했다. java.lang에 속하므로 별도 import 없이 이름으로 쓰고 정적 메서드라 객체를 만들지 않는다.

Math.random은 0.0 이상 1.0 미만의 실수다. 10을 곱하면 0 이상 10 미만이 되고 정수로 바꾼 뒤 1을 더하면 1~10을 얻는다. 곱하기 전에 정수로 바꾸면 처음 값이 1보다 작아 항상 0이 되므로 변환 순서가 중요하다. Random은 java.util에서 가져와 객체를 만든다. nextInt(10)은 0~9이며 끝값 10은 포함하지 않는다.

**Scanner**

Scanner(System.in)은 표준 입력을 읽는다. next는 공백으로 나뉜 한 조각을, nextLine은 현재 줄의 나머지와 줄바꿈을 소비한다. nextInt와 nextDouble은 숫자 토큰을 읽지만 뒤의 줄바꿈이 남을 수 있다. 따라서 nextInt 직후 nextLine으로 이름을 읽으면 남은 줄바꿈을 먼저 만나 빈 문자열이 될 수 있다. 수업은 중간에 nextLine을 한 번 호출해 남은 줄을 소비했다.

한 줄을 읽어 Integer.parseInt로 정수로 바꾸는 방법도 있다. 문자는 직접 읽는 전용 메서드 대신 문자열에서 charAt(0)으로 첫 글자를 고른다. 빈 문자열에는 첫 글자가 없으므로 확인이 필요하다. 읽기를 마친 뒤 close로 자원을 정리한다.

## ☘️ 조건과 반복을 제어하기

if는 참인 조건의 코드를 실행하고 else if는 앞에서 처음 맞는 분기 하나를 고른다. 점수처럼 범위가 겹치면 검사 순서가 중요하다. 안쪽 if로 세부 조건을 다시 검사할 수도 있다. 원본 성적 분류는 A·C·D·F로 나누며 B 구간이 별도 구현되지 않았다는 점을 실제 코드대로 읽는다.

전통 switch는 일치하는 case에서 실행을 시작하고 break가 없으면 다음 분기로 이어진다. 수업의 계산기는 잘못된 연산 기호일 때 return으로 메서드를 끝내 결과 출력을 건너뛴다. switch 표현식은 값 자체를 만들어 대입할 수 있다. 화살표 뒤의 식이 결과가 되고 여러 줄 블록은 yield로 결과를 정한다. yield는 switch의 값, return은 메서드 전체 종료라는 차이가 있다.

for는 초기화 → 조건 → 본문 → 증감 순서이고 횟수나 인덱스 순회에 쓴다. while은 조건부터 검사해 종료 조건 중심으로, do-while은 본문부터 실행해 적어도 한 번 입력받는 구조에 썼다. 중첩 반복은 바깥 한 회마다 안쪽 반복 전체가 진행된다. 합계는 반복 밖에서 초기화해 이전 회차를 누적한다.

break는 가장 가까운 반복·switch를 끝내고, continue는 현재 회차의 나머지를 생략한다. for의 continue 뒤에는 증감식으로, while에서는 조건 검사로 이동한다. return은 반복만이 아니라 메서드를 종료한다. 1~100에서 4와 5의 공배수가 아니면 continue하여 20·40·60·80·100만 남겼다. 안쪽 break만으로 바깥 반복은 끝나지 않으므로 라벨이 붙은 반복을 끝내거나 boolean 종료 신호를 바깥에서 확인하는 방법도 사용했다.

## ☘️ 배열의 생성과 순회

배열은 같은 타입의 값을 고정된 개수로 저장한다. `int[] iarr`는 배열을 가리킬 변수 선언이고 `new int[5]`는 실제 다섯 칸의 배열 생성이다. 둘을 연결해야 각 칸을 사용할 수 있다. 인덱스는 0부터 length-1까지이며, 길이 5에서 5번 위치에 접근하면 범위 오류다.

생성 직후 기본값은 정수 0, 실수 0.0, boolean false, char의 영 문자, 참조형 null이다. 수업의 점수 80·90·75·90·100을 순회해 합계 435를 얻고, 실수 평균을 위해 나눗셈 전에 한쪽을 double로 바꿔 87.0을 계산했다. Arrays.toString은 배열 내용을 읽을 수 있는 문자열로 표시한다.

2차원 배열은 배열 안에 각 행 배열을 둔 구조다. 바깥 length는 행 수, 각 행의 length는 그 행의 과목 수다. 학생별 합계를 구할 때 sum을 바깥 반복의 안쪽, 과목 반복의 바깥에 초기화해야 학생끼리 합계가 섞이지 않는다.

행마다 길이가 달라도 된다. 행만 new int[3][]로 만든 상태에서는 각 행이 null이므로 행 배열을 별도로 생성한 뒤 접근한다. 원본은 iarr3를 선언한 뒤 iarr의 행을 바꾸는 변수 혼동이 있다. 가변 배열은 고정 열 수 대신 현재 행의 length로 순회한다. 읽기만 할 때는 향상된 for를 중첩해 사용할 수 있다.

## ☘️ 같은 배열 공유와 독립 복사

배열 변수를 다른 변수에 대입하면 배열 전체가 복제되는 것이 아니라 참조값이 복사된다. 두 변수가 같은 배열을 가리키므로 한쪽에서 마지막 값을 80으로 바꾸면 다른 쪽에서도 80을 읽고 `==`는 true다.

독립적인 1차원 int 배열은 새 배열을 만들고 for로 값을 옮기거나 Arrays.copyOf, System.arraycopy, clone을 사용할 수 있다. arraycopy는 미리 만든 대상 배열과 원본·대상의 시작 위치, 복사 길이를 받는다. copyOf는 결과 길이를 지정할 수 있고 clone은 같은 길이의 배열을 만든다.

수업에서 복사본의 첫 값을 99로 바꿔도 원본 첫 값은 1이다. 다만 이는 int 값들을 복사한 결과다. 객체나 다차원 배열의 내부 참조까지 모두 독립적으로 복제된다고 일반화하지 않는다.
