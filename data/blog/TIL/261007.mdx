사용자의 입력을 받고 여러 값을 반복 처리하려면 입력 API와 배열의 구조를 이해해야 한다. API는 이미 제공되는 기능을 호출하는 방법이다. Math·Random·Scanner 같은 클래스를 사용하면 직접 구현하지 않고 계산·난수·입력을 처리할 수 있다.

## ☘️ 입력과 반복의 종료 조건

Scanner는 입력 스트림에서 숫자나 문자열을 읽는다. nextInt는 정수 단위를, nextLine은 한 줄을 읽는다. 숫자를 읽은 뒤 남아 있는 줄바꿈 때문에 다음 nextLine이 빈 문자열을 받을 수 있으므로 읽는 단위를 맞춘다. 아래 예제는 실행 결과를 비교하기 위해 고정 문자열을 입력 스트림으로 제공한다.

switch는 값에 맞는 분기를 선택한다. 화살표를 사용하는 switch 표현식은 선택 결과를 값으로 돌려줄 수 있다. while·for는 조건이 유지되는 동안 반복하고 break는 반복 전체를 끝낸다. continue는 현재 회차의 남은 부분만 건너뛴다. 반복 변수의 시작값·마지막 포함 여부·증가량을 먼저 확인한다.

## ☘️ 배열의 생성과 인덱스

배열은 같은 타입의 값을 정해진 개수만큼 저장한다. 인덱스는 0부터 시작하므로 length가 5이면 마지막 칸은 4다. 새 배열의 칸은 타입의 기본값으로 초기화되지만 지역 변수 자체는 사용 전에 초기화해야 한다.

합계는 각 요소를 누적해 구하고 평균은 합계를 요소 수로 나눈다. 정수 나눗셈으로 소수 부분을 잃지 않으려면 나누기 전에 실수로 변환한다. 향상된 for는 값을 차례로 읽기 편하지만 현재 위치가 필요한 수정 작업은 인덱스 반복이 더 명확할 수 있다.

2차원 배열은 배열을 담는 배열이다. 행마다 길이가 다를 수 있으므로 바깥 배열의 길이와 각 행의 길이를 따로 읽는다. 모든 행이 같은 길이라고 가정하면 범위 오류가 날 수 있다.

## ☘️ 참조 복사와 배열 복사

배열 변수를 다른 변수에 대입하면 배열 내용 전체가 복제되지 않고 같은 배열을 가리킨다. 한쪽에서 요소를 바꾸면 다른 쪽에서도 바뀐 값이 보인다. clone이나 arraycopy 등으로 새 배열에 값을 옮기면 기본형 요소는 별도로 보관된다.

참조형 요소라면 바깥 배열을 복사해도 내부 객체 참조는 공유될 수 있다. 이 차이를 얕은 복사라고 한다. 아래 예제는 배열 참조의 == 비교와 실제 요소 값을 함께 출력해 어떤 변경이 공유되는지 보여 준다. Random의 seed는 결과 순서를 재현하기 위해 고정했다.

## ☘️ 입력·반복·배열 복사를 연결한 실행

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.io.ByteArrayInputStream;
import java.nio.charset.StandardCharsets;
import java.util.Arrays;
import java.util.Random;
import java.util.Scanner;

public class Main {
  public static void main(String[] args) {
    String input = "20\n예제 사용자\n";
    try (Scanner scanner =
        new Scanner(new ByteArrayInputStream(input.getBytes(StandardCharsets.UTF_8)))) {
      int age = scanner.nextInt();
      scanner.nextLine();
      String name = scanner.nextLine();
      System.out.println(name + ": " + age);
    }
    System.out.println(new Random(1).nextInt(10));
    int first = 10, second = 3;
    char operator = '+';
    int result =
        switch (operator) {
          case '+' -> first + second;
          case '-' -> first - second;
          default -> {
            yield 0;
          }
        };
    System.out.println(result);
    int[] scores = {80, 90, 75, 90, 100};
    int sum = 0;
    for (int score : scores) sum += score;
    System.out.println(sum + " / " + sum / (double) scores.length);
    int[][] rows = new int[3][];
    rows[0] = new int[] {1, 2, 3};
    rows[1] = new int[] {4, 5};
    rows[2] = new int[] {6};
    for (int[] row : rows) System.out.println(Arrays.toString(row));
    int[] shared = scores;
    shared[0] = 99;
    int[] copied = Arrays.copyOf(scores, scores.length);
    copied[0] = 1;
    int[] byArrayCopy = new int[scores.length];
    System.arraycopy(scores, 0, byArrayCopy, 0, scores.length);
    int[] cloned = scores.clone();
    System.out.println(scores[0] + " / " + copied[0] + " / " + (scores == shared));
    System.out.println(Arrays.equals(byArrayCopy, cloned));
    for (int i = 1; i <= 100; i++) {
      if (!(i % 4 == 0 && i % 5 == 0)) continue;
      System.out.print(i + " ");
    }
    System.out.println();
    int count = 3;
    while (count > 0) count--;
    do {
      count++;
    } while (count < 1);
    outer:
    for (int i = 0; i < 3; i++) {
      for (int j = 0; j < 3; j++) {
        if (j == 1) break outer;
      }
    }
    System.out.println(count);
  }
}
```

입력 결과가 일정하도록 Scanner에 예제 문자열을 제공한다. 실제 키보드 입력을 받으려면 입력 스트림을 System.in으로 바꾼다. 배열의 length는 칸 수이고 마지막 인덱스는 length-1이다. 2차원 배열의 각 행도 배열이므로 행마다 길이를 확인한다. 배열 참조만 대입하면 같은 배열을 가리키고 clone이나 arraycopy는 바깥 배열의 값을 새 배열로 복사한다. 이 예제의 난수는 seed를 고정해 같은 순서가 나오도록 했다.
