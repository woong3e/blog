## 학습 내용

오늘은 Java가 제공하는 API로 난수를 만들고 키보드 입력을 받았다. 이어서 조건문과 반복문으로 실행 흐름을 제어하고, 여러 값을 배열에 저장해 순회하거나 복사하는 방법을 학습했다.

### Java API와 난수

Java는 자주 필요한 기능을 클래스와 메서드로 제공한다. API는 이런 기능을 사용할 수 있도록 공개된 인터페이스이며, 이미 구현된 기능을 호출하면 같은 동작을 직접 다시 작성할 필요가 없다.

`Math`의 메서드는 static 메서드이므로 객체를 만들지 않고 클래스 이름으로 호출한다. `Math`는 `java.lang`에 있어 별도의 import 없이 사용할 수 있다.

```java
System.out.println(Math.abs(-7));      // 7
System.out.println(Math.max(10, 20));  // 20
System.out.println(Math.min(10, 20));  // 10

int random = (int) (Math.random() * 10) + 1;
```

`Math.random()`은 **0.0 이상 1.0 미만**의 실수를 반환한다. 여기에 10을 곱하면 0 이상 10 미만이 되고, `int`로 변환하면 0부터 9까지의 정수가 된다. 마지막에 1을 더해 1부터 10까지의 값을 만든다. 곱하기 전에 정수로 변환하면 항상 0이 되므로 괄호 위치를 주의해야 한다.

`Random`은 객체를 생성해서 사용한다. `nextInt(10)`은 0부터 9까지의 정수 난수를 반환한다.

```java
import java.util.Random;

Random random = new Random();
int number = random.nextInt(10);
```

### Scanner와 입력 처리

`Scanner`는 입력을 원하는 자료형으로 읽는 도구다. 키보드 입력을 받으려면 `System.in`을 전달해 객체를 생성한다.

| 메서드         | 읽는 내용                                      |
| -------------- | ---------------------------------------------- |
| `next()`       | 공백이나 개행으로 구분된 문자열 한 토큰        |
| `nextLine()`   | 현재 위치부터 한 줄의 나머지 내용, 개행도 소비 |
| `nextInt()`    | 정수 토큰을 읽어 `int`로 반환                  |
| `nextDouble()` | 실수 토큰을 읽어 `double`로 반환               |

`nextInt()`는 숫자를 읽은 뒤 줄 끝의 개행을 남길 수 있다. 곧바로 `nextLine()`을 호출하면 남은 개행까지 읽어 빈 문자열을 반환할 수 있다. 다음 줄의 내용을 받으려면 먼저 남은 줄을 소비한다.

```java
import java.util.Scanner;

Scanner sc = new Scanner(System.in);

int age = sc.nextInt();
sc.nextLine(); // 숫자 뒤에 남은 줄의 내용을 소비
String name = sc.nextLine();

sc.close();
```

처음부터 `nextLine()`으로 한 줄을 받은 뒤 `Integer.parseInt()`로 정수로 변환하는 방법도 실습했다. 문자 하나는 문자열로 읽고 `charAt(0)`으로 꺼낸다.

```java
String ageInput = sc.nextLine();
int age = Integer.parseInt(ageInput);

char ch = sc.nextLine().charAt(0);
```

위 코드는 Scanner를 닫기 전에 각각 실행하는 예시다. `charAt(0)`은 첫 번째 문자를 가져오므로 입력 문자열이 비어 있으면 사용할 수 없다.

### 조건문과 switch 표현식

`if`는 조건이 참일 때 실행하고, `if-else`는 참과 거짓에 따라 두 동작 중 하나를 실행한다. 여러 조건을 순서대로 검사할 때는 `if-else if-else`를 사용한다. 먼저 참이 된 분기만 실행되므로 점수 등급처럼 범위가 겹치는 조건은 순서를 살펴야 한다. 분기 안에서 다시 조건을 판단하는 중첩 if도 사용할 수 있다.

```java
if (num % 2 != 0) {
    System.out.println("홀수입니다.");
} else {
    System.out.println("짝수입니다.");
}
```

`switch`는 연산 기호처럼 특정 값에 따라 분기할 때 사용할 수 있다. 기존의 `case 값:` 형태에서는 `break`로 switch를 빠져나오며, 없으면 다음 case의 코드로 이어질 수 있다. 일치하는 case가 없을 때는 `default`를 실행한다.

실습의 switch 표현식은 분기를 실행해 **결과값을 만든다**. 아래는 덧셈·뺄셈 실습을 간단히 정리한 예시다.

```java
int result = switch (operator) {
    case '+' -> first + second;
    case '-' -> first - second;
    default -> {
        System.out.println("잘못된 연산 기호를 입력하셨습니다.");
        yield 0;
    }
};
```

화살표 뒤에 식을 쓰면 그 값이 결과가 된다. 중괄호 블록에서 결과값을 정할 때는 `yield`를 사용한다. `yield`는 switch 표현식의 값을 정하지만, `return`은 현재 메서드를 종료한다. 위 예시는 잘못된 기호가 들어오면 0을 결과로 사용하고 이후 코드를 계속 실행한다.

### 반복문과 흐름 제어

반복문은 같은 작업을 여러 번 수행할 때 사용한다. 실습에서는 학생 이름 입력, 누적 합계, 구구단, 종료 문자열 입력에 적용했다.

| 반복문     | 실행 흐름과 선택 기준                                                       |
| ---------- | --------------------------------------------------------------------------- |
| `for`      | 초기식 → 조건 검사 → 본문 → 증감식. 횟수나 인덱스가 정해진 순회에 편리하다. |
| `while`    | 조건을 먼저 검사한다. 종료 조건에 따라 반복할 때 사용한다.                  |
| `do-while` | 본문을 실행한 뒤 조건을 검사하므로 최소 한 번 실행한다.                     |

```java
int sum = 0;
for (int i = 1; i <= num; i++) {
    sum += i;
}
```

누적 변수 `sum`은 반복문 밖에서 초기화한다. 반복문 안에서 매번 0으로 초기화하면 이전 합계를 유지할 수 없다. 구구단처럼 두 기준을 조합할 때는 중첩 for문을 사용하며, 바깥 반복 한 번마다 안쪽 반복 전체를 실행한다.

반복 도중 실행 흐름을 바꾸는 문장은 종료 범위가 다르다.

| 문장       | 동작                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------- |
| `break`    | 가장 가까운 반복문 또는 switch를 종료한다.                                                         |
| `continue` | 현재 반복 회차의 남은 본문을 건너뛴다. for문에서는 증감식으로, while문에서는 조건 검사로 이동한다. |
| `return`   | 반복문을 포함한 현재 메서드 전체를 종료한다.                                                       |

```java
for (int i = 1; i <= 100; i++) {
    if (!(i % 4 == 0 && i % 5 == 0)) {
        continue;
    }
    System.out.println(i);
}
```

위 코드는 4와 5의 공배수인 `20, 40, 60, 80, 100`을 출력한다. 조건을 만족하지 않는 회차는 `continue`로 출력문을 건너뛴다.

중첩 반복문에서 안쪽의 `break`만 실행하면 바깥 반복문은 계속된다. 실습에서는 바깥 반복문에 `woong3e:` 라벨을 붙여 `break woong3e;`로 종료하거나, boolean 변수 `isBreak`로 종료 신호를 전달한 뒤 바깥에서도 `break`하는 방법을 확인했다.

### 배열의 선언과 순회

배열은 같은 자료형의 여러 값을 하나의 객체에 저장한다. 학생마다 별도 변수를 만드는 대신 배열과 반복문을 사용하면 값의 개수가 늘어나도 같은 방식으로 처리할 수 있다.

```java
int[] iarr;        // 배열을 가리킬 참조 변수 선언
iarr = new int[5]; // 길이 5의 배열 생성 및 참조값 대입

int[] scores = {80, 90, 75, 90, 100};
```

선언만으로 배열 객체가 만들어지지는 않는다. `new int[5]`로 생성한 배열의 각 요소는 0으로 초기화된다. 다른 자료형의 배열도 실수는 0.0, 논리형은 false, 문자형은 `\u0000`, 참조형은 null처럼 기본값으로 채워진다.

배열 인덱스는 **0부터 `length - 1`까지**다. 길이 5인 배열에 `iarr[5]`로 접근하면 `ArrayIndexOutOfBoundsException`이 발생한다. 생성된 배열의 길이는 고정된다.

```java
int sum = 0;
for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
}
double avg = sum / (double) scores.length;

System.out.println(sum); // 435
System.out.println(avg); // 87.0
```

평균은 정수끼리 나누면 소수 부분이 버려지므로 나누기 전에 한쪽을 `double`로 변환한다. 입력 실습도 배열 길이만큼 점수를 받고 합계를 누적한 뒤 평균을 구하는 같은 구조다.

배열의 내용을 한 번에 확인할 때는 `Arrays.toString()`을 사용했다.

```java
import java.util.Arrays;

System.out.println(Arrays.toString(scores)); // [80, 90, 75, 90, 100]
```

### 2차원 배열과 가변 배열

2차원 배열은 배열의 요소가 다시 배열인 구조다. 학생별 여러 과목 점수처럼 두 기준으로 데이터를 구분할 때 사용할 수 있다.

```java
int[][] scores = {
    {80, 78, 67},
    {90, 77, 95},
    {70, 89, 94}
};

for (int i = 0; i < scores.length; i++) {
    int sum = 0;
    for (int j = 0; j < scores[i].length; j++) {
        sum += scores[i][j];
    }
    double avg = sum / (double) scores[i].length;
    System.out.println((i + 1) + "번째 학생의 총점: " + sum);
    System.out.println((i + 1) + "번째 학생의 평균: " + avg);
}
```

`scores.length`는 행 개수이고, `scores[i].length`는 해당 행의 길이다. 각 학생의 합계를 따로 구해야 하므로 `sum`은 바깥 반복문 안에서 매번 초기화한다. 학생 수와 과목 수를 입력받은 뒤 `new int[students][subjects]`로 배열을 생성하는 실습도 진행했다.

가변 배열은 행마다 길이가 다르다. 행만 먼저 생성하면 각 행의 참조값은 null이므로, 행별 배열을 할당한 뒤 요소에 접근해야 한다.

```java
int[][] iarr3 = new int[3][];
iarr3[0] = new int[3];
iarr3[1] = new int[4];
iarr3[2] = new int[2];
```

강의 원본은 `iarr3`를 선언한 뒤 `iarr[0]` 등에 할당하고 있어, 위 예시는 의도에 맞게 대상 변수명을 바로잡았다. 가변 배열을 순회할 때는 모든 행에 고정된 열 개수를 적용하지 않고 **현재 행의 길이**를 사용해야 한다.

인덱스 없이 값을 읽을 때는 향상된 for문을 사용할 수 있다. 바깥 반복은 행 배열을, 안쪽 반복은 각 점수를 꺼낸다.

```java
for (int[] student : scores) {
    for (int score : student) {
        System.out.print(score + " ");
    }
    System.out.println();
}
```

### 배열의 참조 복사와 값 복사

배열 변수에는 배열 객체를 가리키는 참조값이 들어 있다. 다른 변수에 그대로 대입하면 배열의 요소를 새로 복사하는 것이 아니라 같은 배열을 가리키게 된다. 수업에서는 이를 얕은 복사로 설명했다.

```java
int[] originArr = {1, 2, 3, 4, 5};
int[] copyArr = originArr;

System.out.println(originArr == copyArr); // true
copyArr[4] = 80;
System.out.println(originArr[4]);         // 80
```

배열에서 `==`는 두 변수가 같은 배열 객체를 가리키는지 비교한다. 위 예시는 객체가 하나이므로 복사본을 통해 수정한 값이 원본에서도 보인다.

실습의 **1차원 int 배열**에서 원본을 유지하면서 복사본을 수정하려면 새 배열에 값을 복사한다.

| 방법                                             | 특징                                          |
| ------------------------------------------------ | --------------------------------------------- |
| for문                                            | 새 배열을 만든 뒤 요소를 직접 대입한다.       |
| `Arrays.copyOf(원본, 길이)`                      | 지정한 길이의 새 배열을 만들어 복사한다.      |
| `System.arraycopy(원본, 시작, 대상, 시작, 길이)` | 미리 만든 대상 배열의 지정 위치로 복사한다.   |
| `clone()`                                        | 원본과 같은 길이의 새 배열을 만들어 복사한다. |

```java
import java.util.Arrays;

int[] originArr = {1, 2, 3, 4, 5};

int[] copyFor = new int[originArr.length];
for (int i = 0; i < originArr.length; i++) {
    copyFor[i] = originArr[i];
}

int[] copyOf = Arrays.copyOf(originArr, originArr.length);

int[] arrayCopy = new int[originArr.length];
System.arraycopy(originArr, 0, arrayCopy, 0, originArr.length);

int[] copyClone = originArr.clone();
copyClone[0] = 99;

System.out.println(Arrays.toString(originArr)); // [1, 2, 3, 4, 5]
System.out.println(Arrays.toString(copyClone)); // [99, 2, 3, 4, 5]
```

새로 만든 int 배열은 원본과 별도 객체이므로 복사본의 값을 바꿔도 원본은 유지된다. 이 결과는 실습처럼 기본형 값을 담은 1차원 배열을 복사한 경우를 기준으로 이해해야 한다.
