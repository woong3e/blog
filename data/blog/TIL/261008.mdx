## ☘️ 배열과 정렬

int[]의 향상된 for는 값을 반복 변수에 복사한다. `for (int value : arr) value += 10;`은 원본을 바꾸지 않는다. 수정은 `arr[i] += 10`으로 한다.

- 값 교환: `temp = a; a = b; b = temp;`로 원래 a 보존
- 선택 정렬: 남은 범위의 최소 위치를 찾아 앞과 교환. 회차마다 **앞쪽 최소값 확정**, 바깥 반복 length-1
- 버블 정렬: 이웃 비교·교환. 회차마다 **뒤쪽 최대값 확정**, 다음 회차에서 범위를 줄임. j+1 접근 범위 주의
- `Arrays.sort(arr)`: 원본 int[]를 오름차순 정렬. toString으로 결과 확인

**중복 없는 로또**: 1~45 난수 → 이미 저장한 범위만 검사 → 중복 없을 때 저장·index 증가 → 6개가 되면 정렬한다.

```java
int[] lotto = new int[6];
int index = 0;
while (index < lotto.length) {
    int number = (int) (Math.random() * 45) + 1;
    boolean duplicate = false;
    for (int i = 0; i < index; i++) {
        if (lotto[i] == number) { duplicate = true; break; }
    }
    if (!duplicate) lotto[index++] = number;
}
Arrays.sort(lotto);
```

난수는 매번 생성하고, 중복이면 저장 위치를 유지한다. index는 저장 개수이자 다음 위치다.

## ☘️ 객체와 역할

- 클래스: 데이터·기능 정의 / 필드: name·age·hobby 등 / 객체: new Member() / 참조 변수: 객체를 가리키는 값 저장
- 선언 `Member member;`와 생성 `new Member()`는 별개. 연결 후 점으로 필드·메서드 접근
- DTO(Data Transfer Object): 데이터를 묶어 전달. MemberDTO는 번호·이름·나이·성별·키·활성 여부와 getter/setter 제공. boolean getter는 isActivated
- 캡슐화: 내부 상태를 감추고 메서드로 접근·검증. private 필드와 getter/setter만 있다고 검증이 자동인 것은 아님

접근 범위는 public(모두), protected(같은 패키지·다른 패키지 상속 규칙), 생략(같은 패키지), private(클래스 내부)다. 최상위 클래스에는 public 또는 생략만 가능하다.

```java
public void setAge(int age) {
    if (age >= 0) this.age = age;
    else { System.out.println("나이는 음수일 수 없습니다."); this.age = 0; }
}
```

Children.setAge(-10)은 경고 후 0, MemberDTO setter는 값 그대로 저장한다. `this.age`는 필드, age는 매개변수다.

**추상화**는 필요한 특징·기능으로 객체를 표현한다. Application(메뉴) → CarRacer(운전 요청) → Car(상태·동작)로 나눴다. CarRacer가 Car를 가진 has-a 관계다.

- 가속: racer.stepAccelerator() → myCar.go(). 시동 ON이면 속도 +10, OFF면 안내
- stop: 시동 ON·양수 속도면 0 / turnOff: 주행 중이면 먼저 정지 안내 후 시동 유지
- 사용하는 쪽은 속도를 직접 바꾸지 않고 기능 요청. 캡슐화는 접근·상태 보호, 추상화는 역할·기능 표현에 초점

## ☘️ 생성자

new로 객체를 만들 때 초기 상태를 설정한다. **클래스명과 같고 반환 타입이 없다.** void를 쓰면 일반 메서드가 된다.

```java
public User() { }
public User(String id, String pwd, String name) {
    this.id = id; this.pwd = pwd; this.name = name;
}
```

인자 없는 생성은 필드 기본값을 유지, 매개변수 생성은 전달값으로 초기화한다. String·enrollDate 같은 참조형은 별도 초기화 없으면 null, int는 0, boolean은 false다. 세 문자열 생성자도 enrollDate는 null로 남는다.

**생성자를 하나도 선언하지 않았을 때만** 컴파일러가 기본 생성자를 추가한다. 매개변수 생성자를 만들고 new User()도 쓰려면 인자 없는 생성자를 직접 작성한다. 매개변수 구성이 다르면 여러 생성자를 둘 수 있다.
