배열 정렬은 값의 위치를 바꾸는 절차이고 객체 설계는 데이터와 그 데이터를 다루는 동작을 묶는 과정이다. 두 경우 모두 내부 상태를 어떤 규칙으로 변경하는지 명확해야 한다.

## ☘️ 교환과 정렬의 과정

두 값을 교환할 때 한쪽에 먼저 덮어쓰면 원래 값을 잃는다. 임시 변수에 하나를 보관한 뒤 다른 값을 옮기고 마지막에 임시값을 넣는다. 선택 정렬은 아직 정렬하지 않은 구간에서 가장 작은 값을 찾아 현재 위치와 교환한다. 한 회차가 끝날 때 앞쪽 한 칸이 확정된다.

버블 정렬은 이웃한 값을 비교해 순서가 반대면 교환한다. 한 번 끝까지 지나가면 큰 값이 뒤로 이동하므로 다음 회차의 비교 범위를 줄일 수 있다. 아래 두 정렬은 같은 함수를 이름만 바꾼 것이 아니라 비교 대상과 확정되는 위치가 다르다.

로또 번호는 범위 안의 난수를 뽑고 이미 뽑은 값인지 검사한다. 중복을 허용하지 않는 조건과 정렬해서 보여 주는 작업은 별개다. seed를 고정한 예제 결과를 실제 매번 달라지는 추첨과 혼동하지 않는다.

## ☘️ 클래스와 캡슐화

클래스는 객체의 필드와 메서드를 정의하고 new는 실제 객체를 만든다. 객체별로 보관할 값은 필드, 그 값을 다루는 규칙은 메서드로 둔다. private 필드는 외부에서 직접 접근할 수 없게 하고 getter·setter를 통해 허용한 읽기와 변경을 제공한다.

setter의 목적은 단순 대입만이 아니다. Children의 나이에 음수를 넣지 못하게 검사하면 잘못된 상태를 막을 수 있다. 외부에서 필드를 직접 바꾸도록 열어 두면 이 검사 경로를 건너뛸 수 있다.

## ☘️ 생성자와 객체의 협력

생성자는 객체를 만들 때 초기 상태를 정한다. 직접 생성자를 하나라도 작성하면 매개변수 없는 생성자가 자동으로 추가되지 않는다. 필요한 생성 형태를 명시해야 한다. this는 현재 객체를 가리켜 매개변수와 필드 이름이 같을 때 구분한다.

Car는 시동과 속도 규칙을, CarRacer는 운전 요청을 담당한다. 운전자가 자동차 내부 필드를 직접 조작하지 않고 메서드로 요청하면 시동을 걸어야 가속할 수 있다는 조건을 자동차 안에 모을 수 있다. 역할 분리는 파일 개수를 늘리는 것이 아니라 상태 변경 규칙의 위치를 정하는 일이다.

## ☘️ 정렬·객체·캡슐화를 연결하기

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.util.Arrays;
import java.util.Random;

public class Main {
  public static void main(String[] args) {
    int[] values = {2, 5, 4, 6, 1, 3};
    for (int value : values) value += 10;
    System.out.println(Arrays.toString(values));
    for (int i = 0; i < values.length - 1; i++) {
      int min = i;
      for (int j = i + 1; j < values.length; j++) if (values[j] < values[min]) min = j;
      int temp = values[i];
      values[i] = values[min];
      values[min] = temp;
    }
    System.out.println(Arrays.toString(values));
    int[] bubble = {2, 7, 3, 6, 1, 4};
    for (int end = bubble.length - 1; end > 0; end--)
      for (int j = 0; j < end; j++)
        if (bubble[j] > bubble[j + 1]) {
          int temp = bubble[j];
          bubble[j] = bubble[j + 1];
          bubble[j + 1] = temp;
        }
    System.out.println(Arrays.toString(bubble));
    int[] lotto = new int[6];
    int index = 0;
    Random random = new Random(1);
    while (index < lotto.length) {
      int number = random.nextInt(45) + 1;
      boolean duplicate = false;
      for (int i = 0; i < index; i++)
        if (lotto[i] == number) {
          duplicate = true;
          break;
        }
      if (!duplicate) lotto[index++] = number;
    }
    Arrays.sort(lotto);
    System.out.println(Arrays.toString(lotto));
    Children child = new Children();
    child.setAge(-10);
    System.out.println(child.getAge());
    User empty = new User(), named = new User("user02", "예제 사용자");
    System.out.println(empty.info() + " / " + named.info());
    CarRacer racer = new CarRacer();
    racer.stepAccelerator();
    racer.startUp();
    racer.stepAccelerator();
    racer.turnOff();
    racer.stepBrake();
    racer.turnOff();
  }
}

class Children {
  private int age;

  public void setAge(int age) {
    if (age >= 0) this.age = age;
    else {
      System.out.println("나이는 음수일 수 없습니다.");
      this.age = 0;
    }
  }

  public int getAge() {
    return age;
  }
}

class User {
  private String id, name;

  public User() {}

  public User(String id, String name) {
    this.id = id;
    this.name = name;
  }

  public String info() {
    return id + ": " + name;
  }
}

class Car {
  private boolean isOn;
  private int speed;

  public void startUp() {
    isOn = true;
  }

  public void go() {
    if (!isOn) System.out.println("시동을 먼저 걸어주세요");
    else {
      speed += 10;
      System.out.println("속도: " + speed);
    }
  }

  public void stop() {
    if (isOn) speed = 0;
  }

  public void turnOff() {
    if (speed > 0) System.out.println("먼저 멈춰주세요");
    else {
      isOn = false;
      System.out.println("시동 종료");
    }
  }
}

class CarRacer {
  private final Car car = new Car();

  public void startUp() {
    car.startUp();
  }

  public void stepAccelerator() {
    car.go();
  }

  public void stepBrake() {
    car.stop();
  }

  public void turnOff() {
    car.turnOff();
  }
}
```

선택 정렬은 아직 정렬하지 않은 구간에서 가장 작은 값을 찾아 앞과 교환한다. 버블 정렬은 이웃한 두 값을 비교하며 큰 값을 뒤로 보낸다. 두 방법 모두 배열 내부 값을 바꾸므로 입력 배열을 복사해 각각 정렬한다. Children은 필드를 private으로 두고 setter에서 허용하는 나이인지 검사한다. User의 생성자는 객체가 만들어질 때 초기값을 정하며 this는 현재 객체를 가리킨다. CarRacer는 Car를 받아 자동차의 동작을 호출한다. 역할을 나누면 운전자가 자동차의 내부 상태를 직접 바꿀 필요가 줄어든다.
