## ☘️ HTML로 글과 목록 표현하기

HTML은 웹 페이지의 내용과 구조를 나타내는 언어다. 브라우저는 HTML 문서를 읽고 제목, 문단, 이미지, 입력 칸 등을 화면에 표시한다. 태그는 내용의 역할을 나타낸다. 보통 여는 태그와 닫는 태그 사이에 내용을 두며, 태그에 붙이는 속성은 요소에 필요한 추가 정보를 제공한다.

문서의 `head`에는 문자 인코딩과 페이지 제목처럼 문서에 대한 정보를 두고, `body`에는 화면에 표시할 내용을 둔다. 수업 파일은 한글을 포함한 문자를 표현하기 위해 문자 인코딩을 UTF-8로 지정했다.

**제목과 문단**

`h1`부터 `h6`까지는 제목의 단계다. 숫자가 커질수록 더 낮은 단계의 제목을 나타낸다. `p`는 하나의 문단이며 `br`은 문단 안에서 줄을 바꾼다. `hr`은 주제가 바뀌는 지점 등을 구분한다. `pre`는 입력한 공백과 줄바꿈을 그대로 보존해 표시한다.

`strong`은 내용이 중요하다는 뜻이고 `em`은 강조하는 뜻이다. 화면에서는 주로 굵게 또는 기울여 표시되지만, 태그의 의미도 함께 전달된다. `b`와 `i`는 각각 굵은 글씨와 기울인 글씨로 표시하는 데 썼다. `mark`는 눈에 띄게 표시할 내용, `del`은 삭제된 내용을 나타낸다.

**목록**

`ul`은 순서가 중요하지 않은 목록, `ol`은 순서가 있는 목록이다. 두 목록 모두 각 항목을 `li`로 작성한다. 수업에서는 쇼핑 목록을 `ul`로, 조리 순서를 `ol`로 표현했다. 같은 목록이라도 순서가 의미에 필요한지에 따라 태그를 고른다.

## ☘️ 표, 이미지와 링크

**표의 구조**

`table`은 표 전체를 감싸고, `caption`은 표의 제목을 나타낸다. `thead`에는 제목 행을, `tbody`에는 본문 행을 둔다. 행은 `tr`, 제목 셀은 `th`, 일반 데이터 셀은 `td`로 표현한다. `rowspan`은 한 셀이 여러 행을 차지하게 하고 `colspan`은 여러 열을 차지하게 한다.

수업의 시간표는 같은 수업이 두 교시에 걸치는 셀에 `rowspan="2"`를, 여러 요일에 걸친 셀에 `colspan="2"`를 사용했다. 원본에서는 `thead`를 `tbody` 안에 넣었는데, 표의 머리와 본문은 각각 `table`의 자식으로 나누는 것이 올바른 구조다. 메뉴 목록 과제도 표 제목과 메뉴 정보, 전체 메뉴 수를 이 태그들로 구성했다.

**이미지와 미디어**

`img`의 `src`는 이미지 파일의 위치이고 `alt`는 이미지를 볼 수 없을 때 대신 전달할 설명이다. `width`와 `height`로 표시 크기를 지정할 수 있다. `figure`는 이미지처럼 독립적으로 설명할 수 있는 콘텐츠를 묶고, `figcaption`은 그 설명을 붙인다. 메뉴 과제에서는 햄버거 이미지와 대표 메뉴 설명을 함께 묶었다.

`audio`와 `video`는 각각 소리와 영상을 삽입한다. `src`로 파일을 지정하고 `controls`를 붙이면 사용자가 재생과 정지 등을 조작할 수 있다.

**링크**

`a`의 `href`는 이동할 주소다. 다른 웹사이트의 주소나 같은 폴더 안의 파일을 지정할 수 있다. `target="_blank"`는 새 탭을 여는 데 사용했다. `href`에 `#`과 대상의 `id`를 붙이면 같은 페이지의 해당 위치로 이동한다. 메뉴 관리 페이지의 상단 링크는 소개, 카테고리, 메뉴 목록, 메뉴 등록 영역으로 이동하도록 연결했다.

## ☘️ 폼과 입력값

폼은 사용자가 입력한 값을 모아 전송하기 위한 영역이다. `form`의 `action`은 전송할 대상, `method`는 전송 방식을 지정한다. 수업에서는 `method="post"`를 사용했다. 화면에 입력 칸을 만드는 것만으로 실제 서버에 메뉴가 저장되는 것은 아니며, 값을 받을 서버의 처리가 필요하다.

`fieldset`은 관련 입력들을 묶고 `legend`는 그 묶음의 이름을 표시한다. 각 입력 옆의 `label`은 무엇을 입력하는 칸인지 알려 준다. 수업의 메뉴 등록 폼에서는 다음과 같이 연결했다.

```html
<label for="menu-name">메뉴명</label>
<input type="text" id="menu-name" name="menuName" placeholder="메뉴명을 입력하세요" />
```

`label`의 `for`와 입력 칸의 `id`가 같으므로 라벨을 눌러도 연결된 칸에 포커스가 간다. 포커스는 현재 키보드 입력을 받을 대상이다. 이 연결은 보조 기술이 입력 칸의 이름을 파악하는 데도 도움이 된다. `placeholder`는 입력 전 표시되는 힌트다.

폼을 전송할 때 `name`은 해당 입력값을 구분하는 이름이다. 위 입력값은 `menuName`이라는 이름으로 전달된다. `id`는 문서 안의 요소 식별과 라벨 연결에, `name`은 전송할 값을 구분하는 데 쓰인다. React의 JSX에서는 `for` 대신 `htmlFor`를 사용한다.

**입력 종류**

- `type="text"`는 일반 글자, `password`는 비밀번호 입력에 사용한다. `number`는 숫자 입력에 사용한다.
- `required`가 있으면 해당 입력이 비었을 때 브라우저가 제출을 막고 입력을 요구한다.
- `select`는 선택 목록이며 각 선택지는 `option`으로 만든다. 선택지의 `value`가 전송할 값이다.
- `radio`는 같은 `name`을 가진 선택지 중 하나를 고를 때 쓴다. `checked`는 처음 선택된 상태를 지정한다.
- `checkbox`는 선택 여부를 나타내며 여러 항목을 각각 고를 수 있다.
- `textarea`는 여러 줄의 글을 입력한다. `button`의 `submit`은 폼을 제출하고 `reset`은 입력을 기본 상태로 되돌린다.

## ☘️ 페이지 영역과 의미

`div`는 영역을 묶는 일반적인 블록 요소다. 기본적으로 새 줄에서 시작한다. `span`은 문장 안의 일부를 묶는 일반적인 인라인 요소로, 기본적으로 같은 줄에서 내용만큼의 공간을 차지한다. 둘 다 자체로는 그 영역의 구체적인 역할을 설명하지 않는다.

시멘틱 태그는 영역의 역할을 이름으로 드러낸다. 수업의 프로필 페이지에서는 `header`에 페이지 머리말, `nav`에 이동 링크, `main`에 주요 내용, `section`에 소개와 보유 기술, `footer`에 하단 정보를 두었다. 이렇게 역할을 나타내면 사람과 브라우저, 보조 기술이 문서 구조를 파악하는 데 도움이 된다.
