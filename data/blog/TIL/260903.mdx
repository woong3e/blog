### label과 input 연결

```
<label for="user_id">라벨 클릭</label> <input id="user_id" />
```

<label htmlFor="user_id">라벨 클릭</label>
<input id="user_id" />

label의 for 속성과 input의 id 속성의 값을 같도록 하면 label을 클릭해도 input으로 포커싱된다. 접근성 향상돼서 좋음.

# 🍀 input의 name 속성
