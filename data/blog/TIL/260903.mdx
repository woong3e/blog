HTML은 웹 문서의 내용과 구조를 표시한다. 제목·문단·목록·표·입력 폼을 태그로 구분하면 브라우저가 각 부분의 의미를 해석한다. 글자 크기나 색을 정하는 CSS, 사용자의 행동에 반응하는 JavaScript와 역할을 나누어 이해한다.

## ☘️ 문서의 바깥 구조와 내용의 의미

doctype은 HTML 문서임을 알리고 html은 문서 전체를 감싼다. lang은 문서의 주 언어다. head에는 문자 인코딩, 화면 크기 설정, 탭에 보이는 title 같은 정보를 넣는다. body에는 실제 화면에 표시할 내용을 둔다. UTF-8 설정은 한글을 포함한 문자를 올바르게 읽도록 한다.

h1부터 h6까지는 제목의 단계이며 단순히 글자를 크게 만드는 용도가 아니다. p는 문단, br은 문단 내부 줄바꿈, strong은 중요한 내용이다. ul은 순서가 없는 목록, ol은 순서가 있는 목록이며 각 항목은 li로 표시한다. 태그는 여는 위치와 닫는 위치가 맞아야 하고 다른 요소를 넣을 때도 포함 관계를 지킨다.

header·nav·main·section·footer는 머리말·탐색·주요 내용·주제별 영역·바닥글을 구분한다. div와 span은 별도 의미를 부여하지 않는 묶음이다. 같은 모양을 만들 수 있어도 내용의 역할에 맞는 태그를 선택하면 문서 구조를 읽기 쉽다.

## ☘️ 표·미디어·링크의 연결

table은 표 전체, tr은 행, th는 제목 칸, td는 데이터 칸이다. thead와 tbody로 머리와 본문 행을 구분하고 caption으로 표의 주제를 붙인다. colspan은 가로로 합칠 칸 수, rowspan은 세로로 합칠 칸 수다. 칸을 합친 뒤에도 행과 열의 대응을 맞춰야 한다.

img의 src는 이미지 위치이고 alt는 이미지를 보지 못할 때 내용을 설명하는 대체 글이다. audio와 video의 controls는 재생 조작을 표시한다. HTML에 경로를 적는 것과 실제 파일이 존재하는 것은 별개다. 아래 예제는 원본 커밋의 미디어 주소를 사용하므로 네트워크가 필요하다.

a의 href는 이동할 주소다. # 뒤에 id를 적으면 같은 문서의 해당 요소로 이동한다. id는 한 문서에서 요소 하나를 구분하고 class는 여러 요소에 같은 분류를 붙이는 데 사용한다.

## ☘️ 폼이 보내는 이름과 값

form의 action은 전송할 위치, method는 전송 방식을 정한다. GET은 입력값을 주소의 쿼리 문자열로 보내고 POST는 보통 요청 본문에 보낸다. 입력 UI를 만들었다고 서버 저장이 구현되는 것은 아니다. 서버가 해당 요청을 받아 처리하는 코드가 별도로 있어야 한다.

input의 type은 문자·숫자·선택 등 입력 형태를 정한다. name은 전송할 값의 이름이고 value는 전송값이다. label의 for는 input의 id와 연결한다. radio는 같은 name을 공유하는 항목 중 하나를, checkbox는 각 항목의 선택 여부를 다룬다. select의 선택값은 option의 value이며 textarea는 여러 줄 입력이다.

required는 빈 입력 제출을 브라우저가 막도록 한다. 이 검사는 사용자 편의를 위한 것으로 서버의 입력 검사를 대신하지 않는다. submit 버튼은 폼을 제출하고 reset은 처음 기본값으로 되돌린다. 아래 폼은 GET으로 보내 주소에서 name과 value의 대응을 확인한다.

## ☘️ HTML 문서와 입력 폼을 함께 읽기

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**html-demo.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>메뉴 관리</title>
  </head>
  <body>
    <header>
      <h1>메뉴 관리</h1>
      <nav><a href="#menu-list">목록</a> <a href="#add-menu">등록</a></nav>
    </header>
    <main>
      <section id="menu-list">
        <h2>메뉴 목록</h2>
        <p><strong>판매 상태</strong>를 확인하세요.<br />가격은 원 단위입니다.</p>
        <ul>
          <li>한식</li>
          <li>음료</li>
        </ul>
        <ol>
          <li>메뉴 정보 입력</li>
          <li>등록 요청</li>
        </ol>
        <table>
          <caption>
            등록된 메뉴
          </caption>
          <thead>
            <tr>
              <th>이름</th>
              <th>가격</th>
            </tr>
          </thead>
          <tbody>
            <tr>
              <td>한우딸기국밥</td>
              <td>15000</td>
            </tr>
            <tr>
              <td colspan="2">총 1개</td>
            </tr>
          </tbody>
        </table>
        <figure>
          <img
            src="https://raw.githubusercontent.com/woong3e/sesac_lecture/6e71bcd58de0a8ed852ff8935019b0df497c3491/01_html/sample/image/hamburger.jpg"
            alt="대표 메뉴 햄버거"
            width="300"
          />
          <figcaption>대표 메뉴</figcaption>
        </figure>
        <audio
          src="https://raw.githubusercontent.com/woong3e/sesac_lecture/6e71bcd58de0a8ed852ff8935019b0df497c3491/01_html/sample/audio/major.mp3"
          controls
        ></audio>
        <video
          src="https://raw.githubusercontent.com/woong3e/sesac_lecture/6e71bcd58de0a8ed852ff8935019b0df497c3491/01_html/sample/video/video1.mp4"
          controls
          width="300"
        ></video>
      </section>
      <section id="add-menu">
        <h2>메뉴 등록</h2>
        <form action="#add-menu" method="get">
          <fieldset>
            <legend>신규 메뉴 정보</legend>
            <div>
              <label for="menu-name">메뉴명</label
              ><input id="menu-name" name="menuName" type="text" required placeholder="메뉴명" />
            </div>
            <div>
              <label for="menu-price">가격</label
              ><input id="menu-price" name="menuPrice" type="number" />
            </div>
            <label for="category">분류</label
            ><select id="category" name="category">
              <option value="korean">한식</option>
              <option value="drink">음료</option>
            </select>
            <input id="selling" type="radio" name="status" value="Y" checked /><label for="selling"
              >판매중</label
            >
            <input id="soldout" type="radio" name="status" value="N" /><label for="soldout"
              >품절</label
            >
            <input id="featured" type="checkbox" name="featured" value="Y" /><label for="featured"
              >추천</label
            >
            <label for="description">설명</label
            ><textarea id="description" name="description"></textarea>
            <button type="submit">전송값 확인</button><button type="reset">초기화</button>
          </fieldset>
        </form>
      </section>
    </main>
    <footer><span>메뉴 관리 예제</span></footer>
  </body>
</html>
```

head는 문자 인코딩과 탭 제목 등 문서 정보를 담고 body는 화면 내용을 담는다. nav의 링크는 같은 문서의 id로 이동한다. 표는 thead와 tbody로 제목 행과 데이터 행을 나누고 colspan으로 가로 칸을 합친다. label의 for와 입력의 id가 연결되어 글자를 눌러도 해당 입력을 선택할 수 있다. radio는 name이 같아야 한 개만 선택하고 checkbox는 여러 값을 선택할 수 있다. 이 예제의 form은 전송값을 주소에서 살펴보도록 GET으로 정리했다. 별도 서버에 저장하는 기능은 없으며 제출하면 선택한 name과 value가 쿼리 문자열에 붙는다.

**실행 방법**

html-demo.html로 저장해 브라우저에서 연다. 미디어는 원본 커밋의 주소에서 가져오므로 인터넷 연결이 필요하다.
