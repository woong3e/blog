객체가 많아지면 누가 객체를 만들고 어떤 구현을 서로 연결할지 관리하는 코드도 늘어난다. Spring의 핵심 기능은 객체의 생성·연결·수명을 컨테이너에서 관리하게 하는 것이다. 업무 메서드를 실행하는 코드와 객체를 준비하는 설정을 나누어 이해한다.

## ☘️ 컨테이너와 빈 등록

컨테이너는 설정에 따라 객체를 만들고 보관한다. 이 관리 대상 객체를 빈이라고 한다. ApplicationContext는 빈을 등록·조회하는 대표 인터페이스다. 생성과 연결의 주도권을 사용하는 코드 바깥으로 옮기는 방식을 IoC, 제어의 역전이라고 부른다.

XML에서는 bean의 클래스와 생성자 인수를 적는다. Java 설정에서는 @Configuration 클래스의 @Bean 메서드가 반환한 객체를 등록한다. 컴포넌트 스캔은 지정 범위에서 @Component와 관련 표식이 붙은 클래스를 찾아 등록한다. @Service·@Repository·@Controller는 역할을 드러내는 등록 표식이다. 타입이 존재한다는 이유만으로 모든 객체가 자동 등록되는 것은 아니다.

아래 XML과 Java 설정은 별도 컨텍스트로 실행된다. XML 컨텍스트의 Member와 Java 설정의 Member를 같은 객체라고 가정하지 않는다. 빈의 공유 범위도 해당 컨테이너를 기준으로 이해해야 한다.

## ☘️ 의존성 주입과 후보 선택

의존성은 객체가 작업할 때 사용하는 다른 객체다. MemoService가 저장을 위해 MemoRepository를 사용하면 저장소에 의존한다. 의존성 주입은 서비스 내부에서 저장소를 고정 생성하지 않고 바깥에서 전달하는 것이다. 생성자 주입은 필요한 객체가 매개변수에 드러나고 생성 시점에 준비된다.

서비스가 인터페이스를 받으면 설정에서 실제 MemoryMemoRepository를 선택할 수 있다. 사용하는 동작과 만드는 방법을 분리하는 이유다. setter 주입은 생성 후 메서드로 연결하고 필드 주입은 필드에 직접 연결한다. 생성자가 하나인 등록 클래스는 생성자 주입에서 @Autowired를 생략할 수 있다.

같은 타입의 빈이 여러 개이면 후보 선택이 필요하다. @Primary는 기본 우선 후보를, @Qualifier는 특정 후보를 지정한다. 아래는 같은 String 타입의 파이리와 피카츄를 등록하고 명시한 피카츄를 받는다. 실제 학습 코드의 Pokemon 구현 관계를 후보 선택 자체에 집중하도록 줄인 부분이다.

## ☘️ 빈 범위·생명주기·설정값

기본 singleton 범위는 같은 컨테이너에서 같은 빈을 공유한다. prototype은 조회할 때 새 객체를 만든다. 장바구니가 서로 달라야 하는지 같은 값을 공유해야 하는지에 따라 범위를 판단한다. singleton 객체에 변경 가능한 사용자별 상태를 넣으면 서로 영향을 줄 수 있다.

초기화 메서드는 빈이 준비될 때, 종료 메서드는 컨테이너가 닫힐 때 필요한 작업을 수행한다. 아래 Owner는 가게 열기와 닫기로 시점을 보여 준다. prototype은 생성 이후의 정리까지 singleton과 똑같이 관리된다고 가정하지 않는다.

@PropertySource는 설정 파일을 읽고 @Value는 그 안의 값을 주입한다. 문자열 가격도 대상 타입이 int이면 변환이 필요하다. 속성 파일의 인코딩을 명시하고 필수 키가 실제로 준비되어 있는지 확인한다.

## ☘️ AOP로 공통 작업 붙이기

로그나 시간 측정은 여러 업무에 반복되지만 업무 계산 자체와는 다른 관심사다. AOP는 적용할 메서드 범위와 그 앞뒤에 실행할 공통 작업을 분리한다. Aspect는 공통 처리 묶음, Pointcut은 적용 범위, Advice는 실행할 처리다.

Before는 실행 전, AfterReturning은 정상 반환 후, AfterThrowing은 예외가 밖으로 전달될 때, After는 종료 시 처리한다. Around는 실행 전후를 감싸고 proceed로 실제 대상 메서드를 진행한다. proceed를 호출하지 않으면 원래 업무가 실행되지 않을 수 있다. 결과를 반환하고 예외를 전달하는 의미도 유지해야 한다.

Spring의 AOP는 보통 컨테이너가 제공한 프록시를 통해 적용된다. 직접 new로 만든 객체나 같은 객체 내부의 호출은 외부에서 프록시를 통과한 호출과 다를 수 있다. 아래 main은 컨테이너에서 받은 MemoService를 호출해 로그와 업무 결과가 이어지는 것을 확인한다.

## ☘️ 빈 등록·주입·수명·AOP의 전체 연결

서로 다른 학습 프로젝트에 나뉜 빈 등록과 주입, 범위, 생명주기, AOP 동작을 작은 프로젝트 하나로 정리했다. Member의 계좌는 연결 관계만 보도록 문자열로 줄였고 저장소는 메모리를 사용한다. 이는 원본 계좌 업무 로직 전체를 옮긴 예제가 아니다.

**src/main/java/example/Main.java**

```java
package example;

import java.util.ArrayList;
import java.util.List;
import org.aspectj.lang.ProceedingJoinPoint;
import org.aspectj.lang.annotation.After;
import org.aspectj.lang.annotation.AfterReturning;
import org.aspectj.lang.annotation.AfterThrowing;
import org.aspectj.lang.annotation.Around;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Before;
import org.aspectj.lang.annotation.Pointcut;
import org.springframework.beans.factory.annotation.Qualifier;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.context.annotation.EnableAspectJAutoProxy;
import org.springframework.context.annotation.Primary;
import org.springframework.context.annotation.PropertySource;
import org.springframework.context.annotation.Scope;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class Main {
  public static void main(String[] args) {
    try (ClassPathXmlApplicationContext context =
        new ClassPathXmlApplicationContext("context.xml")) {
      System.out.println(context.getBean("xmlMember", Member.class).name);
    }
    try (AnnotationConfigApplicationContext context =
        new AnnotationConfigApplicationContext(Config.class)) {
      Member member = context.getBean(Member.class);
      System.out.println(member.name + ": " + member.account);
      MemoService service = context.getBean(MemoService.class);
      service.add("첫 메모");
      System.out.println(service.findAll());
      Cart first = context.getBean("cart", Cart.class),
          second = context.getBean("cart", Cart.class);
      first.items.add("붕어빵");
      System.out.println(first == second);
      System.out.println(context.getBean("sharedCart") == context.getBean("sharedCart"));
      System.out.println(context.getBean("selectedPokemon", String.class));
      System.out.println(context.getBean("product", String.class));
    }
  }

  public static class Member {
    public final String name, account;

    public Member(String name, String account) {
      this.name = name;
      this.account = account;
    }
  }

  public static class Cart {
    public final List<String> items = new ArrayList<>();
  }

  public interface MemoRepository {
    void save(String value);

    List<String> findAll();
  }

  public static class MemoryMemoRepository implements MemoRepository {
    private final List<String> values = new ArrayList<>();

    public void save(String value) {
      values.add(value);
    }

    public List<String> findAll() {
      return new ArrayList<>(values);
    }
  }

  public static class MemoService {
    private final MemoRepository repository;

    public MemoService(MemoRepository repository) {
      this.repository = repository;
    }

    public void add(String value) {
      repository.save(value);
    }

    public List<String> findAll() {
      return repository.findAll();
    }
  }

  public static class Owner {
    public void openShop() {
      System.out.println("가게 열기");
    }

    public void closeShop() {
      System.out.println("가게 닫기");
    }
  }

  @Configuration
  @EnableAspectJAutoProxy
  @PropertySource(value = "classpath:demo.properties", encoding = "UTF-8")
  public static class Config {
    @Bean
    public Member member() {
      return new Member("예제 사용자", "설명용 계좌");
    }

    @Bean
    public MemoRepository repository() {
      return new MemoryMemoRepository();
    }

    @Bean
    public MemoService service(MemoRepository repository) {
      return new MemoService(repository);
    }

    @Bean
    @Scope("prototype")
    public Cart cart() {
      return new Cart();
    }

    @Bean
    public Cart sharedCart() {
      return new Cart();
    }

    @Bean(initMethod = "openShop", destroyMethod = "closeShop")
    public Owner owner() {
      return new Owner();
    }

    @Bean
    @Primary
    public String charmander() {
      return "파이리";
    }

    @Bean
    public String pikachu() {
      return "피카츄";
    }

    @Bean
    public String selectedPokemon(@Qualifier("pikachu") String pokemon) {
      return pokemon;
    }

    @Bean
    public String product(
        @Value("${product.name}") String name, @Value("${product.price}") int price) {
      return name + ": " + price;
    }

    @Bean
    public LoggingAspect loggingAspect() {
      return new LoggingAspect();
    }
  }

  @Aspect
  public static class LoggingAspect {
    @Pointcut("execution(* example.Main.MemoService.*(..))")
    public void serviceMethods() {}

    @Before("serviceMethods()")
    public void before() {
      System.out.println("메서드 실행 전");
    }

    @AfterReturning("serviceMethods()")
    public void success() {
      System.out.println("정상 반환 후");
    }

    @AfterThrowing("serviceMethods()")
    public void failure() {
      System.out.println("예외 발생 후");
    }

    @After("serviceMethods()")
    public void after() {
      System.out.println("메서드 종료");
    }

    @Around("serviceMethods()")
    public Object around(ProceedingJoinPoint point) throws Throwable {
      long started = System.nanoTime();
      try {
        return point.proceed();
      } finally {
        System.out.println("시간 측정 완료: " + (System.nanoTime() >= started));
      }
    }
  }
}
```

**src/main/resources/context.xml**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://www.springframework.org/schema/beans https://www.springframework.org/schema/beans/spring-beans.xsd">
  <bean id="xmlMember" class="example.Main$Member"><constructor-arg index="0" value="예제 사용자" /><constructor-arg index="1" value="XML" /></bean>
</beans>
```

**src/main/resources/demo.properties**

```text
product.name=붕어빵
product.price=1000
```

XML 컨텍스트는 context.xml의 생성자 인수를 읽어 Member를 만든다. Java 설정 컨텍스트는 @Bean 메서드의 반환 객체를 관리한다. MemoService는 생성자에서 MemoRepository를 받아 자신의 처리에 사용하므로 저장소 생성 방법을 알 필요가 없다. cart는 prototype으로 조회할 때마다 다른 객체이며 sharedCart는 같은 컨텍스트에서 같은 객체다. Owner의 초기화 메서드는 빈 준비 시, 종료 메서드는 컨텍스트를 닫을 때 호출된다.

기본 우선 후보는 @Primary의 파이리지만 selectedPokemon은 @Qualifier로 피카츄를 명시해 받는다. @Value는 properties의 문자열을 읽고 price는 int로 변환한다. AOP는 MemoService 호출을 가로채 업무 앞뒤에 로그를 붙인다. Around의 proceed가 실제 업무를 실행하고 finally는 정상·예외 모두에서 시간 측정 정리를 수행한다. 같은 호출의 Before·AfterReturning·After 출력은 실행 경계를 구분한다. 예외가 나면 AfterReturning 대신 AfterThrowing의 대상이 된다. 현재 main은 정상 경로를 실행한다.

메서드 실행 전

실행 결과에서 XML 회원 출력 뒤 가게 열기가 나타나고, 서비스 호출마다 실행 전·정상 반환·종료·시간 측정 로그가 이어졌다. 메모 목록은 [첫 메모], prototype 참조 비교는 false, singleton 비교는 true, 선택 후보는 피카츄, 설정값은 붕어빵: 1000이었다. 컨텍스트 종료 시 가게 닫기가 출력됐다.

**실행 방법**

JDK 21과 Gradle 환경에서 표시한 파일을 저장하고 프로젝트 루트에서 `gradle run`을 실행한다. 라이브러리를 처음 받을 때 인터넷이 필요하다. Spring 버전은 학습 프로젝트의 설정을 따른다.
