## ☘️ 단락 평가

앞의 값으로 결과가 정해지면 뒤의 표현식을 평가하지 않는다. 논리 연산의 결과는 피연산자 값일 수 있다.

```js
'apple' || 'banana' // apple: 앞이 truthy라 종료
false || 'banana' // banana: 뒤의 값 사용
'apple' && 'banana' // banana: 앞이 truthy라 뒤 평가
false && 'banana' // false: 앞이 falsy라 종료
```

## ☘️ 객체 키와 폼 상태

`user.name`은 고정된 키, `user[key]`는 변수에 든 키를 사용한다. 공백·숫자로 시작하는 이름처럼 점 표기법에 맞지 않는 키는 대괄호로 접근한다. 식별자에는 `$`, `_`를 쓸 수 있다.

```js
const user = {}
user['likes birds'] = true
console.log(user['likes birds']) // true
delete user['likes birds']
```

**문자열 키에는 따옴표, 변수 키에는 변수 자체**를 넣는다. React 폼에도 같은 원리를 적용할 수 있다.

```jsx
const [form, setForm] = useState({ name: '', email: '', password: '' })
const handleChange = ({ target: { name, value } }) => {
  setForm({ ...form, [name]: value })
}
// 각 input의 name을 상태의 키와 맞춘다.
;<input name="email" value={form.email} onChange={handleChange} />
```

하나의 핸들러로 여러 입력을 갱신하고, 제출할 때도 폼 전체를 객체 하나로 다룬다. 이 폼 예시는 객체 키 활용을 복습한 예시다.
