JavaScript는 값을 계산하고 조건에 따라 작업 순서를 바꾸며 객체에 데이터를 묶을 수 있는 언어다. 코드를 읽을 때는 변수에 어떤 값이 들어 있는지, 식이 무엇을 반환하는지, 다음에 어느 문장이 실행되는지를 순서대로 따라간다.

## ☘️ 값·변수·연산 결과

변수는 값을 가리키는 이름이다. let은 나중에 다른 값을 대입할 수 있고 const는 같은 이름에 다시 대입할 수 없다. const로 객체를 받았다고 객체 내부의 프로퍼티까지 변경할 수 없는 것은 아니다. 선언과 초기화, 이후 대입을 구분한다.

숫자는 산술 계산에, 문자열은 글자 표현에, boolean은 참·거짓 판단에 사용한다. undefined는 아직 값이 주어지지 않은 상태에, null은 비어 있음을 명시할 때 사용한다. typeof는 현재 값의 타입 이름을 문자열로 돌려준다. 문자열 숫자와 실제 숫자는 같은 모양으로 출력되어도 연산 방식이 다를 수 있다.

+는 숫자끼리 더하지만 문자열이 끼면 연결 연산이 될 수 있다. -·\*·/·%는 차·곱·몫·나머지를 구한다. ++가 변수 앞에 있으면 증가한 값을 식에서 사용하고 뒤에 있으면 증가 전 값을 사용한 뒤 변수를 바꾼다. 변수의 최종값과 해당 식의 결과를 따로 추적해야 한다.

==는 타입 변환을 포함한 비교이고 ===는 타입과 값을 함께 비교한다. &&는 모두 참인지, ||는 하나라도 참인지, !는 참·거짓을 뒤집는 데 사용한다. &&와 ||는 오른쪽 평가를 건너뛸 수 있고 boolean 외의 피연산자 값도 반환할 수 있다.

## ☘️ 분기와 반복의 실행 순서

if는 조건을 평가해 참인 블록을 실행한다. else if가 이어지면 먼저 참이 된 하나의 가지를 고르고 나머지는 실행하지 않는다. switch는 값과 case를 비교하며 break를 만나면 빠져나온다. break가 없으면 다음 case의 문장으로 이어질 수 있다.

for는 초기화 → 조건 검사 → 본문 → 증감 → 조건 검사 순서다. continue는 현재 회차의 나머지를 건너뛰고 다음 회차로, break는 반복문 밖으로 이동한다. while은 실행 전에 조건을 검사하므로 처음부터 거짓이면 본문을 한 번도 실행하지 않는다.

## ☘️ 객체의 값과 동작

객체는 이름인 키와 값인 프로퍼티를 묶는다. 점 표기법은 정해진 이름을, 대괄호 표기법은 변수에 들어 있는 이름을 사용할 때 유용하다. 존재하지 않는 프로퍼티를 읽으면 undefined가 나온다. delete는 프로퍼티를 제거한다.

객체 안의 함수를 메서드라고 한다. 일반 메서드를 객체를 통해 호출하면 this로 그 객체의 다른 값을 읽을 수 있다. 객체끼리 ===로 비교할 때는 내용이 같은지가 아니라 같은 객체를 가리키는지 확인한다. 아래 전체 예제의 마지막 출력들은 프로퍼티 접근·메서드 호출·참조 비교를 연결해 보여 준다.

## ☘️ 값과 조건문의 실행 순서

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**js-operators.js**

```js
const a = 10,
  b = 5
console.log(a + b, a - b, a * b, a / b, a % b, a ** b)
let c = 5
c += 3
c -= 2
let d = 5,
  first = 5
console.log(c, d++, ++first, d)
console.log(10 === '10', 10 == '10')
console.log('apple' || 'banana', false || 'banana')
console.log('apple' && 'banana', false && 'banana')
const age = 20
console.log(age >= 20 ? '성인' : '미성년자')
const score = 75
if (score >= 90) console.log('우수')
else if (score >= 70) console.log('보통')
else console.log('보완 필요')
const fruit = '바나나'
switch (fruit) {
  case '바나나':
    console.log('바나나')
    break
  default:
    console.log('없음')
}
const odds = []
for (let i = 1; i <= 5; i++) {
  if (i % 2 === 0) continue
  odds.push(i)
}
console.log(odds.join(','))
let count = 3
while (count > 0) count--
do {
  count++
} while (count < 1)
console.log(count)
const dog = {
  name: '뽀삐',
  eat(food) {
    return `${this.name}: ${food}`
  },
}
const prop = 'name'
console.log(dog.prop, dog[prop], dog.eat('두부'))
dog.age = 5
delete dog.age
console.log('name' in dog, 'age' in dog)
for (const key in dog) {
  if (typeof dog[key] !== 'function') console.log(key, dog[key])
}
```

각 console.log는 식을 먼저 계산하고 결과를 출력한다. 덧셈에서 문자열이 포함되면 숫자 계산 대신 문자열 연결이 일어날 수 있다. 비교식은 boolean을 만들며 if와 switch는 그 값에 따라 실행할 문장을 고른다. 반복문은 초기값에서 시작해 조건을 검사하고 본문과 증감을 반복한다. 중괄호 안에서 선언한 let과 const는 그 범위 밖에서 사용할 수 없다. 객체의 프로퍼티는 점 또는 대괄호로 접근하며 배열 인덱스는 0부터 시작한다.
