## ☘️ 값을 계산하고 조건 만들기

JavaScript의 연산자는 값을 계산하거나 비교하는 기호다. 수업에서는 숫자 계산에서 시작해 조건에 따라 실행 흐름을 나누고, 관련 데이터를 객체로 묶는 과정을 실습했다.

**산술과 값 변경**

`+`, `-`, `*`, `/`는 덧셈·뺄셈·곱셈·나눗셈이다. `%`는 나눈 나머지, `**`는 거듭제곱을 구한다. 수업의 10과 5는 각각 15, 5, 50, 2, 0, 100000이라는 결과를 만든다. `c += 3`은 현재 c에 3을 더해 다시 c에 저장한다는 뜻이고, `c -= 2`는 2를 뺀 결과를 저장한다.

`++`와 `--`는 값을 1씩 늘리거나 줄인다. 뒤에 붙이는 `d++`는 기존 값을 먼저 사용한 뒤 증가하고, 앞에 붙이는 `++d`는 증가한 값을 사용한다. 수업에서 둘 다 5로 시작했지만 출력은 각각 5와 6이었다. 실행 뒤에는 두 변수 모두 6이 된다.

**비교와 논리 연산**

비교의 결과는 참을 나타내는 `true` 또는 거짓을 나타내는 `false`다. `==`와 `!=`는 필요하면 자료형을 바꾸어 비교하고, `===`와 `!==`는 자료형까지 비교한다. 수업의 숫자 10과 문자열 "10"은 `===`로 비교하면 다르다. 문자열도 비교할 수 있지만 사람의 사전 정렬과 언제나 같은 것으로 생각해서는 안 된다.

`&&`는 두 조건이 모두 참인지, `||`는 적어도 하나가 참인지 확인할 때 쓰고 `!`는 참·거짓을 뒤집는다. 원본의 OR 출력 옆 주석은 “모두 true”라고 적혀 있지만, OR는 하나만 true여도 true다.

**단락 평가**는 앞의 값으로 결과가 결정되면 뒤의 계산을 생략하는 동작이다. JavaScript의 논리 연산자는 원래 값 자체를 반환할 수도 있다.

```js
console.log('apple' || 'banana')
console.log(false || 'banana')
console.log('apple' && 'banana')
console.log(false && 'banana')
```

위 결과는 차례로 apple, banana, banana, false다. 비어 있지 않은 문자열은 조건에서 참처럼 취급되므로 첫 OR는 apple에서 끝난다. 첫 AND는 앞이 참처럼 취급되니 뒤를 확인한다. 마지막 AND는 앞이 false여서 뒤를 살펴볼 필요가 없다.

## ☘️ 조건과 반복으로 실행 순서 정하기

`if`는 조건이 참일 때 본문을 실행한다. `else if`를 이어 쓰면 앞에서부터 검사해 처음 해당하는 분기 하나를 실행하고, 모두 해당하지 않으면 `else`를 실행한다. 수업의 점수 75는 90 이상 조건에는 해당하지 않고 70 이상 조건에 해당해 “성적이 보통입니다.”를 출력한다. 범위가 겹치는 조건은 검사 순서가 중요하다.

`조건 ? 값1 : 값2`는 조건이 참이면 값1, 거짓이면 값2를 선택한다. 나이 20의 성인 여부처럼 두 값 중 하나를 정하는 데 썼다. `switch`는 과일 이름처럼 한 값을 여러 후보와 비교한다. 일치한 case부터 실행하며 `break`가 없으면 다음 case의 코드까지 이어질 수 있다. 어느 case에도 해당하지 않을 때는 `default`를 실행한다.

**반복문**

`for`는 초기화 → 조건 검사 → 본문 → 증감 → 조건 재검사 순서로 움직인다. 수업에서는 1부터 5까지 출력하고, 배열의 위치를 0부터 `length - 1`까지 옮기며 과일을 읽었다. 배열 길이는 개수이므로 마지막 위치 자체는 length보다 하나 작다. `% 2 === 0`은 나머지가 없는 짝수를 고르는 조건이다.

`while`은 조건부터 검사한다. count를 3에서 시작해 매번 줄이면 3·2·1을 출력한 뒤 0에서 끝난다. `do...while`은 본문부터 실행하므로 최초 조건과 관계없이 한 번은 실행한다. 반복 중 조건이 바뀌지 않으면 끝나지 않을 수 있으므로 종료에 필요한 값 변경도 확인한다.

`continue`는 이번 회차의 남은 코드를 생략하고 다음 회차로 넘어가고, `break`는 가장 가까운 반복문 자체를 끝낸다. 1~10에서 짝수일 때 continue하면 홀수를 모두 출력하지만, 짝수일 때 break하면 1만 출력한 뒤 2에서 종료한다. 중첩 반복문의 안쪽 continue는 바깥 반복 전체를 건너뛰지 않는다.

## ☘️ 객체로 데이터와 동작 묶기

객체는 키와 값으로 이루어진 **프로퍼티**들을 묶는다. 수업의 학생 객체에는 이름·나이와 정보를 만드는 함수가 함께 들어 있다. 객체의 값으로 저장한 함수를 메서드라고 한다. `student.getInfo()`처럼 객체를 통해 호출한 일반 메서드의 `this`는 호출한 객체를 가리킨다.

프로퍼티를 읽는 방법에는 점 표기법과 대괄호 표기법이 있다. 점 뒤의 이름은 그대로 키로 사용하고, 대괄호 안의 표현식은 계산한 결과를 키로 사용한다.

```js
const prop = 'name'
console.log(dog.prop)
console.log(dog[prop])
```

수업의 dog에는 name이 뽀삐로 저장되어 있다. 첫 줄의 조회는 prop이라는 키를 찾으므로 undefined, 두 번째는 변수 prop에 저장된 name을 키로 사용하므로 뽀삐다. 하이픈이 들어간 `dash-key`나 숫자로 된 키처럼 점 표기법으로 직접 쓰기 어려운 이름에도 대괄호를 사용한다.

기존 프로퍼티에 값을 대입하면 수정되고, 없는 프로퍼티에 대입하면 추가된다. `delete`는 프로퍼티를 제거한다. `const`는 변수에 다른 객체를 다시 대입하지 못하게 할 뿐, 기존 객체 내부의 수정까지 막는 것은 아니다.

`in`은 키의 존재 여부를 확인한다. `for...in`은 객체의 키를 하나씩 꺼내며, 키를 담은 변수로 값을 읽을 때는 대괄호를 사용한다. 이후 여러 입력의 이름에 맞는 객체 상태를 갱신할 때도 이와 같은 동적 키 선택 원리가 쓰인다.
