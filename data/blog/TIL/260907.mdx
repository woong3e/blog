## 🍀 단락평가 short circuit

논리 연산자를 사용할때 첫 번째 피연산자의 값만으로 전체 식의 결과를 알 수 있을때 두 번째 피연산자의 평가를 생략하는 동작방식이다.

```javascript
// OR 연산자
console.log('apple' || 'banana') // 첫번째 값이 true 이고 값이기 때문에 그 뒤는 연산하지 않는다. 반환값 : apple
console.log(false || 'banana') // 첫번째 값이 false 이기 때문에 두 번째 피연산자의 값을 평가하여 반환한다. 반환값: banana

//AND 연산자
console.log('apple' && 'banana') // 첫번째 값이 true 이고 두 번째 값에 의해 평가되어 반영된다. 반환값 : banana
console.log(false && 'banana') // 첫번째 값이 false 이기 때문에 그 뒤는 연산하지 않는다. 반환값 : false
```

## 🍀 객체 대괄호 표기법

프로퍼티 키값이 '유효한 변수 식별자' 인 경우에만 점 표기법을 사용해서 읽을 수 있는데, 그렇지 않은 경우에는 점 표기법으로 읽을 수 없습니다.
예를 들면 '공백을 포함하는 변수명',숫자로 시작하는 변수명, $ , \_ 를 제외한 특수문자가 없어야한다.

이렇게 키가 유효한 변수 식별자가 아닌 경우에는 점 표기법 대신에 대괄호 표기법을 사용한다.
대괄호 표기법은 키에 어떤 문자열이 있던지 상관없이 동작한다.

```javascript
let user = {}

// set
user['likes birds'] = true

// get
alert(user['likes birds']) // true

// delete
delete user['likes birds']
```

대괄호 표기법을 사용하는 경우에는 문자열을 따옴표로 묶어줘야합니다.

user[key]는 key 변수의 값을 사용해서 찾음.

이런 대괄호 표기법은 리액트에서 여러 개의 input을 하나의 객체 state로 관리할 때 사용했던 기억이 있다.

```javascript
① 하나의 객체로 상태 관리
const [form, setForm] = useState({
name: "",
email: "",
password: "",
});

② input의 name을 프로퍼티 이름과 맞추기

<input name="name" />
<input name="email" />
<input name="password" />

③ [name]으로 변경할 프로퍼티를 동적으로 결정하기
setForm({
...form,
[name]: value,
});
```

여러 개의 input을 하나의 객체 상태로 관리하면 폼 데이터를 하나의 상태에서 일관되게 관리할 수 있고,
name 속성과 대괄호 표기법을 활용하여 하나의 onChange 핸들러로 여러 input을 처리할 수 있다.
또한 제출 시 폼 전체 데이터를 하나의 객체로 다룰 수 있다는 장점이 있다.
