컬렉션은 여러 값을 저장하고 찾는 자료구조다. 순서·중복·검색 기준이 다르므로 필요한 동작에 맞게 선택한다. 같은 자료구조라도 정렬 기준이나 키의 동등성 규칙에 따라 결과가 달라진다.

## ☘️ List와 정렬

List는 순서가 있고 같은 값을 여러 번 담을 수 있다. 인덱스로 위치를 읽거나 바꾼다. ArrayList는 배열 기반, LinkedList는 연결 구조 기반이므로 내부 구조가 다르다. 사용 목적 없이 이름만 보고 하나가 항상 빠르다고 판단하지 않는다.

정렬은 두 값 중 무엇을 앞에 둘지 정하는 비교 기준이 필요하다. Comparable은 객체의 기본 비교 규칙을, Comparator는 상황별 별도 비교 규칙을 제공한다. 책 번호순과 가격순처럼 같은 목록을 서로 다른 기준으로 정렬할 수 있다. 비교 결과의 음수·0·양수가 순서를 결정한다.

## ☘️ Set·Stack·Queue·Map

Set은 같은 값의 중복을 제한한다. HashSet은 순서를 보장하지 않고 LinkedHashSet은 삽입 순서를 유지하며 TreeSet은 비교 기준으로 정렬한다. 객체를 넣으면 equals·hashCode 또는 정렬 비교 기준이 중복 판단에 관여한다.

Stack은 마지막에 넣은 값을 먼저 꺼내고 Queue는 먼저 넣은 값을 먼저 꺼낸다. 꺼내면서 제거하는 메서드와 현재 값만 보는 메서드를 구분한다. 비어 있을 때 예외를 던지는지 null을 반환하는지도 메서드별로 확인한다.

Map은 키와 값을 묶는다. 같은 키에 put하면 기존 값이 교체되며 키 하나에 값 하나가 대응한다. keySet은 키, values는 값, entrySet은 키·값 쌍을 순회할 때 사용한다.

## ☘️ 와일드카드와 예외 전달

제네릭의 ? extends Number는 Number의 하위 타입 목록을 받아 Number로 읽는 데 적합하다. 실제 구체 타입을 모르므로 임의의 숫자를 넣을 수 없다. ? super Integer는 Integer를 넣을 수 있지만 읽은 값은 Object 수준으로 다뤄야 한다. 읽기와 쓰기에 필요한 보장을 구분하는 기준이다.

checked 예외는 처리하거나 throws로 전달해야 컴파일된다. throws는 오류를 없애는 것이 아니라 호출자에게 처리 책임을 넘기는 선언이다. 아래 main의 두 번째 금액 검사는 예외를 던지고 잡는 catch가 없으므로 프로그램이 종료된다. 이후 문장이 실행되지 않는 것을 정상 종료와 구분해 읽는다.

## ☘️ 컬렉션 선택과 예외 전달의 차이

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.Deque;
import java.util.LinkedHashMap;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Map;
import java.util.Queue;
import java.util.Set;
import java.util.TreeSet;

public class Main {
  public static void main(String[] args) throws Exception {
    List<String> words = new ArrayList<>(List.of("java", "html", "css", "java"));
    words.set(0, "mysql");
    words.sort(Comparator.naturalOrder());
    System.out.println(words);
    Set<String> inputOrder = new LinkedHashSet<>(words);
    System.out.println(inputOrder);
    Set<String> sorted = new TreeSet<>(words);
    System.out.println(sorted);
    List<BookDTO> books =
        new ArrayList<>(
            List.of(new BookDTO(2, 30000), new BookDTO(1, 50000), new BookDTO(4, 40000)));
    books.sort(Comparator.naturalOrder());
    System.out.println(books);
    books.sort(new AscendingPrice());
    System.out.println(books);
    Set<BookDTO> bookSet = new TreeSet<>(books);
    bookSet.add(new BookDTO(2, 18000));
    System.out.println(bookSet.size());
    Deque<Integer> stack = new ArrayDeque<>();
    stack.push(1);
    stack.push(2);
    stack.push(3);
    while (!stack.isEmpty()) System.out.print(stack.pop() + " ");
    System.out.println();
    Queue<String> queue = new ArrayDeque<>();
    queue.offer("first");
    queue.offer("second");
    System.out.println(queue.poll() + " / " + queue.poll() + " / " + queue.poll());
    System.out.println(sum(List.of(10, 20)));
    List<Number> numbers = new ArrayList<>();
    addInteger(numbers);
    printAnyList(numbers);
    Map<String, String> map = new LinkedHashMap<>();
    map.put("one", "java");
    map.put("two", "jdbc");
    map.put("two", "html");
    for (Map.Entry<String, String> entry : map.entrySet())
      System.out.println(entry.getKey() + "=" + entry.getValue());
    checkEnoughMoney(10000, 30000);
    checkEnoughMoney(50000, 30000);
    System.out.println("이 줄은 실행되지 않습니다.");
  }

  static void printAnyList(List<?> values) {
    for (Object value : values) System.out.println(value);
  }

  static double sum(List<? extends Number> values) {
    double sum = 0;
    for (Number value : values) sum += value.doubleValue();
    return sum;
  }

  static void addInteger(List<? super Integer> values) {
    values.add(100);
  }

  static void checkEnoughMoney(int price, int money) throws Exception {
    System.out.println("보유 금액=" + money);
    if (money < price) throw new Exception("돈이 부족해요.");
    System.out.println("구매 가능");
  }
}

class BookDTO implements Comparable<BookDTO> {
  private final int number, price;

  BookDTO(int number, int price) {
    this.number = number;
    this.price = price;
  }

  int getPrice() {
    return price;
  }

  public int compareTo(BookDTO other) {
    return Integer.compare(number, other.number);
  }

  public String toString() {
    return number + ":" + price;
  }
}

class AscendingPrice implements Comparator<BookDTO> {
  public int compare(BookDTO first, BookDTO second) {
    return Integer.compare(first.getPrice(), second.getPrice());
  }
}
```

List는 순서와 중복을 유지하고 Set은 같은 값의 중복을 제한한다. 정렬은 두 값의 순서를 결정하는 기준을 전달한다. Stack은 마지막에 넣은 값을 먼저, Queue는 먼저 넣은 값을 먼저 꺼낸다. Map은 키로 값을 찾으며 같은 키에 다시 넣으면 이전 값이 바뀐다. 마지막 두 검사는 첫 호출은 통과하고 두 번째 호출은 checked 예외를 발생시킨다. main의 throws는 예외를 처리해 계속 진행하라는 뜻이 아니라 호출 바깥으로 넘기겠다는 뜻이어서 두 번째 호출에서 프로그램이 종료된다. 이 예제의 비정상 종료는 의도된 동작이다.

**실행 방법**

JDK 21 환경에서 파일명을 `Main.java`로 저장한다. 같은 폴더에서 `javac -encoding UTF-8 Main.java`로 컴파일한 뒤 `java -Dfile.encoding=UTF-8 Main`을 실행한다. 글마다 Main 클래스가 있으므로 예제는 서로 다른 폴더에 저장한다.
