과제의 결과를 이해하려면 계산식을 외우기보다 입력·조건·반복·반환을 나누어 추적해야 한다. 아래 코드는 변수와 연산, 메서드, 조건과 반복, 배열, 객체 생성 과제를 한 파일에서 확인하도록 정리했다.

## ☘️ 계산식과 메서드의 결과

정수끼리 계산한 나눗셈은 소수 부분을 보관하지 않는다. 평균을 실수로 구하려면 계산 전에 실수 타입이 포함되게 한다. 형변환을 결과에 적용하는 것과 피연산자에 먼저 적용하는 것은 다를 수 있다.

메서드가 return으로 돌려준 값은 호출자의 다음 계산에 쓰인다. 출력만 하는 메서드와 값을 반환하는 메서드를 구분하고 선언한 반환 타입에 맞는 값을 돌려준다. 조건에 따라 일찍 반환하면 나머지 문장은 실행하지 않는다.

## ☘️ 조건의 우선순위와 반복 누적

점수 등급은 높은 구간부터 검사해야 넓은 낮은 기준에 먼저 포함되지 않는다. 홀짝은 2로 나눈 나머지로 구분한다. 합계·개수·문자열 반복은 각각 누적 변수의 역할이 다르다. 매 회차 무엇이 얼마나 바뀌는지 정하면 반복이 끝난 뒤 결과를 계산할 수 있다.

급여 계산에서는 기본 금액과 비율을 곱한 추가 금액을 구분한다. 표시할 문자열과 계산에 사용하는 숫자를 섞지 않아야 한다. 같은 모양의 출력이라도 숫자를 먼저 계산했는지 문자열로 연결했는지에 따라 결과가 달라진다.

## ☘️ 배열과 숫자 야구의 판정

배열의 위치는 0부터 시작하고 마지막 위치는 길이에서 1을 뺀 값이다. 앞에서 증가하다 뒤에서 감소하는 형태는 가운데 위치를 기준으로 두 구간을 나누어 채울 수 있다.

숫자 야구에서 같은 위치에 같은 숫자가 있으면 스트라이크, 다른 위치에 해당 숫자가 있으면 볼이다. 정답과 입력을 이중 반복으로 비교하되 같은 일치 건을 두 번 세지 않도록 판정한다. 정답은 시도마다 새로 뽑는 값이 아니라 게임 동안 유지할 값이다. 아래 예제는 판정이 드러나도록 정답과 세 입력을 고정했다.

## ☘️ DTO와 생성자의 초기값

DTO는 여러 값을 한 묶음으로 전달하는 객체다. BookDTO는 제목·출판사·저자·가격·할인율을 가진다. 기본 생성자는 타입의 기본값을 유지하고 일부 값을 받는 생성자는 전달받은 필드만 초기화하며 전체 생성자는 모든 필드를 정한다.

getter는 저장된 값을 반환하고 setter는 해당 필드를 변경한다. 객체를 생성한 시점의 값과 이후 변경한 값을 구분해야 한다. 아래 전체 코드는 main의 호출부와 BookDTO 정의를 모두 포함하므로 생성자별 출력 차이를 직접 따라갈 수 있다.

## ☘️ 연산부터 숫자 야구까지 완결된 풀이 흐름

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**Main.java**

```java
import java.util.Arrays;

public class Main {
  public static void main(String[] args) {
    int a = 20, b = 30;
    System.out.println((a + b) + "," + (a - b) + "," + (a * b) + "," + (a / b) + "," + (a % b));
    double width = 12.5, height = 36.4, area = width * height, perimeter = (width + height) * 2;
    System.out.println(area + "," + perimeter + "," + (int) 'a');
    int total = (int) (80.5 + 50.6 + 70.8);
    System.out.println(total + "," + total / 3);
    System.out.println(a > b ? a : b);
    System.out.println(60 >= 60 ? "합격" : "불합격");
    System.out.println(-3 % 2 == 0 ? "짝수" : "홀수");
    int grade = (int) 89.9 / 10;
    System.out.println(
        switch (grade) {
          case 9, 10 -> "A";
          case 8 -> "B";
          case 7 -> "C";
          case 6 -> "D";
          default -> "F";
        });
    int month = 7, day = 16;
    System.out.println(
        month >= 1 && month <= 6 && day >= 1 && day <= 15
            ? "배민 쿠폰"
            : month >= 7 && month <= 12 && day >= 16 && day <= 31 ? "스타벅스 커피" : "사탕");
    Calculator calculator = new Calculator();
    calculator.checkMethod();
    System.out.println(calculator.sum1to10());
    calculator.checkMaxNumber(10, 20);
    System.out.println(calculator.sumTwoNumber(10, 20));
    System.out.println(calculator.minusTwoNumber(10, 5));
    int kor = 60, eng = 30, math = 20;
    double average = (kor + eng + math) / 3.0;
    if (average >= 60 && kor >= 40 && eng >= 40 && math >= 40) System.out.println("합격");
    else {
      if (average < 60) System.out.println("평균 미달");
      if (kor < 40) System.out.println("국어 과락");
      if (eng < 40) System.out.println("영어 과락");
      if (math < 40) System.out.println("수학 과락");
    }
    int salary = 3_000_000, revenue = 20_000_000;
    double rate =
        revenue >= 50_000_000 ? .05 : revenue >= 30_000_000 ? .03 : revenue >= 10_000_000 ? .01 : 0;
    System.out.println("보너스=" + (int) (revenue * rate) + ",총급여=" + (int) (salary + revenue * rate));
    for (int i = 1; i <= 5; i++) System.out.print(i % 2 == 1 ? "수" : "박");
    System.out.println();
    int n = 7;
    int[] mountain = new int[n];
    if (n <= 0 || n % 2 == 0) throw new IllegalArgumentException("양의 홀수만 허용");
    for (int i = 0; i < n; i++) mountain[i] = i <= n / 2 ? i + 1 : n - i;
    System.out.println(Arrays.toString(mountain));
    int[] answer = {7, 4, 1, 6};
    for (int guess : new int[] {1234, 5678, 7416}) {
      if (guess < 1000 || guess > 9999) continue;
      int[] digits = new int[4];
      int value = guess;
      for (int i = 3; i >= 0; i--) {
        digits[i] = value % 10;
        value /= 10;
      }
      int strikes = 0, balls = 0;
      for (int i = 0; i < 4; i++)
        for (int j = 0; j < 4; j++)
          if (digits[i] == answer[j]) {
            if (i == j) strikes++;
            else balls++;
          }
      System.out.println(strikes + "S " + balls + "B");
      if (strikes == 4) break;
    }
    new BookDTO().printInformation();
    new BookDTO("자바의 정석", "도우출판", "남궁성").printInformation();
    new BookDTO("홍길동전", "활빈당", "허균", 5_000_000, .5).printInformation();
  }
}

class Calculator {
  void checkMethod() {
    System.out.println("메소드 호출 확인");
  }

  int sum1to10() {
    int sum = 0;
    for (int i = 1; i <= 10; i++) sum += i;
    return sum;
  }

  void checkMaxNumber(int a, int b) {
    System.out.println(Math.max(a, b));
  }

  int sumTwoNumber(int a, int b) {
    return a + b;
  }

  int minusTwoNumber(int a, int b) {
    return a - b;
  }
}

class BookDTO {
  private String title, publisher, author;
  private int price;
  private double discountRate;

  BookDTO() {}

  BookDTO(String title, String publisher, String author) {
    this.title = title;
    this.publisher = publisher;
    this.author = author;
  }

  BookDTO(String title, String publisher, String author, int price, double discountRate) {
    this(title, publisher, author);
    this.price = price;
    this.discountRate = discountRate;
  }

  void printInformation() {
    System.out.println(
        title + ", " + publisher + ", " + author + ", " + price + ", " + discountRate);
  }

  String getTitle() {
    return title;
  }

  void setTitle(String value) {
    title = value;
  }

  String getPublisher() {
    return publisher;
  }

  void setPublisher(String value) {
    publisher = value;
  }

  String getAuthor() {
    return author;
  }

  void setAuthor(String value) {
    author = value;
  }

  int getPrice() {
    return price;
  }

  void setPrice(int value) {
    price = value;
  }

  double getDiscountRate() {
    return discountRate;
  }

  void setDiscountRate(double value) {
    discountRate = value;
  }
}
```

각 메서드는 입력을 받고 결과를 돌려주거나 출력하는 책임을 분리한다. 반복문에서는 누적값과 반복 조건을 먼저 정하고, 배열 처리에서는 인덱스 범위를 지킨다. BookDTO는 책 한 권의 값을 객체로 전달하기 위한 자료형이며 생성자와 getter·setter를 함께 제공한다. 숫자 야구는 같은 위치이면 스트라이크, 다른 위치에 숫자만 있으면 볼이다. 정답 배열은 반복 바깥에서 한 번 정하고 시도마다 비교한다. 아래 예제는 판정 순서를 확인하도록 정답과 입력을 고정했으며 대화형 게임 전체를 그대로 옮긴 것은 아니다.
