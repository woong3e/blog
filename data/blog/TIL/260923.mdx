## ☘️ 페이지와 이동

- App Router의 폴더는 경로, page.js는 페이지, layout.js는 공통 영역과 children 위치
- `/dashboard`: 루트 layout → dashboard/layout → dashboard/page 순으로 중첩
- `Link`는 클라이언트 이동·프리패칭, `router.push()`는 이벤트 안에서 이동. App Router Hook은 next/navigation에서 import
- Navbar는 `'use client'`와 usePathname 사용. `/menu?sort=price`의 pathname은 `/menu`
- `pathname === '/menu'`는 상세 `/menu/1`까지 활성화하지 않으므로 필요한 범위를 따로 정함

## ☘️ 메뉴 상세와 검색

| URL                          | 값 읽기                             | 용도      |
| ---------------------------- | ----------------------------------- | --------- |
| `/menu/1`                    | `useParams().menuCode`              | 상세 식별 |
| `/menu/search?menuName=열무` | `useSearchParams().get('menuName')` | 검색 조건 |

`menu/[menuCode]/page.js`에 상세 코드를 두고 `Link href={'/menu/' + menu.menuCode}`로 연결한다. 경로에서 읽은 `'1'`은 문자열이므로 JSON의 숫자와 비교 전 Number로 바꾼다.

```js
export function getMenuByMenuCode(menuCode) {
  return menus.find((menu) => menu.menuCode === Number(menuCode))
}
// 상세 컴포넌트
useEffect(() => {
  setMenu(getMenuByMenuCode(menuCode))
}, [menuCode])
```

첫 menu는 undefined라 `menu?.menuName`으로 표시했다. 이는 네트워크 요청이 아닌 import한 JSON 조회다.

검색 입력을 state로 두고 버튼에서 `router.push()`로 검색어를 URL에 넣는다. 결과는 menuName 의존성 Effect에서 filter·includes로 다시 계산한다. 원본은 문자열을 바로 붙였으며, 보완 시 URLSearchParams로 인코딩하고 검색 키가 없어 null일 때의 기본값도 정한다.

```jsx
<Suspense fallback={<p>검색 조건을 확인하는 중...</p>}>
  <MenuSearchResultContent />
</Suspense>
```

정적 페이지에서 useSearchParams를 읽는 부분은 가까운 Suspense 경계까지 클라이언트 렌더링된다. 개발 서버와 달리 프로덕션 빌드에서 경계가 필요하며, fallback은 **Effect의 요청 완료를 자동으로 기다리는 UI가 아니다.**

## ☘️ useReducer

useState는 핸들러가 다음 값을 계산하고, useReducer는 **이벤트 → dispatch(action) → reducer(현재 상태, action) → 다음 상태**로 규칙을 모은다.

```jsx
function reducer(number, action) {
  switch (action.type) {
    case 'PLUS1':
      return number + 1
    case 'MULTI4':
      return number * 4
    case 'DIVIDE3':
      return number / 3
    default:
      return number
  }
}
const [number, dispatch] = useReducer(reducer, 0)
// 클릭 시 dispatch({ type: 'PLUS1' })
```

reducer는 순수 함수로 다음 상태를 반환한다. 초기 0에서 세 액션을 순서대로 보내면 1 → 4 → 4/3이며 나누기는 정수 반올림하지 않는다. 이벤트는 의도만 전달하고 변경 규칙은 한곳에 둔다.
