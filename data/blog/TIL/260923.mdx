Next.js의 App Router는 폴더와 파일의 위치로 화면 주소를 정한다. React 상태를 바꾸는 것과 URL을 바꾸어 다른 페이지로 이동하는 것은 다른 동작이다. 주소의 경로·검색 조건을 어디서 읽는지와 컴포넌트가 서버·브라우저 중 어디의 기능을 쓰는지를 함께 구분한다.

## ☘️ page와 layout의 적용 범위

app/page.js는 루트 주소를, app/menu/page.js는 /menu를 만든다. page는 해당 주소의 화면이고 layout은 아래 페이지들을 감싸는 공통 구조다. 루트 layout의 html과 body는 전체 문서의 뼈대다. dashboard/layout은 dashboard 아래에서만 공통 내용을 추가한다.

App Router 컴포넌트는 기본적으로 서버 컴포넌트다. useState·useReducer·브라우저 탐색 훅처럼 클라이언트 기능이 필요한 파일은 맨 위에 use client를 선언한다. 이 경계는 단순 주석이 아니라 어떤 기능을 사용할 수 있는지에 영향을 준다.

Link는 주소 이동을 선언적으로 표현한다. 이벤트 처리 뒤 조건에 따라 이동해야 하면 useRouter의 push 등을 사용한다. 현재 경로로 탐색 메뉴의 표시를 바꾸려면 usePathname을 사용한다. 화면 상태만 바꾸는 버튼과 주소를 바꾸는 링크의 목적을 나누어 읽는다.

## ☘️ 경로 변수와 쿼리 문자열

[menuCode] 폴더는 해당 위치의 값을 받는 동적 경로다. /menu/1의 1을 useParams로 읽고 메뉴 번호와 비교한다. 주소에서 읽은 값은 문자열이므로 숫자 메뉴 번호와 비교하려면 변환해야 한다. 없는 번호는 별도의 안내를 표시한다.

검색어는 URL의 물음표 뒤에 들어가는 쿼리 문자열이다. URLSearchParams로 구성하면 글자 인코딩을 직접 이어 붙일 필요가 줄어든다. 검색 페이지는 useSearchParams로 값을 읽고 포함된 메뉴를 고른다. 이 훅을 쓰는 부분은 Suspense로 감싸 빌드와 렌더링 경계를 처리한다.

## ☘️ Reducer에 상태 변경 규칙 모으기

useReducer는 현재 상태와 dispatch를 제공한다. 이벤트가 action을 보내면 reducer가 이전 상태와 action으로 다음 상태를 계산한다. PLUS·MULTI·DIVIDE처럼 변경 종류가 여러 개일 때 한 함수에서 규칙을 읽을 수 있다. reducer는 값을 계산하며 상태를 직접 변경하거나 화면을 조작하지 않는다.

아래 홈의 계산 버튼은 Reducer를, 메뉴·검색·대시보드는 라우팅을 확인한다. 설정 파일과 공통 layout, 데이터 함수까지 모두 포함했으므로 파일 위치와 import가 실제로 어떻게 연결되는지 함께 볼 수 있다.

## ☘️ Reducer와 파일 경로 기반 라우팅의 전체 연결

연결된 Reducer·Next.js 학습 코드를 바탕으로 메뉴 데이터와 화면을 하나의 작은 프로젝트로 정리했다. 파일 경로도 라우팅 규칙의 일부이므로 각 파일을 표시한 경로 그대로 저장한다.

**app/menu/data.js**

```jsx
export const menus = [
  { menuCode: 1, menuName: '열무김치라떼', menuPrice: 4500 },
  { menuCode: 2, menuName: '우럭스무디', menuPrice: 5000 },
]
export function getMenuByMenuCode(code) {
  return menus.find((menu) => menu.menuCode === Number(code))
}
export function searchMenu(name) {
  return menus.filter((menu) => menu.menuName.includes(name))
}
```

**app/menu/page.js**

```jsx
'use client'
import Link from 'next/link'
import { useRouter } from 'next/navigation'
import { useState } from 'react'
import { menus } from './data'
export default function MenuList() {
  const [keyword, setKeyword] = useState('')
  const router = useRouter()
  return (
    <>
      <input
        aria-label="검색어"
        value={keyword}
        onChange={(event) => setKeyword(event.target.value)}
      />
      <button
        onClick={() => router.push('/menu/search?' + new URLSearchParams({ menuName: keyword }))}
      >
        검색
      </button>
      <ul>
        {menus.map((menu) => (
          <li key={menu.menuCode}>
            <Link href={'/menu/' + menu.menuCode}>{menu.menuName}</Link>
          </li>
        ))}
      </ul>
    </>
  )
}
```

**app/menu/search/page.js**

```jsx
'use client'
import { Suspense } from 'react'
import { useSearchParams } from 'next/navigation'
import { searchMenu } from '../data'
function Results() {
  const params = useSearchParams()
  const keyword = params.get('menuName') ?? ''
  return (
    <ul>
      {searchMenu(keyword).map((menu) => (
        <li key={menu.menuCode}>{menu.menuName}</li>
      ))}
    </ul>
  )
}
export default function SearchPage() {
  return (
    <Suspense fallback={<p>검색 조건 확인 중</p>}>
      <Results />
    </Suspense>
  )
}
```

**app/navbar.js**

```jsx
import Link from 'next/link'

export default function Navbar() {
  const pathname = usePathname()
  return (
    <nav>
      {['/', '/menu', '/dashboard'].map((href) => (

          href={href}

          {href}
        </Link>
      ))}
    </nav>
  )
}
```

**app/page.js**

```jsx
'use client'
import { useReducer } from 'react'
function reducer(number, action) {
  switch (action.type) {
    case 'PLUS1':
      return number + 1
    case 'MULTI4':
      return number * 4
    case 'DIVIDE3':
      return number / 3
    default:
      return number
  }
}
export default function Home() {
  const [number, dispatch] = useReducer(reducer, 0)
  return (
    <>
      <p>{number}</p>
      {['PLUS1', 'MULTI4', 'DIVIDE3'].map((type) => (
        <button key={type} onClick={() => dispatch({ type })}>
          {type}
        </button>
      ))}
    </>
  )
}
```

**package.json**

```json
{
  "private": true,
  "scripts": { "dev": "next dev", "build": "next build", "start": "next start" },
  "dependencies": { "next": "16.3.6", "react": "19.2.8", "react-dom": "19.2.8" }
}
```

홈 화면의 dispatch는 action을 reducer에 전달하고 reducer가 반환한 값이 다음 상태가 된다. 메뉴 목록은 Link로 상세 주소에 이동하고 [menuCode] 페이지는 주소의 값을 읽어 해당 메뉴를 찾는다. 검색 페이지는 물음표 뒤의 쿼리 값을 읽는다. 동적 경로와 검색 조건은 다른 주소 부분이다. useSearchParams를 사용하는 화면은 Suspense 안에 두고, useRouter·usePathname 같은 브라우저 훅을 사용하는 파일에는 use client를 선언한다. 루트 layout은 모든 화면에, dashboard/layout은 dashboard 경로 아래에만 공통으로 적용된다.

**실행 방법**

Node.js 환경에서 프로젝트 루트의 package.json과 나머지 파일을 저장하고 `npm install`, `npm run dev`를 차례로 실행한다. http://localhost:3000에서 홈·메뉴·검색·대시보드로 이동한다.
