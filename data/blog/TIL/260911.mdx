# 🍀 ES6 문법에서 DOM 선택까지

날짜를 출력하고 객체를 만드는 연습에 이어, 배열과 객체를 간결하게 다루는 ES6 문법을 배웠다. 이어서 HTML 요소를 선택하면서 자바스크립트의 배열과 DOM에서 반환하는 목록이 어떻게 다른지도 확인했다.

## 날짜와 객체, 화살표 함수

**Date로 날짜 꺼내기**

`new Date()`는 생성한 시점의 날짜와 시간을 나타내는 객체를 만든다. 연도는 `getFullYear()`, 일자는 `getDate()`로 가져온다. `getMonth()`는 1월을 0으로 반환하므로 사람이 읽는 월을 표시하려면 1을 더해야 한다.

```javascript
const now = new Date()
const year = now.getFullYear()
const month = now.getMonth() + 1
const day = now.getDate()

console.log(`${year}년 ${month}월 ${day}일`)
console.log(now.toLocaleString('ko-KR'))
```

`toLocaleString('ko-KR')`는 한국어 표시 형식을 지정한다. 언어 형식과 시간대는 별개이므로 한국 시간을 고정하려면 `timeZone: 'Asia/Seoul'` 같은 옵션이 필요하다.

**클래스로 학생 객체 만들기**

`Student` 클래스의 `constructor(name, score)`에서 이름과 점수를 초기화하고, `getInfo()`로 정보를 출력했다. `new Student()`를 두 번 호출하면 서로 다른 인스턴스가 만들어진다. 한 학생의 점수를 수정해도 다른 학생의 점수는 바뀌지 않는다. 클래스는 `new` 없이 일반 함수처럼 호출할 수 없다.

**화살표 함수의 핵심은 this**

배열의 `map()` 콜백은 `(price) => price * 2`처럼 짧게 쓸 수 있다. 중괄호 없이 식 하나를 쓰면 그 식의 결과가 반환되고, 중괄호로 함수 본문을 쓰면 필요한 값을 `return`해야 한다.

영화 목록 실습에서는 객체의 메서드를 일반 함수로 작성하고, 그 안의 `forEach()` 콜백을 화살표 함수로 작성했다.

```javascript
const theater = {
  store: '청량리역점',
  titles: ['오딧세이', '옵세션'],

  showMovieList() {
    this.titles.forEach((title) => {
      console.log(`${this.store}: ${title}`)
    })
  },
}

theater.showMovieList()
```

`theater.showMovieList()`의 `this`는 `theater`다. 내부 화살표 함수는 자신만의 `this`를 만들지 않고 바깥 메서드의 `this`를 사용한다. 객체 자신을 참조하는 메서드까지 무조건 화살표 함수로 바꾸면 이 동작이 달라진다.

## 값을 꺼내고 모으는 ES6 문법

**이터러블과 for...of**

배열과 문자열처럼 값을 순서대로 꺼낼 수 있는 이터러블은 `for...of`로 순회할 수 있다. 인덱스가 필요하지 않은 반복을 간단하게 표현하고, `break`로 반복을 끝낼 수도 있다. 일반 객체는 기본적으로 이터러블이 아니므로 직접 `for...of`에 넣을 수 없다. 객체의 내용을 순회하려면 `Object.keys()`, `Object.values()`, `Object.entries()`로 얻은 배열 등을 사용한다.

**Spread는 펼치고, Rest는 모은다**

둘 다 `...`를 사용하지만 위치에 따라 역할이 다르다. 함수 호출의 인수 자리에서는 배열을 개별 값으로 펼치고, 함수 선언의 매개변수 자리에서는 여러 인수를 배열로 모은다.

장바구니와 주문 상태를 다룬 실습을 정리한 예시다. 합계 함수는 출력만 하는 대신 계산 결과를 반환하도록 정리했다.

```javascript
const cart = ['키보드', '마우스']
const updatedCart = [...cart, '모니터']

const order = { id: 1, status: '결제 대기' }
const completedOrder = { ...order, status: '결제 완료' }

function getTotal(...prices) {
  let total = 0
  for (const price of prices) {
    total += price
  }
  return total
}

const prices = [50000, 30000, 200000]
console.log(getTotal(...prices)) // 280000
console.log(Math.max(...prices)) // 200000
```

객체에 같은 키가 여러 번 나오면 뒤에 적은 값이 적용된다. 따라서 기존 주문을 먼저 펼치고 그 뒤에 `status`를 써야 원하는 상태로 바꿀 수 있다.

스프레드로 복사한 배열이나 객체는 원본과 다른 참조를 갖지만 **얕은 복사**다. 배열 안에 객체가 있다면 내부 객체의 참조는 공유한다.

```javascript
const original = [{ name: '박지성' }]
const copied = [...original]

console.log(original === copied) // false
console.log(original[0] === copied[0]) // true
```

**구조 분해 할당은 필요한 값만 꺼낸다**

배열은 위치를 기준으로, 객체는 프로퍼티 키를 기준으로 값을 꺼낸다. 객체의 키 이름과 저장할 변수 이름을 다르게 정할 수도 있다.

```javascript
const [leader, assistant = '미정'] = ['박지성']
const student = { name: '박지성', age: 16, major: '역사' }
const { name: learnerName, major, job = '학생' } = student

const products = [
  { name: '키보드', price: 50000 },
  { name: '마우스', price: 30000 },
]
const productNames = products.map(({ name }) => name)
```

`name: learnerName`은 `name`의 값을 `learnerName` 변수에 담는 문법이다. 기본값은 값이 없거나 `undefined`일 때 적용되며, `null`에는 적용되지 않는다. 함수 매개변수와 배열 콜백에서도 구조 분해를 사용하면 어떤 값이 필요한지 코드에 바로 드러난다.

## DOM 선택과 변경되는 목록

DOM에서는 선택 메서드에 따라 반환값이 다르다.

| 메서드                     | 반환값                     | 기억할 점                             |
| -------------------------- | -------------------------- | ------------------------------------- |
| `querySelector()`          | 첫 번째 요소 또는 `null`   | CSS 선택자로 요소 하나 선택           |
| `querySelectorAll()`       | 정적인 `NodeList`          | 선택 당시 일치한 요소 목록 유지       |
| `getElementById()`         | 요소 하나 또는 `null`      | ID 문자열로 선택                      |
| `getElementsByClassName()` | 살아 있는 `HTMLCollection` | 해당 클래스의 추가·제거를 목록에 반영 |

**반복하면서 클래스도 지우면 목록이 바뀐다**

`getElementsByClassName('text')`로 가져온 목록을 앞에서부터 순회하며 `text` 클래스를 지웠다. 첫 번째 요소가 목록에서 빠지면 다음 요소의 인덱스가 당겨진다. 그런데 반복문의 인덱스는 증가하므로 일부 요소를 건너뛰게 된다.

이때는 현재 목록을 배열로 옮긴 뒤 순회할 수 있다.

```javascript
const texts = document.getElementsByClassName('text')
const textArray = [...texts]

textArray.forEach((element) => {
  element.classList.remove('text')
})

console.log(texts.length) // 0
console.log(textArray.length) // 원래 선택한 요소 수
```

배열에 담긴 요소는 원래 DOM 요소와 같다. 고정되는 것은 목록의 구성이고, 요소를 복제하는 것은 아니다. `querySelectorAll()`의 `NodeList`가 정적이라는 점도 기억해야 한다. 모든 `NodeList`가 정적인 것은 아니다.

**기억할 점**

- `...`는 사용 위치를 보고 펼치는지 모으는지 판단한다.
- 스프레드 복사에서 내부 객체까지 새로 만들어졌다고 생각하지 않는다.
- 화살표 함수는 바깥 `this`를 사용한다.
- DOM 목록을 순회하며 바꿀 때는 목록 자체가 실시간으로 변하는지 확인한다.

참고로 얕은 복사와 구조 분해의 기본값 규칙은 [MDN Spread syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax), [MDN Destructuring](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring)에서 확인했다. 화살표 함수의 `this`와 DOM 목록의 동작은 [MDN Arrow functions](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Arrow_functions), [MDN querySelectorAll](https://developer.mozilla.org/en-US/docs/Web/API/Document/querySelectorAll), [MDN HTMLCollection](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCollection)을 참고했다. 날짜 표시 형식과 시간대 옵션은 [MDN toLocaleString](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Date/toLocaleString)에서 확인했다.
