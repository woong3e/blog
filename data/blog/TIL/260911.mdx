## ☘️ 날짜, 클래스와 화살표 함수

`Date`는 날짜와 시간을 표현하는 객체다. `new Date()`는 생성한 시점의 값을 담는다. `getFullYear()`로 연도, `getDate()`로 일자를 얻으며 월은 `getMonth()`가 0부터 반환하므로 화면에 표시할 때 1을 더한다. `toLocaleString('ko-KR')`는 한국어 표시 형식의 문자열을 만든다. 언어 형식을 정하는 것과 시간대를 한국으로 고정하는 것은 별개다.

Student 클래스는 constructor에서 이름과 점수를 저장하고 getInfo로 정보를 문자열로 만든다. `new`는 새 인스턴스를 만들 때 필요하며 클래스를 일반 함수처럼 호출하면 오류다. 학생 하나의 점수를 바꿔도 다른 학생은 별도 객체라 영향을 받지 않는다.

**화살표 함수와 this**

화살표 함수는 짧은 함수를 표현하는 문법이다. 수업에서는 가격 배열을 map으로 읽으면서 각 가격을 두 배로 바꿨다. map은 원래 배열의 각 값을 함수에 전달하고, 함수가 반환한 값들을 새 배열로 모은다. 본문이 식 하나라면 중괄호와 return을 생략할 수 있지만, 중괄호를 열면 반환할 값을 return으로 명시해야 한다.

화살표 함수에는 자신의 this가 없어서 바깥 범위의 this를 사용한다. 영화관 객체의 일반 메서드는 객체를 통해 호출하므로 this가 theater이고, 안쪽 화살표 함수도 그 this를 사용한다.

```js
showMovieList: function () {
  this.titles.forEach((title) => console.log(this.store + ': ' + title))
}
```

위 코드는 수업의 theater 객체에서 메서드 부분을 발췌한 것이다. 메서드 자체까지 화살표 함수로 바꾸면 바깥 this를 사용하므로 theater를 가리킨다는 보장이 없다. 문법이 짧다는 이유만으로 일반 함수를 모두 교체하지 않는다.

## ☘️ 순회와 Spread·Rest

**이터러블과 for...of**

이터러블은 값을 차례로 꺼낼 수 있는 대상이다. 배열과 문자열이 대표적이며 `for...of`의 반복 변수에는 인덱스 대신 현재 값이 들어온다. 수업에서는 과일과 문자열의 글자를 순회하고 break로 중단했다. 순번이 필요하면 별도 변수를 증가시킨다. 일반 객체는 그대로 for...of에 사용할 수 없으므로 Object.keys·values·entries 등으로 배열을 얻어 다룬다.

**펼치기와 모으기**

Spread는 배열 안의 값을 펼친다. Math.max는 숫자를 각각 받으므로 배열 scores를 그대로 넘기면 NaN이지만 `Math.max(...scores)`로 펼치면 최대값 95를 구한다. 배열 리터럴 안에서 펼치면 새 배열을 만들 수 있다. 객체도 기존 프로퍼티를 새 객체에 펼치고 뒤에 같은 키를 지정하면 그 값으로 덮어쓴다.

Spread 복사는 **얕은 복사**다. 수업의 original과 copied는 바깥 배열은 다르지만 첫 번째 내부 객체는 같다. 바깥만 새로 만들었다고 내부 객체까지 모두 독립적인 것은 아니다.

Rest는 함수의 매개변수 위치에서 여러 인수를 배열 하나로 모은다. 호출할 때는 Spread로 펼치고, 함수가 받을 때는 Rest로 모은다는 차이가 있다. 수업의 합계 함수는 모인 숫자를 for...of로 더한다. 가격 50000·30000·200000의 합은 280000이다. 다만 Spread 과제의 getTotal은 합계를 출력만 하고 return하지 않았다. “반환하는 함수”라는 요구를 충족하려면 계산한 값을 돌려줘야 한다.

## ☘️ 구조 분해와 과제 흐름

구조 분해는 배열이나 객체에서 필요한 값을 꺼내 변수로 받는 문법이다. 배열은 위치로, 객체는 키 이름으로 찾는다. 배열의 두 번째 값이 없을 때 assistant를 미정으로, 객체의 job이 없을 때 학생으로 받는 식으로 기본값을 지정할 수 있다. 기본값은 undefined일 때 적용하며 null을 대체하지 않는다.

객체의 `name: learnerName`은 name 값을 learnerName이라는 변수로 받겠다는 뜻이다. 함수 매개변수에서도 필요한 프로퍼티를 곧바로 꺼낼 수 있다. 중첩 객체의 cpu만 받는 구조도 수업에서 확인했다.

과제의 주문 배열은 map과 매개변수 구조 분해로 상품명·가격·수량을 받아 결제 금액 문자열로 바꾼다. 키보드 100000원, 마우스 30000원, 모니터 400000원이 된다. 원본 문자열은 콜론 뒤 공백이 없어 문제의 예상 표시와는 차이가 있다.

팀 명단 과제는 두 팀과 이순신을 Spread로 합친 뒤 함수의 인수로 펼치고 Rest로 받도록 요구한다. 원본은 배열 하나를 넘겨 매개변수에서 배열 구조 분해를 하므로 출력은 비슷해도 요구된 호출 방식과 다르다. 사용자 정보 구조 분해와 상품 갱신 문제는 해당 커밋에 풀이가 비어 있다.

상품 갱신의 요구 흐름은 새 배열에 상품 추가 → map으로 id 1의 객체만 새로 복사해 가격 55000으로 변경 → filter로 재고가 있는 상품 선택 → map으로 이름 추출 → Rest와 reduce로 가격 합계 계산이다. 원본 3개는 그대로 두고 새 목록은 4개, 판매 가능 이름은 키보드·모니터·스피커, 전체 가격 합계는 365000이 되어야 한다. 이는 완성된 원본 구현이 아니라 과제 요구사항을 설명한 것이다.

## ☘️ DOM 요소 선택과 변하는 목록

DOM은 브라우저가 HTML을 읽어 만든 객체 구조다. JavaScript는 이 객체를 선택해 글자나 스타일을 바꾼다. querySelector는 CSS 선택자에 맞는 첫 요소 하나를, querySelectorAll은 맞는 요소들의 NodeList를 반환한다. getElementById는 id로 하나를 찾는다. 하나를 찾는 메서드는 결과가 없으면 null이므로 이후 속성 접근 전에 확인해야 한다.

getElementsByClassName은 현재 클래스 조건을 실시간으로 반영하는 HTMLCollection을 반환한다. 수업에서 이 목록을 앞에서부터 돌며 클래스를 제거하면 목록 자체가 줄어들고 뒤 항목의 위치가 당겨져 일부를 건너뛴다.

```js
const $texts2 = document.getElementsByClassName('text2')
const textArray = [...$texts2]
textArray.forEach((item) => {
  item.classList.remove('text2')
})
```

먼저 배열로 현재 목록을 고정하면 모두 처리할 수 있다. 처리 후 살아 있는 목록의 길이는 0이지만 배열은 처음 담은 요소 세 개를 계속 가리킨다. 요소 자체를 복제한 것은 아니다. NodeList와 HTMLCollection은 실제 배열이 아니며, querySelectorAll의 NodeList는 정적이지만 모든 NodeList가 정적인 것은 아니다.
