## ☘️ 날짜와 객체

- `new Date()`: 생성 시점의 날짜·시간. `getFullYear()`는 연도, `getDate()`는 일, `getMonth() + 1`은 표시할 월
- `toLocaleString('ko-KR')`: 한국어 형식. 한국 시간대 고정은 별도로 `{ timeZone: 'Asia/Seoul' }` 지정
- `Student`의 constructor로 이름·점수를 초기화하고 `getInfo()`로 출력했다. `new`로 만든 학생끼리는 별도 객체이며, 클래스는 `new` 없이 호출할 수 없다.

```js
const theater = {
  store: '청량리역점',
  titles: ['오딧세이', '옵세션'],
  showMovieList() {
    this.titles.forEach((title) => console.log(`${this.store}: ${title}`))
  },
}
theater.showMovieList()
```

일반 메서드의 `this`는 호출한 theater, 내부 화살표 콜백은 그 바깥 this를 사용한다. 메서드 자체를 화살표 함수로 바꾸면 같은 this가 아니다. `price => price * 2`는 식을 반환하지만 `{}` 본문은 명시적 return이 필요하다.

## ☘️ ES6로 값 다루기

**이터러블**은 값을 순서대로 꺼낼 수 있는 배열·문자열 등이다. `for...of`로 값 순회, `break`로 중단한다. 일반 객체는 바로 순회할 수 없어 `Object.keys/values/entries()`로 배열을 얻는다.

- Spread: `[...cart, '모니터']`, `{ ...order, status: '결제 완료' }`처럼 펼친다. 같은 키는 뒤의 값이 우선
- Rest: `function getTotal(...prices)`처럼 여러 인수를 배열로 모은다.
- 호출할 때 `getTotal(...prices)`, `Math.max(...prices)`로 배열을 인수에 펼친다. 50000·30000·200000의 합은 280000, 최대는 200000
- Spread는 **얕은 복사**: 바깥 배열은 다르지만 내부 객체 참조는 공유한다.

```js
const original = [{ name: '박지성' }]
const copied = [...original]
original === copied // false
original[0] === copied[0] // true
const [leader, assistant = '미정'] = ['박지성']
const { name: learnerName, job = '학생' } = { name: '박지성' }
const names = products.map(({ name }) => name)
```

구조 분해는 배열의 **위치**, 객체의 **키**로 꺼낸다. `name: learnerName`은 변수명 변경이다. 기본값은 값이 없거나 undefined일 때만 적용하며 null에는 적용하지 않는다. 함수 매개변수에도 사용할 수 있다.

## ☘️ DOM 선택과 목록

- `querySelector(선택자)`: 첫 요소 또는 null
- `getElementById(id)`: 해당 요소 또는 null
- `querySelectorAll(선택자)`: 선택 시점의 정적 NodeList
- `getElementsByClassName(클래스)`: 변경이 반영되는 HTMLCollection

살아 있는 목록을 앞에서부터 순회하며 클래스를 지우면 인덱스가 당겨져 일부 요소를 건너뛴다.

```js
const texts = document.getElementsByClassName('text')
const snapshot = [...texts]
snapshot.forEach((element) => element.classList.remove('text'))
// texts.length: 0, snapshot.length: 처음 요소 수
```

배열로 고정한 것은 **목록 구성**이며 DOM 요소를 복제한 것은 아니다. 모든 NodeList가 정적인 것도 아니므로 반환 메서드를 확인한다.
