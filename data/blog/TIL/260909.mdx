## ☘️ 생성자와 프로토타입

생성자는 객체마다 다른 데이터를 `this`에 저장하고, 공통 계산은 프로토타입에 둔다.

```js
function Book(title, price) {
  this.title = title
  this.price = price
}
Book.prototype.getTotal = function (quantity) {
  return this.price * quantity
}
const book1 = new Book('책1', 15000)
const book2 = new Book('책2', 20000)
book1.getTotal(2) // 30000
book2.getTotal(2) // 40000
```

객체의 `[[Prototype]]`은 상위 객체로 이어지는 연결이다. 인스턴스에 없는 메서드는 이 연결을 따라 찾는다. 일반 객체 리터럴은 보통 `Object.prototype`과 연결된다.

## ☘️ 참조와 소유 확인

```js
book1.getTotal === book2.getTotal // true: 함수 공유
Object.hasOwn(book1, 'getTotal') // false
Object.hasOwn(Book.prototype, 'getTotal') // true
book1.price = 18000
book1.getTotal(2) // 36000
book2.getTotal(2) // 40000
book1.getTotal(0) // 0 (book2도 0)
```

메서드는 공유하지만 `this`는 호출한 도서다. 한 도서의 가격을 바꿔도 다른 도서의 가격은 바뀌지 않는다.
