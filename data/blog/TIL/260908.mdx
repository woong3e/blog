주문 계산은 숫자를 더하는 것만으로 끝나지 않는다. 입력이 문자열인지 숫자인지 확인하고, 할인이나 통과 조건의 경계를 정하고, 여러 값에서 필요한 결과를 누적해야 한다. 값의 형태와 처리 순서를 먼저 정하면 결과를 예상하기 쉽다.

## ☘️ 입력 변환과 조건의 경계

입력 폼 등에서 받은 가격은 숫자처럼 보여도 문자열일 수 있다. 문자열 두 개를 +로 연결하면 합계가 아니라 글자가 이어진다. 아래 코드는 Number로 가격과 배송비를 각각 숫자로 바꾼 뒤 더해 15000을 구한다. 변환할 수 없는 문자열은 NaN이 될 수 있으므로 실제 입력에서는 변환 결과도 검사해야 한다.

회원이면서 주문 금액이 기준 이상이어야 하는 조건은 &&로 묶는다. 금액이 정확히 20000인 경우를 포함하려면 >=를 사용한다. >로 적으면 경계값은 제외된다. 조건에 맞을 것 같은 값 하나만 확인하지 말고 기준 직전·같음·직후를 나누어 읽는다.

점수 분류는 범위를 벗어난 입력을 먼저 걸러낸 뒤 높은 구간부터 검사한다. if·else if는 먼저 맞은 분기에서 끝나므로 낮은 기준부터 넓게 잡으면 높은 점수도 앞의 조건에 포함되어 뒤까지 도달하지 못할 수 있다.

## ☘️ 반복과 객체 상태 변경

1부터 20까지 반복하면서 3의 배수일 때만 개수와 합계를 바꾼다. 개수는 조건에 맞을 때 1씩 늘고 합계는 현재 숫자만큼 늘어난다. 두 변수의 의미를 나누면 최종 개수 6과 합계 63이 왜 다른 값인지 알 수 있다.

상품 객체의 stock을 줄인 뒤 재고가 남았는지 계산해 isAvailable에 넣는다. 이 값은 stock과 자동으로 연결된 수식이 아니라 계산 당시의 boolean이다. 나중에 재고를 다시 바꾸면 판매 가능 여부도 다시 계산해야 한다. delete로 category를 없앤 뒤 읽으면 undefined가 반환된다.

## ☘️ 함수의 입력·반환·조합

함수의 매개변수는 호출자가 넘긴 값을 받는다. getOrderTotal은 가격과 수량을 받아 수량이 양수일 때 곱을 돌려준다. 수량이 0 이하라면 0을 즉시 반환해 나머지 계산으로 진행하지 않는다. return은 함수의 실행을 끝내고 호출 위치에 결과를 전달한다.

console.log는 결과를 보여 주는 동작이고 return은 다른 계산이 쓸 값을 돌려주는 동작이다. 둘은 대체되지 않는다. 마지막 줄은 반환된 주문 금액에 배송비 2500을 더한다. 함수 내부에서만 출력하고 반환하지 않으면 호출자는 undefined를 받으므로 같은 합계를 만들 수 없다.

## ☘️ 분기·반복·함수를 연결한 계산

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**js-orders.js**

```js
const productName = '노트',
  price = 3000,
  isAvailable = true
console.log(productName, price, isAvailable)
console.log(typeof productName, typeof price, typeof isAvailable)
const inputPrice = '12000',
  inputDeliveryFee = '3000'
console.log(Number(inputPrice) + Number(inputDeliveryFee))
for (const [isMember, orderAmount] of [
  [true, 18000],
  [true, 20000],
  [false, 30000],
]) {
  console.log(isMember && orderAmount >= 20000)
}
function classify(score) {
  if (score < 0 || score > 100) return '점수를 확인하세요.'
  if (score >= 90) return '우수'
  if (score >= 70) return '통과'
  return '재학습'
}
console.log([90, 70, 69, 0].map(classify).join(','))
let count = 0,
  sum = 0
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) {
    count++
    sum += i
  }
}
console.log(count, sum)
const product = { name: '노트', price: 3000, stock: 10, category: '문구' }
const key = 'price'
product.stock -= 2
product.isAvailable = product.stock > 0
delete product.category
console.log(product[key], product.stock, product.isAvailable, product.category)
function getOrderTotal(price, quantity) {
  if (quantity <= 0) return 0
  return price * quantity
}
console.log(
  getOrderTotal(3000, 2),
  getOrderTotal(5000, 1),
  getOrderTotal(3000, 0),
  getOrderTotal(3000, -2)
)
console.log(getOrderTotal(3000, 2) + 2500)
```

가격과 배송비는 Number로 각각 변환한 뒤 더한다. 회원 조건은 20000 이상인 경계값을 포함한다. 1부터 20까지 3의 배수는 6개이며 합은 63이다. 상품 재고를 2 줄이면 8이 되고 삭제한 category는 undefined가 된다. getOrderTotal은 수량이 0 이하이면 0을 반환하고 나머지는 가격과 수량을 곱한다. 마지막에는 주문 금액 6000에 배송비 2500을 더해 8500을 출력한다.
