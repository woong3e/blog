## ☘️ 타입과 조건

상품·주문 과제에서 변수 → 타입 변환 → 조건 → 반복 → 객체 → 함수를 연습했다.

- `typeof '노트'`는 string, `typeof 3000`은 number, `typeof true`는 boolean
- 문자열 금액은 `Number('12000') + Number('3000')`으로 계산 → 숫자 15000. 변환하지 않은 `+`는 문자열 연결
- 무료 배송: `isMember && orderAmount >= 20000`. 회원·18000원은 false, 회원·20000원은 true, 비회원·30000원은 false

```js
if (score < 0 || score > 100) console.log('점수를 확인하세요.')
else if (score >= 90) console.log('우수')
else if (score >= 70) console.log('통과')
else console.log('재학습')
```

범위 검증을 먼저 하고 높은 점수부터 검사한다. 90은 우수, 70·85는 통과, 0·69는 재학습, -1·101은 오류다.

## ☘️ 누적과 객체 변경

```js
let count = 0
let sum = 0
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0) {
    console.log(i) // 3, 6, 9, 12, 15, 18
    count++
    sum += i
  }
} // count: 6, sum: 63
```

누적 변수는 반복문 밖에서 초기화한다.

```js
const product = { name: '노트', price: 3000, stock: 10, category: '문구' }
const key = 'price'
product.stock -= 2
product.isAvailable = product.stock > 0
delete product.category
// product[key]: 3000, stock: 8, isAvailable: true, category: undefined
```

`const` 객체는 다른 객체로 재할당할 수 없지만 프로퍼티 조회·수정·추가·삭제는 가능하다.

## ☘️ 함수 반환과 조기 종료

```js
function getOrderTotal(price, quantity) {
  if (quantity <= 0) return 0
  return price * quantity
}
console.log(getOrderTotal(3000, 2) + 2500) // 배송비 포함 8500
```

`console.log`는 화면 출력, `return`은 호출자에게 값을 전달하고 함수를 종료한다. 5000원 1개는 5000, 수량 0·-2는 0을 반환한다. 외부 변수 대신 반환값으로 후속 계산을 이어 간다.
