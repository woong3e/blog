화면의 목록을 추가·삭제하거나 입력값으로 프로필을 바꾸려면 HTML 문자열과 실제 DOM 요소를 구분해야 한다. 요소를 만든 뒤 문서에 연결하는 과정과 이미 연결된 요소를 이동하는 과정도 서로 다르다.

## ☘️ 요소와 주변 노드 찾기

DOM의 노드는 태그에 해당하는 요소뿐 아니라 글자와 주석도 포함한다. 줄바꿈과 들여쓰기 역시 텍스트 노드가 될 수 있다. children은 요소 자식만, childNodes는 텍스트 등을 포함한 자식 노드를 담는다. firstChild와 firstElementChild의 결과가 다를 수 있는 이유다.

parentElement는 부모 요소, nextElementSibling과 previousElementSibling은 옆의 요소를 찾는다. 대상이 없으면 null이 될 수 있으므로 다음 프로퍼티를 읽기 전에 확인한다. 요소 선택은 DOM을 바꾸는 작업의 시작이며 선택만으로 화면이 변경되지는 않는다.

## ☘️ 생성·삽입·삭제의 순서

createElement는 메모리에 요소를 만든다. textContent로 내용을 넣고 appendChild로 부모에 연결해야 화면에 나타난다. 같은 노드를 다시 appendChild하면 복사본이 생기는 것이 아니라 그 노드가 이동한다. 여러 할 일을 만들 때 li를 한 번만 생성하면 항목이 늘지 않는 이유다. 아래 코드는 추가할 때마다 새 li를 만든다.

DocumentFragment는 여러 노드를 임시로 담는 공간이다. 부모에 연결할 때 그 안의 자식들이 이동하며 fragment 자체가 화면의 별도 태그가 되지는 않는다. remove는 해당 요소를 제거한다. 빈 목록에서 마지막 항목을 지우려면 제거할 요소가 있는지도 검사해야 한다.

textContent는 입력을 글자로 표시한다. innerHTML은 태그로 해석하므로 사용자 입력을 그대로 넣으면 의도하지 않은 HTML이 삽입될 수 있다. 단순 이름·소개·할 일 내용에는 textContent를 사용하면 된다.

## ☘️ 입력값·데이터·표시 상태

input.value는 사용자가 지금 입력한 값이다. HTML의 value 속성은 기본값과 관련되므로 최신 입력을 처리할 때 getAttribute만 읽지 않는다. 체크박스는 현재 선택 여부인 checked 프로퍼티를 읽는다.

data-\*는 요소에 부가 정보를 담는다. dataset으로 읽는 값은 문자열이므로 숫자 계산이 필요하면 변환한다. classList는 클래스 전체를 덮지 않고 추가·제거·전환할 수 있다. 클래스 이름에는 CSS 선택자의 점을 붙이지 않는다.

아래 예제는 검색·할 일·선택 카드·프로필을 나누어 구현했다. 검색은 입력과 상품 이름을 비교하고, 선택 표시는 이전 카드의 상태를 지운 뒤 새 카드에 적용한다. 다크 모드와 크기는 실제 꾸밀 카드의 클래스를 바꾼다. 데이터 변경과 화면 반영을 한 단계씩 연결해 읽으면 된다.

## ☘️ 요소 생성과 화면 상태 변경

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**dom-demo.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>DOM 변경</title>
    <style>
      .matched {
        background: yellow;
      }
      .selected {
        border: 2px solid green;
      }
      .dark {
        background: #222;
        color: white;
      }
      .compact {
        max-width: 220px;
      }
      article {
        padding: 12px;
        border: 1px solid #888;
      }
    </style>
  </head>
  <body>
    <ol id="steps">
      <li>HTML</li>
      <li id="current">JavaScript</li>
      <li>React</li>
    </ol>
    <p id="relations"></p>
    <input id="search" aria-label="상품 검색" /><button id="search-button">검색</button>
    <p id="result"></p>
    <ul id="products">
      <li class="product">키보드</li>
      <li class="product">마우스</li>
    </ul>
    <input id="todo-input" aria-label="할 일" /><button id="add">추가</button
    ><button id="remove">마지막 삭제</button>
    <ul id="todos"></ul>
    <article
      class="product-card"
      data-product-id="p-101"
      data-product-name="키보드"
      data-price="50000"
    >
      <button class="select">키보드 선택</button>
    </article>
    <article
      class="product-card"
      data-product-id="p-102"
      data-product-name="마우스"
      data-price="30000"
    >
      <button class="select">마우스 선택</button>
    </article>
    <p id="selected"></p>
    <input id="name" value="홍길동" aria-label="이름" /><textarea id="message" aria-label="소개">
개발 공부중</textarea>
    <input id="color" type="color" value="#315efb" aria-label="테두리색" /><select
      id="size"
      aria-label="크기"
    >
      <option value="normal">기본</option>
      <option value="compact">작게</option>
    </select>
    <button id="apply">프로필 적용</button><button id="dark">다크 모드 켜기</button>
    <article id="profile">
      <h2 id="profile-name">홍길동</h2>
      <p id="profile-message">개발 공부중</p>
    </article>
    <script>
      const current = document.getElementById('current')
      document.getElementById('relations').textContent =
        current.previousElementSibling.textContent + ' / ' + current.nextElementSibling.textContent
      console.log(current.parentElement.children.length, current.parentElement.childNodes.length)
      document.getElementById('search-button').onclick = () => {
        const keyword = document.getElementById('search').value.trim().toLowerCase()
        let count = 0
        for (const product of document.querySelectorAll('.product')) {
          const matches = keyword !== '' && product.textContent.toLowerCase().includes(keyword)
          product.classList.toggle('matched', matches)
          if (matches) count++
        }
        document.getElementById('result').textContent = keyword
          ? `일치한 상품: ${count}개`
          : '검색어를 입력해주세요.'
      }
      const input = document.getElementById('todo-input'),
        list = document.getElementById('todos')
      document.getElementById('add').onclick = () => {
        const text = input.value.trim()
        if (!text) return
        const item = document.createElement('li')
        item.textContent = text
        list.appendChild(item)
        input.value = ''
      }
      document.getElementById('remove').onclick = () => {
        if (list.lastElementChild) list.lastElementChild.remove()
      }
      const fragment = document.createDocumentFragment()
      for (const text of ['DOM 복습하기', '실습 문제 풀기']) {
        const item = document.createElement('li')
        item.textContent = text
        fragment.appendChild(item)
      }
      list.appendChild(fragment)
      document.querySelectorAll('.select').forEach(
        (button) =>
          (button.onclick = () => {
            const selected = button.closest('.product-card')
            for (const card of document.querySelectorAll('.product-card')) {
              card.classList.remove('selected')
              card.removeAttribute('data-selected')
            }
            selected.classList.add('selected')
            selected.dataset.selected = 'true'
            document.getElementById('selected').textContent =
              selected.dataset.productName +
              ': ' +
              Number(selected.dataset.price).toLocaleString('ko-KR') +
              '원'
          })
      )
      const profile = document.getElementById('profile')
      document.getElementById('apply').onclick = () => {
        document.getElementById('profile-name').textContent = document.getElementById('name').value
        document.getElementById('profile-message').textContent =
          document.getElementById('message').value
        profile.style.borderColor = document.getElementById('color').value
        profile.classList.toggle('compact', document.getElementById('size').value === 'compact')
      }
      document.getElementById('dark').onclick = (event) => {
        profile.classList.toggle('dark')
        event.currentTarget.textContent = profile.classList.contains('dark')
          ? '다크 모드 끄기'
          : '다크 모드 켜기'
      }
    </script>
  </body>
</html>
```

검색은 상품 배열에서 이름에 입력 문자열이 포함된 항목을 고르고 화면 목록을 다시 만든다. textContent는 입력값을 HTML 태그로 해석하지 않고 글자로 넣는다. 할 일 추가는 빈 문자열을 먼저 거부하고 li와 삭제 버튼을 만든 뒤 목록에 붙인다. 삭제 버튼은 자신이 속한 li를 제거한다. DocumentFragment는 여러 요소를 담아 한꺼번에 연결하는 임시 그릇이다. dataset은 data-\* 값을 문자열로 읽으며 선택 표시는 classList로 바꾼다. 입력 필드의 value는 현재 입력값, textContent는 요소 안의 글자라는 차이가 있다.

**실행 방법**

`dom-demo.html`로 저장하고 브라우저에서 연다. 버튼을 누르거나 입력값을 바꾸며 아래의 화면 변화를 확인한다.
