## ☘️ 탐색과 텍스트

DOM에는 요소뿐 아니라 텍스트·주석도 있다. 들여쓰기·줄바꿈도 텍스트 노드가 될 수 있다.

| 목적        | 모든 노드                         | 요소만                                          |
| ----------- | --------------------------------- | ----------------------------------------------- |
| 자식        | `childNodes`                      | `children`                                      |
| 처음·마지막 | `firstChild` / `lastChild`        | `firstElementChild` / `lastElementChild`        |
| 부모        | `parentNode`                      | `parentElement`                                 |
| 앞·뒤 형제  | `previousSibling` / `nextSibling` | `previousElementSibling` / `nextElementSibling` |

childNodes는 NodeList, children은 HTMLCollection이다. 부모·형제가 없으면 null일 수 있으므로 접근 전 확인한다.

- 요소의 `nodeValue`는 null. 텍스트 노드의 값을 직접 바꿀 때 nodeValue 사용
- `textContent`: 내부 텍스트를 읽고 교체. 태그 문자열도 글자로 표시하며 **기존 자식은 제거**
- `innerText`: CSS·화면 표시의 영향 / textContent: DOM 텍스트 기준

## ☘️ 생성과 삽입

- `innerHTML`: 문자열을 HTML로 해석해 내부 교체. 사용자 입력의 단순 출력에는 textContent 사용
- `insertAdjacentHTML(위치, HTML)`: 기존 내용 유지하며 삽입. 바깥 앞 `beforebegin`, 내부 앞 `afterbegin`, 내부 뒤 `beforeend`, 바깥 뒤 `afterend`
- `createElement()`: 생성만 함 / `appendChild()`: 부모 끝에 붙임
- `DocumentFragment`: 여러 노드를 임시로 모음. 붙이면 **자식들이 이동하고 fragment는 비워짐**
- 기존 노드를 appendChild하면 복사가 아니라 이동. 같은 부모면 맨 뒤로 이동
- `insertBefore(새 노드, 기준 자식)`, `replaceChild(새 노드, 기존 자식)`, `removeChild(자식)`, `노드.remove()`

```js
function addTodo() {
  const text = todoInput.value.trim()
  if (!text) return
  const item = document.createElement('li') // 항목마다 새로 생성
  item.textContent = text
  todoList.appendChild(item)
  todoInput.value = ''
}
function removeLastTodo() {
  todoList.lastElementChild?.remove()
}
```

li를 함수 밖에서 한 번만 만들면 항목이 쌓이지 않고 기존 노드만 이동한다. 빈 입력·빈 목록도 처리한다.

## ☘️ 입력값과 스타일

- 어트리뷰트: HTML에 설정한 속성. `getAttribute`, `setAttribute`, `hasAttribute`, `removeAttribute`로 관리
- input의 value 어트리뷰트는 기본값, **`.value`는 현재 입력값**
- 체크박스의 `.checked`는 현재 boolean. checked 어트리뷰트는 존재 자체가 기본 체크를 뜻하므로 문자열 `'false'`로 해제할 수 없음
- `data-board-id` → `dataset.boardId`: 화면 동작에 필요한 데이터 저장. 상품 카드 선택 과제의 요구사항도 확인
- `style.backgroundColor`: 인라인 스타일. 하이픈 속성은 카멜 표기법으로 접근
- `className`: 클래스 문자열 전체 교체 / `classList`: `add`, `remove`, `toggle`, `contains`로 개별 관리

toggle은 없으면 추가·있으면 제거하고 변경 후 존재 여부를 반환한다. `classList.toggle('dark')`에는 점을 붙이지 않는다. 다크 모드 클래스는 버튼이 아니라 실제 꾸밀 카드에 적용한다.

입력의 기본 속성을 읽을지 현재 상태를 읽을지 구분하고, 여러 스타일의 상태 전환은 클래스로 묶는다.
