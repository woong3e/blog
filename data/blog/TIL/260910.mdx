같은 종류의 객체 여러 개를 만들려면 객체마다 다른 데이터와 공통 기능을 구분해야 한다. 생성자 함수와 class는 이 구조를 표현하는 두 방식이다. 문법 모양보다 생성되는 객체와 메서드가 어디에 놓이는지 살펴보는 것이 중요하다.

## ☘️ 객체마다 달라지는 값과 함께 쓰는 함수

이름과 나이는 사람마다 다르므로 각 객체의 필드로 저장한다. 정보를 문자열로 만드는 규칙은 같으므로 공통 메서드로 표현할 수 있다. 생성자 안에서 함수를 매번 대입하면 객체마다 별도 함수가 만들어지고 prototype에 정의하면 여러 객체가 하나의 함수를 공유한다.

두 객체의 메서드를 ===로 비교하면 함수 참조가 같은지 알 수 있다. 함수 내용이 같은 모양이어도 서로 새로 만든 함수는 다른 객체다. 메서드 공유는 필드 공유와 다르다. 같은 getInfo를 호출해도 this가 각 사람을 가리키면 각자의 이름과 나이로 결과를 만든다.

## ☘️ class의 생성과 호출

class의 constructor는 new로 새 인스턴스를 만들 때 호출되어 입력값으로 필드를 초기화한다. 클래스 본문에 적은 일반 메서드는 프로토타입에 놓이므로 인스턴스들이 공유한다. 메서드 이름 앞에 function을 쓰지 않는 점도 함수 생성자 방식과 다르다.

클래스는 new 없이 일반 함수처럼 호출할 수 없다. 또한 선언 전에 사용할 수 없으므로 사용할 위치보다 먼저 정의한다. 함수 생성자와 결과 구조가 비슷하다고 모든 동작 규칙이 동일한 것은 아니다.

아래 코드는 두 방식을 순서대로 실행한다. 각 방식에서 두 객체의 함수 참조를 비교하고 getInfo와 bye를 호출한다. 먼저 각 console.log가 필드 값인지 함수 참조 비교인지 구분하면 출력의 true·false와 문자열을 연결해 이해할 수 있다.

## ☘️ 함수 생성자와 클래스의 같은 역할 비교

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**js-class.js**

```js
function PersonFunction(name, age) {
  this.name = name
  this.age = age
  this.getInfo = function () {
    return `${this.name}은 ${this.age}세 입니다.`
  }
}
PersonFunction.prototype.sayHi = function () {
  console.log(`hi ${this.name}`)
}
PersonFunction.sayBye = function () {
  console.log('bye')
}
class Person {
  constructor(name, age) {
    this.name = name
    this.age = age
    this.getInfo = function () {
      return `${this.name}은 ${this.age}세 입니다.`
    }
  }
  sayHi() {
    return `hi ${this.name}은 ${this.age}세 입니다.`
  }
  static sayBye() {
    console.log('bye')
  }
}
function compare(Type) {
  const person1 = new Type('박지성', 30),
    person2 = new Type('손흥민', 20)
  console.log(
    person1 === person2,
    person1.getInfo === person2.getInfo,
    person1.sayHi === person2.sayHi
  )
  console.log(person1.getInfo())
  Type.sayBye()
}
compare(PersonFunction)
compare(Person)
```

두 방식 모두 new 호출로 객체를 만들고 이름과 나이를 각 객체에 저장한다. 메서드는 해당 객체를 통해 호출해 this가 가리키는 값을 읽는다. class의 constructor는 생성할 때 초기값을 받으며 getInfo는 인스턴스에서 사용할 메서드다. 클래스는 함수를 짧게 적는 것 이상의 규칙이 있어 new 없이 호출할 수 없다. 두 인스턴스가 같은 메서드를 공유해도 필드는 서로 다르므로 한 사람의 나이 변경은 다른 사람에게 전달되지 않는다.

**js-class.js 실행 확인 결과**

```text
false false true
박지성은 30세 입니다.
bye
false false true
박지성은 30세 입니다.
bye
```

**실행 방법**

Node.js를 설치한 환경에서 `js-class.js`로 저장하고 `node js-class.js`를 실행한다. 별도 패키지는 필요 없다.
