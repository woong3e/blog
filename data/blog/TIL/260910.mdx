## ☘️ 객체 생성과 메서드

JavaScript는 프로토타입 기반이며 생성자 함수와 클래스 모두 인스턴스를 만든다. 클래스 없이도 프로토타입으로 상속을 구현할 수 있고, ES6 클래스는 생성·상속 의도를 표현하기 쉽게 한다.

```js
function Person(name, age) {
  this.name = name
  this.age = age
  this.getInfo = function () {
    return `${this.name}: ${this.age}`
  }
}
Person.prototype.sayHi = function () {
  return `hi ${this.name}`
}
Person.sayBye = function () {
  console.log('bye')
}
const p1 = new Person('박지성', 30)
const p2 = new Person('손흥민', 20)
```

- `p1 === p2`: false. 별도 객체의 참조를 비교
- `p1.getInfo === p2.getInfo`: false. 생성자 안의 함수는 객체마다 생성
- `p1.sayHi === p2.sayHi`: true. 프로토타입 함수 공유
- `Person.sayBye()`: 객체 없이 생성자에 붙은 정적 메서드 호출

## ☘️ 클래스와 용어

```js
class Person {
  constructor(name, age) {
    this.name = name
    this.age = age
    this.getInfo = function () {
      return `${this.name}: ${this.age}`
    }
  }
  sayHi() {
    return `hi ${this.name}`
  }
  static sayBye() {
    console.log('bye')
  }
}
```

생성자 함수 예제와 같은 비교 결과다. 두 예제는 각각 실행한다.

- 프로퍼티: 객체의 키·값 쌍 / 인스턴스: `new`로 만든 객체
- `constructor`: 클래스의 초기화 메서드
- 생성자 내부의 메서드: 객체마다 새로 생성 / 클래스 본문의 일반 메서드: 프로토타입에 위치
- 정적 메서드: 클래스·생성자로 접근 / `[[Prototype]]`: 객체와 프로토타입의 연결
- `class`, `extends`, `super`, `static`: 생성·상속·부모 접근·정적 기능을 명확히 표현
