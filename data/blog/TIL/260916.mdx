React는 상태와 입력값을 바탕으로 화면 구조를 계산하는 라이브러리다. DOM을 여러 곳에서 직접 수정하는 대신 컴포넌트가 어떤 화면을 반환할지 작성한다. 컴포넌트를 작은 역할로 나누면 같은 형태를 다른 값으로 재사용할 수 있다.

## ☘️ JSX에서 실제 화면까지

JSX는 JavaScript 안에서 태그 형태로 화면을 표현하는 문법이다. 브라우저가 JSX를 그대로 실행하는 것은 아니므로 변환 과정이 필요하다. 아래 문서는 실습을 위해 Babel을 브라우저에서 불러온다. root 요소를 만든 뒤 ReactDOM.createRoot로 연결하고 render에 App을 전달한다.

컴포넌트 이름은 대문자로 시작해 일반 HTML 태그와 구분한다. 함수 컴포넌트는 JSX를 반환하고 클래스 컴포넌트는 render 메서드에서 반환한다. 여러 요소를 반환할 때는 부모 하나나 Fragment로 묶는다. JSX 안의 중괄호는 JavaScript 표현식의 값을 넣는 자리다.

class 대신 className처럼 DOM 속성 표기가 달라지는 경우가 있다. style은 문자열이 아니라 객체로 전달하며 backgroundColor처럼 JavaScript 프로퍼티 이름을 사용한다. 객체 전체를 화면에 바로 넣지 말고 표시할 문자열·숫자나 JSX로 변환한다.

## ☘️ props와 children의 방향

props는 부모가 자식에게 전달하는 입력이다. 같은 StudentCard라도 이름과 점수를 다르게 넘기면 다른 학생을 표시한다. 자식이 전달받은 props를 직접 수정하는 대신 부모가 새 입력을 내려 주도록 구성한다.

children은 컴포넌트의 여는 태그와 닫는 태그 사이에 넣은 내용이다. 공통 테두리나 패널을 만들고 그 안의 내용만 바꿀 때 사용할 수 있다. 기본값은 입력이 빠졌을 때 무엇을 표시할지 정한다. 함수 컴포넌트는 인수에서, 클래스 컴포넌트는 this.props에서 값을 읽는다.

## ☘️ 목록과 반복 렌더링

배열의 map은 각 데이터를 JSX로 바꾼 배열을 만든다. key는 같은 목록 안에서 항목을 안정적으로 구분하는 값이다. 재정렬이나 삭제가 있는 목록에서는 항목의 id가 적합하며 순번만으로 구분하면 다른 항목을 같은 것으로 볼 수 있다.

render를 다시 호출하면 새 입력으로 화면을 다시 계산한다. 아래 Clock은 새 시각을 전달해 표시가 갱신되는 과정을 보여 준다. 재계산한다고 매번 화면의 모든 DOM을 없애고 새로 만드는 것은 아니다. React가 이전 결과와 비교해 필요한 변경을 반영한다.

## ☘️ 컴포넌트와 props를 표시하는 전체 문서

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**index.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>React 동작 확인</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
  </head>
  <body>
    <div id="root"></div>
    <script type="text/babel">
      function CourseHeader({ title, teacher }) {
        return (
          <h1>
            {title} / {teacher}
          </h1>
        )
      }
      function StudentCard({ name, age, track = '미정' }) {
        return (
          <p>
            {name} / {age} / {track}
          </p>
        )
      }
      function InfoPanel({ title = '안내', children }) {
        return (
          <section>
            <h2>{title}</h2>
            {children}
          </section>
        )
      }
      class TitleClass extends React.Component {
        render() {
          return React.createElement('h2', null, '클래스형 컴포넌트')
        }
      }
      function Clock() {
        return <p>현재 시간: {new Date().toLocaleTimeString()}</p>
      }
      function App() {
        return (
          <>
            <CourseHeader title="박지성 자서전" teacher="박지성" />
            <StudentCard name="박지성" age={30} track={5} />
            <StudentCard name="손흥민" age={20} />
            <InfoPanel>
              <p>첫 내용</p>
              <p>둘째 내용</p>
            </InfoPanel>
            <TitleClass />
            <Clock />
          </>
        )
      }
      const root = ReactDOM.createRoot(document.getElementById('root'))
      root.render(<App />)
      setInterval(() => root.render(<App />), 1000)
    </script>
  </body>
</html>
```

root 요소가 React 화면이 들어갈 자리다. createRoot로 연결하고 App을 render하면 App 안의 자식 컴포넌트가 각자 JSX를 반환한다. props는 부모가 전달한 입력이며 자식은 이를 읽어 화면을 만든다. children은 여는 태그와 닫는 태그 사이의 내용이다. 목록의 key는 형제 항목을 구분하는 안정적인 값으로 정한다. 클래스 컴포넌트는 this.props를, 함수 컴포넌트는 함수 인수를 통해 입력을 읽는다. Clock은 새 시각으로 다시 렌더링되어 초 단위 표시가 바뀐다. 객체 자체를 JSX 안에 직접 넣는 대신 표시할 문자열이나 숫자 프로퍼티를 골라야 한다.

**실행 방법**

아래 전체 코드를 index.html로 저장하고 브라우저에서 연다. React 18·React DOM 18·Babel을 CDN에서 가져오므로 인터넷 연결이 필요하다. Babel은 브라우저에서 JSX를 변환하는 실습용 구성이다. 파일을 여러 조각으로 나누어 붙일 필요가 없다.
