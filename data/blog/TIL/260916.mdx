# 🍀 브라우저 렌더링 과정

브라우저는 hmtl을 파싱하여 HTML DOM 트리를 만들고 css 파일을 파싱하여 CSSOM 트리를 만들고 DOM 트리와 CSSOM 트리를 결합하여 render 트리를 만듭니다.
그 다음에는 레이아웃을 계산하는데 각 노드의 위치와 크기를 계산합니다. 브라우저 화면의 어느 위치에 어느 크기로 출력될지 계산하는 단계입니다.
레이아웃 계산이 끝나면 레이아웃에 따라 노드를 화면에 그립니다.
여기까지가 브라우저 렌더링 과정이다.
근데 어떠한 액션이나 이벤트가 발생하면 레이아웃을 다시 계산해주고 다시 그려주어야하는데 이 과정을 reflow, repaint 라고 한다.

React 이전에도 DOM을 직접 조작해서 화면을 만들 수 있었지만, UI가 복잡해질수록 상태 변화에 따라 어떤 DOM을 수정해야 하는지 개발자가 직접 관리해야 했다.
React는 선언적으로 UI를 작성하고, 상태가 바뀌면 새로운 UI 트리를 만든 뒤 기존 트리와 비교하는 reconciliation 과정을 사용한다.
일반적인 트리 비교 알고리즘은 O(n³)의 비용이 들 수 있지만, React는 몇 가지 가정을 기반으로 한 diffing 알고리즘을 사용해 O(n) 수준으로 비교한다.
이후 실제로 변경이 필요한 DOM만 갱신한다.
