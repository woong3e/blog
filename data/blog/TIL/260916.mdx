## ☘️ 컴포넌트와 props

props는 부모가 자식에게 전달하는 객체이며 **부모 → 자식 단방향**이다. 같은 컴포넌트도 다른 props로 재사용한다.

```jsx
function CourseHeader({ title, teacher }) {
  return (
    <h1>
      {title} / {teacher}
    </h1>
  )
}
function StudentCard({ name, age, track = '미정' }) {
  return (
    <p>
      {name} / {age} / {track}
    </p>
  )
}
function InfoPanel({ title = '안내', children }) {
  return (
    <section>
      <h2>{title}</h2>
      {children}
    </section>
  )
}
function App() {
  return (
    <>
      <CourseHeader title="박지성 자서전" teacher="박지성" />
      <StudentCard name="박지성" age={30} track={5} />
      <StudentCard name="손흥민" age={20} />
      <InfoPanel>
        <p>첫 내용</p>
        <p>둘째 내용</p>
      </InfoPanel>
    </>
  )
}
```

구조 분해로 필요한 값을 받고, 전달하지 않은 track·title은 기본값을 사용한다. 태그 사이의 요소들은 children으로 전달되어 자식이 지정한 위치에 표시된다.

## ☘️ 렌더링 흐름

**HTML 파싱 → DOM / CSS 파싱 → CSSOM → 렌더 트리 → 레이아웃 → 페인트**

- 레이아웃: 각 노드의 위치·크기 계산
- reflow: 레이아웃 재계산 / repaint: 화면 다시 그리기. 변화 종류에 따라 필요한 과정이 달라짐
- 직접 DOM 조작: 상태 변화에 맞춰 수정할 DOM을 개발자가 관리
- React: 상태에 맞는 UI를 선언 → 새 UI 트리 구성 → 이전 트리와 reconciliation → 필요한 DOM 갱신

일반적인 트리 비교는 O(n³)까지 들 수 있지만 React의 휴리스틱 diff는 O(n) 수준으로 비교한다는 점을 학습했다. 상태를 바꾸면 React가 화면 갱신을 처리한다.
