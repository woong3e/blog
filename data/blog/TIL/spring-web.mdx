웹 화면과 서버는 HTTP 요청과 응답으로 데이터를 주고받는다. 서버는 주소와 요청 방식으로 처리 메서드를 고르고, 입력을 Java 값으로 변환해 검증한 뒤 상태 코드와 본문을 돌려준다. 아래 예제는 회원 API를 중심으로 이 흐름과 파일 업로드·인터셉터·React 연동을 연결한다.

## ☘️ 요청을 메서드와 값에 연결하기

SpringApplication.run은 애플리케이션을 시작하고 @SpringBootApplication은 설정과 컴포넌트 탐색의 출발점을 제공한다. @RestController는 반환값을 응답 본문으로 보내는 컨트롤러다. @RequestMapping은 공통 경로, Get·Post·Put·DeleteMapping은 요청 방식과 세부 경로를 정한다.

@PathVariable은 주소 경로의 회원 번호를, @RequestParam은 쿼리 문자열을, @RequestHeader는 헤더를, @CookieValue는 쿠키를 읽는다. @RequestBody는 본문을 받는다. 이 값들은 모두 요청에 들어 있지만 위치가 다르므로 같은 방식으로 찾을 수 없다. 선택값은 누락 가능성과 null 처리를 함께 정한다.

JSON은 이름과 값, 배열을 텍스트로 표현한 형식이다. 객체를 JSON으로 보내는 것이 직렬화, 받은 JSON을 객체로 읽는 것이 역직렬화다. @JsonProperty는 Java 필드와 JSON 이름을 연결하고 @JsonFormat은 날짜 형식을 지정한다. DTO 객체를 반환하는 것과 JSON을 이미 문자열로 만든 뒤 다시 반환하는 것은 결과 구조가 다르다.

## ☘️ 응답·검증·예외 처리

ResponseEntity는 상태·헤더·본문을 함께 정한다. 등록 성공은 201과 새 자원의 Location, 조회는 200, 본문 없이 끝난 수정·삭제는 204로 표현한다. 클라이언트는 204에서 JSON 본문을 읽으려고 하지 않아야 한다. 요청 DTO와 응답 DTO를 나누면 비밀번호 같은 입력값을 응답에서 제외할 수 있다.

@Valid는 DTO에 선언한 제약을 검사한다. NotBlank는 빈 문자열과 공백, NotNull은 null, Size는 길이, Past는 과거 날짜 조건이다. 본문 JSON 자체를 읽지 못한 오류와 읽은 값이 제약에 맞지 않는 오류는 발생 단계가 다르다.

@RestControllerAdvice는 여러 컨트롤러의 예외를 공통 응답으로 바꾼다. 없는 회원은 404, 잘못된 입력은 400으로 돌려 호출자가 원인을 구분하도록 한다. 예상하지 못한 내부 오류는 서버에 원인을 기록하고 응답에는 일반 안내를 보낸다. 아래 메모리 목록은 서버를 재시작하면 초기화되며 데이터베이스 저장은 구현하지 않는다.

## ☘️ 파일 저장과 요청 전후 처리

파일은 multipart/form-data 요청에서 MultipartFile로 받는다. 빈 파일과 이름을 검사한 뒤 UUID를 붙인 새 이름으로 저장한다. 계산한 경로가 업로드 폴더 안인지 확인하고 응답에는 절대 경로 대신 상대 경로를 보낸다. 파일 하나의 크기와 요청 전체 크기는 별도 제한이다. 확장자를 보존했다고 실제 내용의 형식까지 검사한 것은 아니다.

다중 업로드는 앞에서 성공한 파일을 기억해 중간 실패 시 정리를 시도한다. 파일 저장은 데이터베이스 트랜잭션이 자동으로 취소하는 작업이 아니다. 정리 도중의 실패가 최초 원인을 덮지 않도록 suppressed 예외로 추가한다. 전송 중 부분적으로 생긴 파일이나 프로세스 중단까지 완전하게 복구하는 저장 시스템은 이 예제의 범위가 아니다.

인터셉터는 컨트롤러 앞뒤에서 공통 동작을 수행한다. preHandle이 true이면 진행하고 false이면 이후 처리를 멈춘다. afterCompletion은 완료 시점에 시간 계산 같은 정리를 한다. 아래는 전체 API의 시간을 측정하고 관리자 경로에 추가 키 검사를 적용한다. 키를 검사하는 인터셉터가 직접 응답하면 상태와 본문 형식도 직접 정해야 한다.

## ☘️ React 연동과 API 문서

localhost라도 포트가 3000과 8080이면 출처가 다르다. CORS는 브라우저가 다른 출처의 응답을 사용하도록 서버가 허용 범위를 알리는 규칙이다. 서버의 실제 처리 실패와 브라우저의 출처 제한은 원인이 다르므로 구분한다.

클라이언트는 Effect에서 목록 요청 → 상태 확인 → JSON 읽기 → state 저장 순서로 처리한다. 등록은 form의 onSubmit에서 기본 전송을 막고 JSON을 POST한 뒤 반환된 회원을 새 배열에 추가한다. 최초 조회와 등록 중 상태를 나누면 버튼 비활성화와 로딩 안내를 각각 표현할 수 있다.

OpenAPI는 요청·응답의 문서 형식이고 Swagger UI는 이를 읽고 요청을 시험하는 화면이다. Operation과 Schema는 기능과 필드의 의미를 설명한다. 문서에 오류 코드를 적는 것만으로 서버의 예외 처리가 구현되지는 않는다. 문서의 약속과 실제 상태 코드를 함께 확인해야 한다.

## ☘️ HTTP·검증·오류·파일·화면을 연결한 전체 예제

HTTP 요청 연결, JSON 변환, 검증, 오류 응답, 파일 업로드, 인터셉터와 React 연동을 하나의 회원 API로 정리했다. 원본의 메뉴·주문·회원 프로젝트를 그대로 합친 것이 아니라 같은 동작을 회원 자원으로 확인하는 설명용 구성이다. server는 아래 build.gradle과 src, client는 client 폴더의 별도 프로젝트다.

```jsx
'use client'
import { useEffect, useState } from 'react'
const base = process.env.NEXT_PUBLIC_API_URL
export default function Page() {
  const [members, setMembers] = useState([])
  const [name, setName] = useState('')
  const [loading, setLoading] = useState(true)
  const [saving, setSaving] = useState(false)
  const [error, setError] = useState('')
  useEffect(() => {
    let active = true
    async function load() {
      try {
        const response = await fetch(`${base}/api/v1/members`)
        if (!response.ok) throw new Error('목록 조회 실패')
        const data = await response.json()
        if (active) setMembers(data)
      } catch (error) {
        if (active) setError(error.message)
      } finally {
        if (active) setLoading(false)
      }
    }
    load()
    return () => {
      active = false
    }
  }, [])
  async function submit(event) {
    event.preventDefault()
    setSaving(true)
    setError('')
    try {
      const response = await fetch(`${base}/api/v1/members`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          id: 'example-user',
          password: 'demo-only',
          name,
          enrollDate: '2020-01-01',
        }),
      })
      if (!response.ok) {
        const data = await response.json()
        throw new Error(data.message || '등록 실패')
      }
      const member = await response.json()
      setMembers((previous) => [...previous, member])
      setName('')
    } catch (error) {
      setError(error.message)
    } finally {
      setSaving(false)
    }
  }
  return (
    <main>
      <h1>회원 목록</h1>
      {loading && <p>조회 중</p>}
      {error && <p role="alert">{error}</p>}
      <ul>
        {members.map((member) => (
          <li key={member.memberNo}>
            {member.memberNo}: {member.name}
          </li>
        ))}
      </ul>
      <form onSubmit={submit}>
        <label>
          이름{' '}
          <input
            required
            maxLength={5}
            value={name}
            onChange={(event) => setName(event.target.value)}
          />
        </label>
        <button disabled={saving}>{saving ? '등록 중' : '등록'}</button>
      </form>
    </main>
  )
}
```

**src/main/java/example/Main.java**

```java
package example;

import com.fasterxml.jackson.annotation.JsonFormat;
import com.fasterxml.jackson.annotation.JsonProperty;
import io.swagger.v3.oas.annotations.Operation;
import io.swagger.v3.oas.annotations.media.Schema;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import jakarta.validation.Valid;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.NotNull;
import jakarta.validation.constraints.Past;
import jakarta.validation.constraints.Size;
import java.io.IOException;
import java.net.URI;
import java.nio.file.Files;
import java.nio.file.Path;
import java.time.LocalDate;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.CookieValue;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.PutMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.multipart.MultipartFile;
import org.springframework.web.servlet.HandlerInterceptor;
import org.springframework.web.servlet.config.annotation.CorsRegistry;
import org.springframework.web.servlet.config.annotation.InterceptorRegistry;
import org.springframework.web.servlet.config.annotation.WebMvcConfigurer;

@SpringBootApplication
public class Main {
  public static void main(String[] args) {
    SpringApplication.run(Main.class, args);
  }

  public static class MemberRequest {
    @NotBlank public String id;

    @NotBlank
    @Size(max = 10)
    public String password;

    @NotBlank
    @Size(max = 5)
    @Schema(description = "회원 이름", example = "사용자")
    public String name;

    @NotNull
    @Past
    @JsonFormat(pattern = "yyyy-MM-dd")
    public LocalDate enrollDate;
  }

  public static class MemberResponse {
    @JsonProperty("memberNo")
    public int no;

    public String id, name;

    @JsonFormat(pattern = "yyyy-MM-dd")
    public LocalDate enrollDate;

    public MemberResponse(int no, MemberRequest request) {
      this.no = no;
      id = request.id;
      name = request.name;
      enrollDate = request.enrollDate;
    }
  }

  public static class MissingMember extends RuntimeException {
    public MissingMember(int no) {
      super(no + "번 회원 없음");
    }
  }

  @RestController
  @RequestMapping("/api/v1")
  public static class Controller {
    private final List<MemberResponse> members = new ArrayList<>();
    private int nextNo = 1;
    private final Path uploads;

    public Controller(@Value("${file.upload-dir}") String directory) {
      uploads = Path.of(directory).toAbsolutePath().normalize();
    }

    @GetMapping("/hello")
    public String hello() {
      return "Spring Boot Hello";
    }

    @GetMapping("/members")
    @Operation(summary = "회원 목록 검색")
    public List<MemberResponse> list(@RequestParam(required = false) String name) {
      return members.stream().filter(member -> name == null || member.name.contains(name)).toList();
    }

    @GetMapping("/members/{no}")
    public MemberResponse find(@PathVariable int no) {
      return member(no);
    }

    @PostMapping("/members")
    public ResponseEntity<MemberResponse> create(@Valid @RequestBody MemberRequest request) {
      MemberResponse member = new MemberResponse(nextNo++, request);
      members.add(member);
      return ResponseEntity.created(URI.create("/api/v1/members/" + member.no)).body(member);
    }

    @PutMapping("/members/{no}")
    public ResponseEntity<Void> update(
        @PathVariable int no, @Valid @RequestBody MemberRequest request) {
      MemberResponse member = member(no);
      member.id = request.id;
      member.name = request.name;
      member.enrollDate = request.enrollDate;
      return ResponseEntity.noContent().build();
    }

    @DeleteMapping("/members/{no}")
    public ResponseEntity<Void> delete(@PathVariable int no) {
      members.remove(member(no));
      return ResponseEntity.noContent().build();
    }

    private MemberResponse member(int no) {
      return members.stream()
          .filter(member -> member.no == no)
          .findFirst()
          .orElseThrow(() -> new MissingMember(no));
    }

    @GetMapping("/request-info")
    public Map<String, Object> requestInfo(
        @RequestParam Map<String, String> query,
        @RequestHeader(value = "User-Agent", required = false) String agent,
        @CookieValue(value = "clientId", required = false) String clientId) {
      Map<String, Object> response = new LinkedHashMap<>();
      response.put("query", query);
      response.put("agent", agent);
      response.put("clientId", clientId);
      return response;
    }

    @PostMapping("/raw")
    public String raw(@RequestBody String body) {
      return body;
    }

    @PostMapping("/files")
    public Map<String, Object> upload(@RequestParam("file") MultipartFile file) throws IOException {
      if (file.isEmpty()
          || file.getOriginalFilename() == null
          || file.getOriginalFilename().isBlank()) throw new IllegalArgumentException("빈 파일 또는 이름");
      String name = file.getOriginalFilename();
      if (name.contains("..")) throw new IllegalArgumentException("잘못된 이름");
      name = Path.of(name).getFileName().toString();
      String extension = name.contains(".") ? name.substring(name.lastIndexOf('.')) : "";
      Files.createDirectories(uploads);
      Path destination = uploads.resolve(UUID.randomUUID() + extension).normalize();
      if (!destination.startsWith(uploads)) throw new IllegalArgumentException("잘못된 경로");
      file.transferTo(destination);
      return Map.of(
          "originalName",
          name,
          "path",
          uploads.relativize(destination).toString(),
          "size",
          file.getSize());
    }

    @PostMapping("/files/multiple")
    public List<Map<String, Object>> uploadMultiple(
        @RequestParam("files") List<MultipartFile> files) throws IOException {
      List<Map<String, Object>> saved = new ArrayList<>();
      try {
        for (MultipartFile file : files) saved.add(upload(file));
        return saved;
      } catch (IOException | RuntimeException original) {
        for (Map<String, Object> file : saved) {
          try {
            Files.deleteIfExists(uploads.resolve((String) file.get("path")));
          } catch (IOException cleanup) {
            original.addSuppressed(cleanup);
          }
        }
        throw original;
      }
    }

    @PostMapping("/admin/check")
    public String admin() {
      return "관리자 요청 통과";
    }
  }

  @RestControllerAdvice
  public static class Errors {
    @ExceptionHandler(MissingMember.class)
    public ResponseEntity<Map<String, Object>> missing(
        MissingMember error, HttpServletRequest request) {
      return ResponseEntity.status(404)
          .body(
              Map.of(
                  "status", 404, "message", error.getMessage(), "path", request.getRequestURI()));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<Map<String, Object>> invalid(MethodArgumentNotValidException error) {
      String message =
          error.getBindingResult().getFieldErrors().stream()
              .findFirst()
              .map(field -> field.getDefaultMessage())
              .orElse("잘못된 입력");
      return ResponseEntity.badRequest().body(Map.of("status", 400, "message", message));
    }

    @ExceptionHandler(IllegalArgumentException.class)
    public ResponseEntity<Map<String, Object>> bad(IllegalArgumentException error) {
      return ResponseEntity.badRequest().body(Map.of("status", 400, "message", error.getMessage()));
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    public ResponseEntity<Map<String, Object>> unreadable() {
      return ResponseEntity.badRequest()
          .body(Map.of("status", 400, "message", "요청 본문과 날짜 형식을 확인하세요"));
    }

    @ExceptionHandler(Exception.class)
    public ResponseEntity<Map<String, Object>> internal(Exception error) {
      error.printStackTrace();
      return ResponseEntity.internalServerError()
          .body(Map.of("status", 500, "message", "서버 처리 중 오류가 발생했습니다"));
    }
  }

  @Configuration
  public static class WebConfig implements WebMvcConfigurer {
    private final String key;

    public WebConfig(@Value("${demo.api-key}") String key) {
      this.key = key;
    }

    public void addCorsMappings(CorsRegistry registry) {
      registry
          .addMapping("/api/**")
          .allowedOrigins("http://localhost:3000")
          .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS")
          .allowedHeaders("Content-Type", "X-API-KEY");
    }

    public void addInterceptors(InterceptorRegistry registry) {
      registry
          .addInterceptor(
              new HandlerInterceptor() {
                public boolean preHandle(
                    HttpServletRequest request, HttpServletResponse response, Object handler) {
                  request.setAttribute("started", System.nanoTime());
                  return true;
                }

                public void afterCompletion(
                    HttpServletRequest request,
                    HttpServletResponse response,
                    Object handler,
                    Exception error) {
                  System.out.println(
                      "요청 시간(ns): " + (System.nanoTime() - (Long) request.getAttribute("started")));
                }
              })
          .addPathPatterns("/api/**")
          .order(1);
      registry
          .addInterceptor(
              new HandlerInterceptor() {
                public boolean preHandle(
                    HttpServletRequest request, HttpServletResponse response, Object handler)
                    throws IOException {
                  if (!key.isBlank() && key.equals(request.getHeader("X-API-KEY"))) return true;
                  response.setStatus(401);
                  response.setContentType("application/json;charset=UTF-8");
                  response.getWriter().write("{\"status\":401,\"message\":\"API key required\"}");
                  return false;
                }
              })
          .addPathPatterns("/api/v1/admin/**")
          .order(2);
    }
  }
}
```

서버의 회원 목록은 메모리에만 있어 재시작하면 사라진다. GET은 목록·상세를 조회하고 POST는 등록 뒤 201과 Location을 반환한다. PUT·DELETE는 성공 시 본문 없는 204를 보낸다. 요청 DTO는 비밀번호를 받지만 응답 DTO에는 비밀번호 필드가 없다. JSON의 memberNo는 Java 필드 no와 @JsonProperty로 연결된다. @Valid가 문자열·날짜 제약을 검사하고 잘못된 값은 Advice에서 400, 없는 회원은 404로 바꾼다. 최대 길이 등은 학습 코드의 조건이며 일반 서비스의 정책을 제시하는 것은 아니다.

request-info는 쿼리·헤더·쿠키가 들어오는 위치를 나누어 보여 준다. 파일은 빈 값과 이름을 검사하고 새 UUID 이름으로 업로드 폴더에 쓴다. 응답은 절대 경로 대신 상대 경로를 보낸다. 인터셉터의 preHandle이 false이면 관리자 컨트롤러에 도달하지 않는다. 관리자 테스트를 하려면 서버 실행 전 DEMO_API_KEY에 직접 준비한 연습용 값을 넣고 같은 값을 X-API-KEY 헤더로 보낸다. 코드에는 고정 키를 넣지 않았다. 이 방식은 인터셉터 흐름을 확인하는 예제다.

클라이언트의 Effect는 목록을 fetch해 상태에 저장한다. 등록 폼은 onSubmit에서 기본 전송을 막고 JSON 요청을 보낸 뒤 반환된 새 회원을 배열에 추가한다. loading과 saving을 나누어 최초 조회와 등록 중 표시를 구분한다. 공개 API 주소만 환경 변수에 넣으며 예제의 id와 password는 요청 형태를 보여 주는 가상 테스트 입력이다. React 화면 3000과 서버 8080은 다른 출처라 서버 CORS 설정이 필요하다. Swagger UI는 /swagger-ui/index.html에서 열고 /v3/api-docs로 문서를 읽는다. 문서화 어노테이션이 실제 오류 처리를 대신하지는 않는다.

실제 요청 검증에서 등록 201, 조회 200, 수정·삭제 204, 없는 회원 404, 검증·JSON 오류 400, 관리자 키 누락 401을 확인했다. 단일 파일 저장과 다중 업로드의 빈 파일 오류, OpenAPI 문서 조회도 확인했다. 검증 서버는 충돌을 피하려고 18089 포트로 실행했으며 예제 기본 포트는 8080이다.

**실행 방법**

서버 루트에서 JDK 21과 Gradle로 `gradle bootRun`을 실행한다. 클라이언트는 client/.env.local.example을 .env.local로 복사하고 `npm install`, `npm run dev`를 실행한다. API는 http://localhost:8080, 화면은 http://localhost:3000이다. api-test.http는 HTTP 요청 도구에서 순서대로 실행한다. 파일 업로드는 multipart/form-data의 file 필드로 보내며 업로드 폴더가 필요할 때 생성된다.
