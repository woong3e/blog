이벤트는 클릭·입력·제출 같은 일이 발생했다는 알림이다. 리스너는 그 알림을 받았을 때 실행할 함수다. 이벤트가 어디서 시작했고 어느 요소가 처리 중인지 구분하면 중첩 버튼과 목록도 일관되게 다룰 수 있다.

## ☘️ 등록한 함수와 이벤트 대상

addEventListener는 요소에 이벤트 종류와 함수를 연결한다. 함수 자체를 전달해야 하며 등록하는 자리에서 함수를 호출한 결과를 넘기면 의도와 다르다. removeEventListener는 등록할 때 사용한 같은 함수 참조가 필요하다. 모양이 같은 새 함수를 전달해도 기존 리스너가 제거되지 않는다.

이벤트 객체의 target은 실제 이벤트가 시작된 요소이고 currentTarget은 현재 실행 중인 리스너가 붙은 요소다. 버튼 안의 글자나 다른 태그를 누르면 target은 내부 요소일 수 있다. 함수가 처리할 기준이 어느 쪽인지 명확히 정한다.

## ☘️ 전파와 이벤트 위임

이벤트는 상위 요소를 거쳐 대상으로 내려가는 캡처 단계와 대상에서 위로 올라가는 버블 단계를 가질 수 있다. 기본 클릭 리스너는 보통 버블 단계에서 실행된다. 자식과 부모 양쪽에 클릭 처리가 있으면 한 번 누른 것이 여러 핸들러를 실행할 수 있다.

이벤트 위임은 목록 부모에 리스너 하나를 두고 target에서 실제 작업 버튼을 찾는 방식이다. closest는 자신부터 위로 올라가며 선택자에 맞는 요소를 찾는다. contains로 현재 목록 안의 버튼인지 확인하면 다른 영역까지 잘못 처리하는 것을 막을 수 있다. 항목이 나중에 추가되어도 부모의 리스너를 사용할 수 있다.

stopPropagation은 이후 상위 요소로 전달되는 것을 막는다. preventDefault는 링크 이동이나 폼 제출 같은 기본 동작을 막는다. 전파를 막는 것과 기본 동작을 막는 것은 서로 대신할 수 없다.

## ☘️ 입력과 폼 처리

input 이벤트는 입력값이 바뀔 때, keydown은 키를 누를 때 사용한다. focus와 blur는 초점 진입·이탈을 나타낸다. 입력 길이는 현재 value를 읽어 계산하고 Enter 처리는 이벤트의 key를 확인한다.

폼은 버튼 클릭보다 submit 이벤트에서 처리하면 클릭과 Enter 제출을 같은 경로로 다룰 수 있다. 기본 제출을 막은 뒤 입력을 검사하고 오류가 있으면 안내한다. 빈 문자열과 공백만 있는 문자열을 구분하려면 trim한 값으로 검사한다. 아래 코드는 카운터 해제·위임·모달·입력·검증을 별도 요소에서 확인하도록 구성했다.

## ☘️ 이벤트 전달과 기본 동작 제어

다음은 연결된 학습 코드의 핵심 동작을 한 파일에서 확인하도록 정리한 설명용 예제다. 원본 프로젝트 전체를 그대로 옮긴 것은 아니다. 필요한 선언과 실행 부분을 함께 두었으며, 아래 코드만 저장해 흐름을 따라갈 수 있다.

**events-demo.html**

```html
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <title>이벤트 흐름</title>
    <style>
      .selected {
        background: gold;
      }
      .focused {
        outline: 2px solid blue;
      }
      #backdrop {
        position: fixed;
        inset: 0;
        background: #7778;
      }
      #modal {
        margin: 100px auto;
        padding: 20px;
        background: white;
        width: 280px;
      }
    </style>
  </head>
  <body>
    <button id="count">증가 <strong>버튼</strong></button><button id="stop">중지</button>
    <p id="counter">0</p>
    <ul id="menus">
      <li data-menu-id="1">
        <span>아메리카노</span><button class="select-menu"><strong>선택</strong></button>
      </li>
      <li data-menu-id="2"><span>카페라떼</span><button class="select-menu">선택</button></li>
    </ul>
    <p id="selection"></p>
    <button id="open">모달 열기</button>
    <div id="backdrop" hidden>
      <div id="modal">
        <p>내부 클릭으로는 닫히지 않습니다.</p>
        <a href="https://example.invalid" id="notice">이동을 막는 링크</a>
      </div>
    </div>
    <input id="message" aria-label="메시지" />
    <p id="length">0</p>
    <p id="message-result"></p>
    <form id="signup">
      <input id="username" aria-label="이름" /><input
        id="password"
        type="password"
        aria-label="비밀번호"
      /><input id="terms" type="checkbox" /><label for="terms">약관 동의</label
      ><button>검증</button>
    </form>
    <p id="signup-result"></p>
    <script>
      const countButton = document.getElementById('count')
      let count = 0
      const increase = (event) => {
        document.getElementById('counter').textContent = ++count
        console.log(event.target.tagName, event.currentTarget.tagName)
      }
      countButton.addEventListener('click', increase)
      document.getElementById('stop').onclick = () =>
        countButton.removeEventListener('click', increase)
      const menus = document.getElementById('menus')
      menus.addEventListener('click', (event) => {
        const button = event.target.closest('.select-menu')
        if (!button || !menus.contains(button)) return
        const item = button.closest('li')
        for (const menu of menus.children) menu.classList.remove('selected')
        item.classList.add('selected')
        document.getElementById('selection').textContent =
          item.dataset.menuId + ': ' + item.querySelector('span').textContent
      })
      const backdrop = document.getElementById('backdrop')
      document.getElementById('open').onclick = () => {
        backdrop.hidden = false
      }
      backdrop.onclick = () => {
        backdrop.hidden = true
      }
      document.getElementById('modal').onclick = (event) => event.stopPropagation()
      document.getElementById('notice').onclick = (event) => {
        event.preventDefault()
        event.currentTarget.textContent = '이동 차단됨'
      }
      const message = document.getElementById('message'),
        length = document.getElementById('length')
      message.oninput = () => {
        length.textContent = message.value.length
      }
      message.onkeydown = (event) => {
        if (event.key === 'Enter' && message.value.trim()) {
          document.getElementById('message-result').textContent = message.value.trim()
          message.value = ''
          length.textContent = 0
        }
      }
      message.onfocus = () => message.classList.add('focused')
      message.onblur = () => message.classList.remove('focused')
      document.getElementById('signup').onsubmit = (event) => {
        event.preventDefault()
        const name = document.getElementById('username').value.trim(),
          password = document.getElementById('password').value
        document.getElementById('signup-result').textContent =
          name.length < 2
            ? '이름 두 글자 이상'
            : password.length < 6
              ? '비밀번호 여섯 글자 이상'
              : !document.getElementById('terms').checked
                ? '약관 동의 필요'
                : '회원가입 검증에 성공했습니다.'
      }
    </script>
  </body>
</html>
```

같은 함수 참조를 addEventListener와 removeEventListener에 넘겨야 등록한 함수를 해제할 수 있다. target은 실제로 누른 요소, currentTarget은 현재 리스너가 붙은 요소다. 목록에 리스너 하나를 두고 closest로 항목 버튼을 찾으면 나중에 추가된 항목에도 같은 처리 흐름을 적용할 수 있다. contains 검사는 목록 바깥 요소를 잘못 처리하지 않도록 범위를 확인한다. preventDefault는 링크 이동이나 폼 전송을 막고, stopPropagation은 상위 요소로 이벤트가 전달되는 것을 막는다. 둘은 다른 동작이다. input은 값이 바뀔 때, keydown은 키를 누를 때, submit은 폼을 제출할 때 발생한다.

**실행 방법**

`events-demo.html`로 저장하고 브라우저에서 연다. 버튼을 누르거나 입력값을 바꾸며 아래의 화면 변화를 확인한다.
