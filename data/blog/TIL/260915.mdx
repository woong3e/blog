## ☘️ 등록과 이벤트 대상

- HTML 이벤트 속성, DOM의 `onclick`, `addEventListener()`로 등록할 수 있다.
- onclick에 새 함수를 대입하면 이전 함수를 덮어쓴다. addEventListener는 서로 다른 핸들러를 여러 개 등록 가능
- `removeEventListener('click', handler)`는 **같은 함수 참조·이벤트 종류·capture 설정**이 필요. 닮은 화살표 함수를 새로 쓰면 제거되지 않음
- 카운터는 클릭마다 횟수를 올리고, 중지 버튼에서 등록한 증가 함수를 제거

`target`은 이벤트가 시작된 요소, `currentTarget`은 지금 핸들러가 등록된 요소다. 버튼 속 글자를 클릭하면 둘이 다를 수 있다. `clientX/Y`는 뷰포트 기준 클릭 위치다.

```js
button.addEventListener('click', (event) => {
  const clickedButton = event.currentTarget
  clickedButton.textContent = '클릭됐다.'
  setTimeout(() => {
    clickedButton.textContent = 'Best Practice'
  }, 2000)
})
```

일반 함수 핸들러의 this는 currentTarget, 화살표 함수는 바깥 this다. 나중에는 currentTarget이 null일 수 있어 비동기 콜백에서 쓸 요소는 미리 저장한다.

## ☘️ 위임과 데이터

전파는 **캡처링 → 타깃 → 버블링**이다. click처럼 버블링하는 이벤트는 부모에서 처리할 수 있어, 나중에 추가된 항목에도 위임이 적용된다. 모든 이벤트가 버블링하는 것은 아니다.

```js
productList.addEventListener('click', (event) => {
  const item = event.target.closest('.product-item')
  if (!item || !productList.contains(item)) return
  const price = Number(item.dataset.price)
  infoPanel.textContent = `${item.dataset.productId}: ${price.toLocaleString('ko-KR')}원`
})
```

- `closest()`는 자신부터 부모 방향으로 탐색. 결과를 사용해야 자식 strong 등을 눌러도 처리됨
- `contains()`는 실제 목록 내부인지 확인. 다시 target.matches('li')만 검사하면 중첩 클릭 누락
- `data-product-id` → `dataset.productId`, `data-menu-id` → `dataset.menuId`
- dataset 값은 문자열. 계산 전 Number 변환, `dataset.selected = 'true'`로 설정, `delete`로 제거
- 메뉴·상품의 단일 선택: 기존 selected 클래스들을 제거하고 선택 항목에 추가. 음료 목록은 highlight 토글

## ☘️ 입력과 폼 검증

- `preventDefault()`: 취소 가능한 기본 동작 차단(링크 이동·폼 제출)
- `stopPropagation()`: 요소 간 전파 차단(모달 내부 클릭이 배경 닫기로 이어지는 것 방지)
- 둘은 별개다. 모달 내부의 링크 이동을 막으려면 링크 기본 동작도 따로 제어
- `dblclick`, `mousedown`, `event.button`: 마우스 동작·버튼 확인
- `keydown` / `keyup`: 키 누름·뗌. `key`는 Enter·a 같은 값, `code`는 KeyA 같은 물리 위치
- `input`: 붙여넣기까지 포함한 입력값 변경. 코드로 value를 비우면 자동 발생하지 않아 글자 수도 직접 초기화
- `focus` / `blur`: 이름 입력 스타일 변경 / `checked`: 관심사 선택 수·약관 동의 확인

```js
form.addEventListener('submit', (event) => {
  event.preventDefault()
  if (nameInput.value.trim().length < 2) {
    showError('이름 두 글자 이상')
    return
  }
  if (passwordInput.value.length < 6) {
    showError('비밀번호 여섯 글자 이상')
    return
  }
  if (!terms.checked) {
    showError('약관 동의 필요')
    return
  }
  signupResult.textContent = '회원가입 검증에 성공했습니다.'
})
```

showError는 안내 표시를 줄여 쓴 표현이다. 버튼 click 대신 **폼 submit**을 처리해야 Enter 제출도 포함한다. 오류는 안내 후 return, 성공 시에도 실습은 기본 제출을 막으며 실제 회원 저장까지 하지는 않는다.
