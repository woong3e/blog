# 🍀 비동기 처리

동기란? 하나의 작업이 끝날 때까지 기다린 후 다음 작업을 수행하는 방식.
비동기란? 하나의 작업이 종료되기를 기다리지 않고 다음 작업을 수행하는 방식.

![동기비동기](/static/images/동기비동기.png)

자바, c# → 멀티스레드 프로그래밍 가능

자바스크립트 → 기본적으로 단일스레드

```jsx
아래 실행순서는

console.log('1')

setTimeout(()=>{
	console.log('2');
},5000);

console.log('3');

실행결과
1
3
2
```

일반적으로 API 요청의 경우, 시간이 오래걸릴 수 있기 때문에 비동기 방식으로 처리한다.

1. 데이터 요청
2. 데이터를 받아서 실행해야 하는 코드

데이터가 도착하기 전에 2번이 실행되면 문제가 발생할 수 있다.

비동기 작업이 완료된 후 다음 코드가 실행되도록 하기 위해서, 초기에는 콜백 함수를 사용했다.

# 🍀 콜백 함수

```jsx
function 고차함수(callback) {
  console.log('저는 고차함수입니다.');
  callback();
}

function 콜백함수() {
  console.log('저는 콜백함수입니다.');
}

고차함수(콜백함수);

실행결과
저는 고차함수입니다.
저는 콜백함수입니다.

```

# 🍀 promise 객체

콜백 함수의 단점을 보완하여 나온 것이 Promise 객체.

Promise 객체는 자바스크립트의 내장 객체.

Promise는 비동기 작업의 성공과 실패에 대한 결과를 처리할 수 있는 방법을 제공.

pending, fulfilled, rejected 3개의 상태를 가지는데 resolve 함수는 성공 결과를 전달하는 함수, reject 함수는 실패 이유를 전달하는 함수이다.

Promise를 사용할 때는 then과 catch 메서드를 이용하여 비동기 작업을 처리한다.

then을 사용하여 순차적으로 비동기 작업을 처리할 수 있지만, then을 많이 사용하다 보면 코드가 길어지며 복잡해지고 가독성을 해칠 수 있다.

```jsx
fetch('/api/user')
  .then((response) => response.json())
  .then((user) => fetch(`/api/orders/${user.id}`))
  .then((response) => response.json())
  .then((orders) => {
    // 주문 데이터 사용
  })
  .catch((error) => {
    // 에러 처리
  })
```

# 🍀 async/await

이것을 보완하여 나온 것이 async/await 이다.

기존 Promise 보다 직관적이며 간결하게 사용이 가능하다.

async 키워드가 붙으면 항상 Promise 객체를 반환하고 await 은 Promise 의 결과가 나올때까지 기다린다.

await 키워드는 async 함수 내에서 사용해야만 합니다.

‘try, catch’ 블록을 사용하여 에러 처리하며 동기코드와 동일한 방식으로 에러를 처리할 수 있어 이해하기 쉽다.

```jsx
async function getUser() {
  try {
    const response = await fetch('/api/user')
    const user = await response.json()
    return user
  } catch (error) {
    console.error(error)
  }
}
```

Promise 객체의 주요 메서드

Promise.all() : 여러 비동기 작업을 동시에 실행하고, 모두 성공해야 결과를 받는다.

Promise.allSettled() : 여러 비동기 작업의 성공/실패 여부를 모두 확인한다.

Promise.any() : 여러 비동기 작업 중 가장 먼저 성공한 결과를 받는다.
